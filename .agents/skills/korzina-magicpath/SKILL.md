# Интерфейс Korzina в MagicPath

1. Прочитай в корне репозитория `AGENTS.md`, затем `docs/design.md` и запись нужного блока в `docs/progress.md`. Если пользователь просит продолжить разработку и не указал блок, возьми следующий шаг из `docs/plan.md`.
2. Для работы с холстом используй подключённый плагин MagicPath. Целевой проект — «Korzina · Главная», ID `473071804261478400`. Если команда пришла из другого холста, используй его только по указанию пользователя.
3. Сверь выбранный кадр Figma, связанные состояния, пояснения и имеющийся код. Собери или проверь только запрошенный сценарий. Если пользователь просит только показать, сравнить или проверить экран, сначала прочитай имеющуюся ревизию без изменений.
4. Когда принятый компонент нужен в приложении, перенеси его исходники и ресурсы в локальный Git-репозиторий. Проверь сборку и основной сценарий, затем обнови запись блока с результатом, ссылками и ограничениями.

Если плагин недоступен в новом чате, сообщи об этом и продолжи ту часть работы, которая возможна в репозитории.
