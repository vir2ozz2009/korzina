# Навыки Korzina

`korzina-demo-recheck` — пилот точечной перепроверки дефекта, не первичная приёмка. Процедура ссылается на актуальные WORKFLOW/TESTING; навык не расширяет полномочия.

Codex с checkout обнаруживает `.agents/skills` в поддерживаемой версии клиента. Персональная версия для Work сохраняется отдельно; после изменения сверить её текст с этой копией. Не устанавливать две одноимённые версии в одном клиенте: выбирать персональную или репозиторную. Наличие файла не доказывает обнаружение на Mac/в облачной сессии — проверить список доступных навыков там. До подтверждения использовать [маршрут](../../docs/context/recheck.md) напрямую.

Положительные запросы: «Перепроверь исправление D7 на demo по передаче», «Проверь дефект в Safari и Telegram на указанной сборке». Отрицательные: «Напиши спецификацию скидок», «Реализуй новый экран», «Прими весь блок», «Проверь другой проект».

Формат frontmatter для дешёвой проверки CI: только `name` и `description`, по одной строке; строки — plain YAML без двоеточия с пробелом/комментариев либо JSON-quoted. Сложные YAML-конструкции не поддерживаются. Код внутри scripts не считается документацией.
