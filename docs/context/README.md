# Чтение по задаче и этапу

AGENTS → строка ID в [PROGRESS](../PROGRESS.md) → актуальная карточка/передача → один маршрут ниже. Если ID неизвестен, посмотреть очередь. PLAN и истории — только строки задачи; архив — по конкретному пробелу. Вложенный AGENTS зависит от рабочей папки, не темы.

## Общие зависимости этапа

| Работа | Минимальный маршрут |
|---|---|
| Новая функция / спецификация / холст | [Подготовка](preparation.md); реализация после согласования — [код](implementation.md) |
| Подтверждённый дефект | [Исправление](defect.md) |
| Текст, цвет, отступ без новой логики | [Визуальная правка](visual.md) |
| Документация / отчёт / передача | [Документы](documentation.md) |
| Физическая проверка demo | [Проверка](recheck.md): первичная приёмка и перепроверка имеют разный объём |

## Когда расширить карту

Деньги → расчёт, заказ, оплаченные доли, снимок и возврат. Права → отзыв и чужой магазин/сессия. Команда → повтор, версия, гонка. Новые данные → слияние профилей/гостя, копирование, выход и удаление. Открыть нужные DOMAIN, контракты, потребителей и тесты даже вне карты. Платное → COSTS; новая функция → NEW_FEATURE; Lavka — только разрешённая ссылка. Новое поведение/конфликт требований → Work, не догадка.

## Как открыть раздел

Найти заголовок/символ через `rg`, читать нужный диапазон. Не перечитывать неизменённое. При усечении дочитать недостающее. Подробности при необходимости: [адресное чтение](reading.md).

## Поддержание контекста

В затронутом PR сохранить один источник правила, обновить зависимые ссылки/карту; не копировать статусы и не переносить PASS на другой SHA. [Подробные правила](maintenance.md) — при изменении организации документов. [Шаблоны заданий](prompts.md) — для новой передачи. Системные инструкции сервиса не управляются этими файлами.
