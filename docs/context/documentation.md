# Документы и передача

Читать затронутый документ/раздел и его прямые входящие ссылки. Карточка задаёт объём; действующее поведение — спецификация, инварианты — DOMAIN, процедуры — WORKFLOW/TESTING. Историю решения сохранять ссылкой, отменённое правило убрать из действующей нормы. Для продуктового решения применить [подготовку](preparation.md).

Для docs-only не запускать runtime. Проверить diff, затронутые ссылки/якоря и сохранность требований; зелёный Check не доказывает отсутствие смысловых противоречий. Изменение scripts/CI — отдельная карточка и проверка исполняемого поведения.

Завершение: [WORKFLOW](../WORKFLOW.md#как-заканчивать-чат) и [шаблон отчёта](../WORKFLOW.md#шаблон-отчёта). Обновлять только строку своей задачи в PROGRESS, подробности — одна существующая передача. Статус истории «сделано» — после проверки всех критериев на demo. Физические проверки и приёмку не заменять документальной готовностью. Следующий этап/исполнитель — [таблица переходов](../specs/README.md#что-предложить-андрею-в-конце-итерации).
