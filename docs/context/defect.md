# Подтверждённый дефект

Актуальная передача: воспроизведение, ожидаемое принятое правило, затронутые сценарии и разрешённый СТОП → [короткий цикл](../WORKFLOW.md#короткий-цикл-исправления) → [реализация](implementation.md), только применимые строки.

Для восстановления принятого поведения не повторять полную спецификацию и холст. Найти нужный пункт и зависимости. Новое продуктовое поведение вернуть в Work. Регрессия до/после — TESTING §8; локально адресный повтор, полный Check в CI на итоговом SHA. Видимое изменение требует preview и снимки по §7. Разрешённый цикл включает demo, если нет более раннего явного СТОПа; prod исключён.

После выпуска передать точный SHA и только дефект/затронутые зависимости. Остаток полного блока не присоединять. Физическая перепроверка — [отдельный маршрут](recheck.md).
