# Физическая проверка demo

Актуальная передача с выпущенным SHA, средой и CI/smoke → согласованные сценарии и нужные фикстуры. TESTING §5, §8 и [стандарт блока: шаги 7–8](../specs/README.md#стандартный-порядок-блока-решение-андрея-18112026-эталон--блок-2-покупка). Work до передачи сверяет покрытие: первичное — полностью, исправление — только изменение покрытия.

Первичная приёмка: весь согласованный чек-лист и таблица покрытия. Перепроверка: только дефект и непосредственные зависимости по [короткому циклу](../WORKFLOW.md#короткий-цикл-исправления); старые отчёты/спецификации — лишь для конкретного пробела. Карта/карточка — если передаче не хватает границ.

Локальный Codex использует физический iPhone через Mirroring, Safari/Telegram по заданию. Недоступное отметить ⏸ и продолжить независимое; API-подготовка не является UI-доказательством. Сохранять приватно исходное состояние своих фикстур и восстанавливать после прогона. Не объявлять PASS целевого SHA без его подтверждения; эмуляцию учитывать отдельно. Итог — [одна передача](documentation.md); принимает Андрей.
