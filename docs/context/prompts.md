# Короткие задания

Использовать при подготовке передачи, не читать на каждом старте. Если поля уже есть в карточке, достаточно ID, ссылки и изменённых условий.

```text
Задача: <ID и цель>.
Источник: <одна актуальная карточка/передача>.
Границы: <что изменить и сохранить>.
Разрешённый результат: <например, исправление + CI + demo>.
Готово: <проверяемый результат и доказательство>.
СТОП: <конкретная граница>.
```

Исследование: вопрос, источники, анализ или правки, критерий достаточности. Ревью: base/head и конкретные риски. Перепроверка: SHA, среда, сценарии и остаток. Требовать доказательства результата, не раскрытие внутреннего мышления. Мышление выбирать по сложности; несколько агентов не обязательны и не гарантируют экономию.

Полномочия и СТОП не выводить из слова «готово». Уже разрешённые действия повторно не согласовывать; новое продуктовое решение — Work. Обязательные поля передачи — [WORKFLOW](../WORKFLOW.md#шаблон-отчёта).
