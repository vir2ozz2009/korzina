## Работа из репозитория

1. Открой `korzina` в Codex и используй подключённые Figma и MagicPath в этом чате. Выбери блок по плану. Достаточно ссылки на точный кадр, его состояния и примечания. Переносить весь файл Figma в холст заранее не требуется.
2. Свяжи состояния в один React-сценарий. Например, кадры томатов с 0, 1 и 2 единицами становятся переключениями одной карточки, избранное и подробности живут в том же тесте. Если экран отсутствует, используй айдентику и соседние макеты. Пометь предложенные состояния и укажи, какие правила ждут уточнения. «Отбраковка» была отдельным тестом скорости и попадёт в продукт только при подтверждении сценария.
3. Собери или обнови компонент в указанном проекте MagicPath. Проверь внешний вид на целевом экране и прокликай сценарий. При доработке из репозитория передавай в MagicPath только нужный интерфейс и демонстрационные данные.
4. Перенеси принятую ревизию в репозиторий через контекст исходников или план установки компонента MagicPath. Сохрани нужные ресурсы локально, адаптируй компонент к общим стилям, навигации и контракту API. В сборке MagicPath используй явные пути к изображениям и иконкам, чтобы загрузчик смог их обработать.
5. Обнови запись в прогрессе и сохрани изменения в Git. Для дальнейших правок ориентируйся на исходник репозитория и принятые сценарии. Изменения между холстом и Git переносит Codex. Автоматическая двусторонняя синхронизация для этого проекта не настроена.

Figma задаёт вид и содержит сценарии. Репозиторий хранит код и принятые решения. MagicPath служит площадкой для интерактивного прототипа и проверки интерфейса. Конфликты логики покупателя и продавца сверяем по источникам и разрешаем в общей модели, затем отражаем одинаковое решение во всех интерфейсах.
