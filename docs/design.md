Рабочий проект MagicPath — **«Платформа корзины»**, ID `473127254868766720`. Код пишет Codex через плагин; собственная генерация MagicPath не используется.

Способ сборки страниц, компонентов, переходов и мобильных взаимодействий Codex выбирает по Figma без старых регламентов переноса. Недостающие экраны и состояния продолжает в стиле магазина. Серверные правила и критерии результата — в AGENTS.md и плане.

Макеты берём по мере работы. Код и ресурсы выбранной ревизии Codex переносит в репозиторий, подключает к общим API и проверяет работающий сценарий. Автоматическая двусторонняя синхронизация не настроена.
