# A15 · Маленькая витрина

Блок 24 · [План](../PLAN.md) · [История US-A15](../stories/later.md).

- **Figma:** [57](https://www.figma.com/design/Y8MsoSYwEr373vVvlvXAGJ/?node-id=620-49321)
- **Холст:** нужен. Вид и переходы согласуются в составе блока 24.
- **Входит:** Маленькая витрина; поиск с внешним ИИ (если решим подключать).
- **Нажимается:** Открыть витрину магазина с 1–5 товарами → выбрать фасовку → добавить товар → перейти к существующей корзине.
- **Не входит и границы:** Внешний ИИ-поиск — только по отдельному решению Андрея.
- **Данные (API):** Использовать каталог магазина и общую корзину; условия выбора вида закрепить в спецификации.
- **Состояния:** Один товар, пять товаров, нет доступных фасовок, ассортимент вырос.
- **Готово, когда:** Проверить на одном и пяти товарах выбор фасовки, количество и итог корзины. На границе с обычным каталогом позиции корзины сохраняются.
