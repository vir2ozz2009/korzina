# F8 · Каркас приложения, шаблоны и переходы
- **Цель:** TanStack Router, оболочки витрины и кабинета, 8 шаблонов экранов, `Screen`/`Header`/`QueryBoundary`/`SheetRoute`/`Transition` (push, sheet, tab), адаптер Telegram (viewport, safe-area, BackButton, тема, раскрытие на всю высоту), тосты, восстановление прокрутки, десктоп — колонка по центру.
- **Скелетоны:** если в ките F7 нет примитивов `SkeletonText`, `SkeletonBlock`, `SkeletonTile`, `SkeletonRow` (`components.md`) — добавить их здесь; временную текстовую заглушку «Загружаем палитру…» в `src/app/App.tsx` заменить скелетоном шаблона.
- **Также:** `src/app/query-defaults.ts` — `staleTime` по типам данных, объединение запросов, точечная инвалидация, остановка опросов в скрытой вкладке (PERFORMANCE §3); разделение кода по маршрутам (витрина / кабинет / админка).
- **Читать:** PERFORMANCE §3, DESIGN §3–4, `design-system/templates.md`, `design-system/reference-screens.md`, «Оболочки» в `design-system/navigation.md`, CONVENTIONS «Экраны».
- **Готово, когда:** восемь шаблонов на демо-данных и три демо-маршрута показывают все виды переходов; загрузка кода и данных показывает скелетон шаблона по правилам `templates.md` («Загрузка без «бац»»): без текстовых заглушек, без прыжков вёрстки, без мигания на быстрых ответах; переход по ссылке с предзагрузкой открывается без скелетона; «назад» работает жестом, кнопкой браузера и BackButton в Telegram; состояния загрузки, пусто и ошибки демонстрируются на флаге `?simulate=`.
