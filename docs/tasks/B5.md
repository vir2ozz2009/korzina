# B5 · Поиск — **48**
- **Figma:** 48 (`404:28201`) — в этой задаче: `initial`, `history-cleared`, `focus`, `typing`, `results`, `tomato1`, `tomato2`, `weight1000*`, `milk*`, `typo`, `vegetables`, `brand`, `filtered`, `filters-zero`, `filters*`, `sort`, «Сначала дешевле», «… · сохранение текущего запроса», «Результат · фасовка …», «Запрос очищен · корзина …», «Корзина из поиска / …», `no-results`, `loading`, `error`, `offline`, `empty-store`, `unsupported`, `soldout`; в B5b: `dish*`, `list*`, `limit-text`, `limit-items`, `weight-missing`.
- **Истории:** C06.
- **Входит:** **один вход — кнопка «Нейропоиск» слева внизу** (на месте плавающей «Поиск»; отдельного поля поиска на главной нет); экран поиска: поле с автофокусом, поиск по мере ввода (от 2 символов, пауза 250 мс), по названию, бренду, категории и описанию опубликованных товаров без учёта регистра и «ё/е»; название, бренд и тип важнее случайного слова в описании; **опечатки** — исходный запрос сохраняется, показываются похожие товары, исправление текста только по нажатию; явный вес в запросе («томаты 1кг») выбирает эту фасовку; результаты — те же плитки с фасовками и «+»; **фильтры и сортировка — из B3b** для текущей выдачи (по умолчанию «По релевантности»); история до 8 запросов магазина на устройстве — запись после подтверждения или перехода, не на каждом символе («Очистить»); пока печатают, плавающая корзина скрыта, клавиатура не закрывается. Сервер — FTS5 в Shop DO, обновляется при изменении каталога; бюджет SQL — тест. Внешнего ИИ нет — это локальный поиск по правилам (подпись в 48).
- **Нажимается:** «Нейропоиск» → экран поиска (`push`); запрос из истории → поиск; «Очистить» → история пуста; подсказка исправления → поиск по исправленному; «Фильтры», «Сортировка» → шторки B3b; плитка и «+» — как на главной; «×» → очистить поле (товары в корзине не меняются).
- **Не входит:** список покупок и поиск по блюду (B5b); поиск с внешним ИИ.
- **Состояния:** по кадрам 48: пустое поле — история; `no-results` — «Попробуйте другое название, бренд или категорию»; `filters-zero` — «Измените цену или сбросьте фильтры»; `offline` — сохранённая выдача «Цена и наличие уточнятся при добавлении»; `empty-store`; `error` — «Попробуйте ещё раз. Ваш запрос сохранён»; поздний ответ старого запроса не показывается.
- **Готово, когда:** тесты поиска (регистр, «ё», опечатка «молко», бренд, категория, скрытые не находятся, «томаты 1кг» → фасовка 1 кг); запрос короче 2 символов не уходит на сервер; smoke: поиск → фильтр → плитка → назад сохраняет запрос, фильтр, фасовку и прокрутку; товар в корзину → «×» в поле → плавающая «Корзина» с суммой видна; «назад» — кнопка не мигает.
