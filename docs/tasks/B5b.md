# B5b · Список покупок и поиск по блюду — **48**
- **Figma:** 48 — `list`, `list-found`, `list-added-milk`, `list-added`, `dish`, `dish-added`, `limit-text`, `limit-items`, `weight-missing`.
- **Входит:** в том же поле — список через запятую или с новой строки («молоко, хлеб, томаты»): каждая позиция ищется отдельно, найденные показаны группами, внутри группы — та же сетка плиток по 2 в ряд, что везде (Figma 48: «единые карточки»), неразобранные — отдельно; ничего не добавляется само, количество и фасовку покупатель подтверждает «+»; пределы 4000 символов и 40 позиций — понятная ошибка, текст не обрезается. Поиск по блюду («греческий салат») — общий словарь блюд для всех магазинов (файл в `src/shared`), показываются только подходящие опубликованные товары, без обещания полного набора, состава и диет. Поле до 3 строк.
- **Состояния:** `limit-text`, `limit-items`, `weight-missing` (вес не указан — фасовку выбирает покупатель).
- **Готово, когда:** тесты разбора списка (запятые, переносы, 41 позиция → ошибка), блюдо «греческий салат» находит томаты и огурцы магазина и не подмешивает лишнее.
