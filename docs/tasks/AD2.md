# AD2 · Карточка магазина, статусы, дополнения
- **Холст:** нужен (вместе с AD1).
- **Цель:** карточка магазина (US-AD04), смена статуса с последствиями для витрины и заказов (US-AD05), флаги магазина из реестра F5 (US-AD06), повторное приглашение.
- **Готово, когда:** приостановленный магазин не принимает новые заказы, но кабинет и текущие заказы работают; архив закрывает витрину и кабинет без потери данных; флаг включается одному магазину; всё пишется в журнал.
