# O5 · Деньги: оплаты, доплаты, возвраты — **39/40 (сторона продавца), 68**
- **Холст:** нужен.
- **Figma (справочник Claude):** 68 (`886:58722`): «Обзор · сегодня», «Выбор периода», «Свой период», «К получению · все открытые задачи», «Переводы на проверке», «Ожидается доплата», «К возврату · реквизиты и частичный возврат», «Операции · поступления / возвраты», «Задача уже закрыта», «Доступ ограничен»; финал «53 · Доплата и частичный возврат» (`1502:123085`).
- **Входит (68):** раздел «Деньги»: обзор за период (по умолчанию сегодня, время магазина; свой период с проверкой дат) — «Получено», «Возвращено», «К получению сейчас»; финансовые задачи — «Переводы на проверке», «Ожидается доплата», «К возврату» (с реквизитами и частичным возвратом), открытые задачи видны независимо от периода; операции — поступления и возвраты с подгрузкой; переход из задачи и операции в карточку заказа к разделу оплаты. Подтверждение перевода, фактического получения и возврата — в карточке заказа, с правом на деньги.
- **Замена чека покупателем** (решение 18.11.2026): в «Переводы на проверке» виден последний файл и история замен; подтверждение относится к последнему файлу.
- **Решения 24.11.2026** — исправления и полнота истории, разбивка возврата и «Открыть возврат» по выполненному заказу с правом на деньги. [Спецификация §10](../specs/money-and-sales.md#10-ответы-андрея-от-24112026).
- **Не входит:** статистика продаж (O9).
- **Состояния:** по кадрам 68: загрузка без нулей, «Операций нет», «Финансовых задач нет», «Задача уже закрыта» (параллельное действие), «Доступ ограничен» (суммы скрыты на сервере).
- **Готово, когда:** выполняется T05; пример 68: 239 + 189 = 428 к получению, возвраты 69 + 239 = 308; оплата курьеру напрямую не входит в суммы; двойное подтверждение не зачисляет дважды.
