# A10 · Добавление товаров к активному заказу

Блок 22 · [План](../PLAN.md) · [История US-A10](../stories/later.md).

- **Figma:** [54](https://www.figma.com/design/Y8MsoSYwEr373vVvlvXAGJ/?node-id=553-41667)
- **Холст:** нужен. Вид и переходы согласуются в составе блока 22.
- **Входит:** Добавление к активному заказу.
- **Нажимается:** Из корзины выбрать доступный активный заказ → посмотреть изменения состава и суммы → подтвердить → открыть обновлённый заказ у обеих ролей.
- **Не входит и границы:** Заявка на изготовление A8; новые платёжные механики вне задачи.
- **Данные (API):** Допустимость дополнения, версия заказа, доступный остаток, разница сумм и состояние оплаты через существующий расчёт.
- **Состояния:** Нет подходящего заказа, заказ изменился, остаток закончился, нужна доплата.
- **Готово, когда:** Повтор подтверждения не удваивает позиции. При смене статуса между просмотром и подтверждением сервер повторно проверяет допустимость; при отказе сохраняет корзину.
