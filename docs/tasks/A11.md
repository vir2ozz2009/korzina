# A11 · Набор по специальной цене

Подблок 12.2 · [План](../PLAN.md) · [История US-A11](../stories/later.md).

[Спецификация 12.2 и нумерованные сценарии](../specs/promo-quantity-and-bundles.md).

- **Figma:** [59](https://www.figma.com/design/Y8MsoSYwEr373vVvlvXAGJ/?node-id=1157-72304), [93](https://www.figma.com/design/Y8MsoSYwEr373vVvlvXAGJ/?node-id=1157-70836)
- **Холст:** нужен. Вид и переходы согласуются на общем холсте подблока 12.2.
- **Входит:** Акционный набор. [Правила продвижения](../stories/promo.md), §1, 4–6.
- **Нажимается:** Выбрать фасовки и количество каждой, задать цену и способ применения (автоматически по умолчанию или по промокоду) → опубликовать → собрать набор в корзине и в режиме по коду применить код → изменить состав.
- **Не входит и границы:** Механика бесплатных единиц — A1b. Исходные 59/93 на согласовании.
- **Данные (API):** Состав набора по идентификаторам фасовок, цена, способ применения, код для режима по промокоду, совпавшие количества и распределение скидки.
- **Состояния:** Полный комплект, недостающая фасовка, неверный код, предложение отключено.
- **Готово, когда:** Проверить комплект и корзину с тем же общим количеством, но другой фасовкой; после удаления обязательной позиции сумма пересчитана, причина видна.

Для обоих способов продавец задаёт, сколько полных наборов получат скидку: 1 по умолчанию, своё число или без ограничений. В составе сначала выбирают товар, затем только его фасовку. Покупатель видит конечный лимит рядом с ценой набора до добавления, а в корзине — число наборов со скидкой и экономию. См. проверки §7 №9–11 спецификации. Остальные единицы сохраняют подходящие автоматические акции. Для частичного возврата берётся оплаченная доля из снимка.

Удаление отсутствующей позиции магазином после оформления сохраняет оплаченную долю остальных строк набора. Замена и цена согласуются по O6.

В подборе для увеличения суммы заказа и в прямом выборе доступно одно и то же комбо. Карточка предложения показывает число проданных комплектов и фактическую скидку по [спецификации результата](../specs/promo-discounts.md#11-результаты-предложения).
