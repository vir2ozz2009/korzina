# A11 · Набор по специальной цене

Подблок 12.2 · [План](../PLAN.md) · [История US-A11](../stories/later.md).

[Спецификация 12.2 и нумерованные сценарии](../specs/promo-quantity-and-bundles.md).

- **Figma:** [59](https://www.figma.com/design/Y8MsoSYwEr373vVvlvXAGJ/?node-id=1157-72304), [93](https://www.figma.com/design/Y8MsoSYwEr373vVvlvXAGJ/?node-id=1157-70836)
- **Холст:** нужен. Вид и переходы согласуются на общем холсте подблока 12.2.
- **Входит:** Акционный набор. [Правила продвижения](../stories/promo.md), §1, 4–6.
- **Нажимается:** Выбрать фасовки и количество каждой, задать цену набора → опубликовать → ввести код набора в корзине → изменить состав.
- **Не входит и границы:** Механика бесплатных единиц — A1b. Исходные 59/93 на согласовании.
- **Данные (API):** Состав набора по идентификаторам фасовок, цена, код, совпавшие количества и распределение скидки.
- **Состояния:** Полный комплект, недостающая фасовка, неверный код, предложение отключено.
- **Готово, когда:** Проверить комплект и корзину с тем же общим количеством, но другой фасовкой; после удаления обязательной позиции сумма пересчитана, причина видна.

Один код даёт цену одного комплекта на заказ. Остальные единицы сохраняют подходящие автоматические акции. Для частичного возврата берётся оплаченная доля из снимка.

Удаление отсутствующей позиции магазином после оформления сохраняет оплаченную долю остальных строк набора. Замена и цена согласуются по O6.
