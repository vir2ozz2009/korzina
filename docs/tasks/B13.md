# B13 · Профиль покупателя — **44**

- **Figma (справочник Claude):** 44 (`283:18751`): `profile`, `profile-phone`, `profile-empty`, `profile-disabled`, `guest`, `login-wait`, `login-error`, `login-phone*`, `link-wait`, `link-conflict`, `data`, `data-phone`, `name-*`, `contact-*`, `addresses*`, `address-*`, `logout-confirm`, `logout-error`. Кадры `wallet*`, `cashback*`, `withdraw*` (A4), `offers*` (A1), `favorite-*` (A5), «Уведомления об акциях» (A12), `reviews*` (A2) — не делать.
- **Истории:** вход и профиль — K03 (B9), заказы — Z02 (B11), избранное — C07 (B12).
- **Холст:** нужен — экраны новые.
- **Входит:**
  - **Профиль:**
    - аватар или инициалы, имя;
    - как вошёл: «Telegram подключён» или номер телефона;
    - пункты «Мои заказы» (B11), «Избранное» (B12), «Мои данные», «Мои адреса», «Выйти».
  - **Гость** — «Войти» → шторка входа B9 («Войти через Telegram», ссылка «У меня нет Telegram» → номер без СМС).
  - **Профиль по номеру** работает только на этом устройстве (решение 18.11.2026). Пометка «Вошли по номеру на этом устройстве» и «Подключить Telegram» — чтобы видеть историю везде.
  - **Привязка Telegram** к профилю по номеру: ожидание; «Этот Telegram уже привязан к другому профилю» (`link-conflict`).
  - **«Мои данные»** — имя и контакт: проверка, «Сохранено», ошибка сохранения.
  - **«Мои адреса»:**
    - список: «Дом», «Работа», свои;
    - добавить — тот же выбор адреса, что в корзине, со всеми режимами: карта, районы, адрес текстом, свой адрес без точки;
    - изменить, удалить с подтверждением;
    - лимит адресов;
    - эти адреса показываются в шторке адреса корзины, по умолчанию подставляется последний использованный (D19).
  - **«Выйти»** — подтверждение; сессия устройства очищается, корзина и избранное гостя остаются на устройстве.
  - Вход в профиль — кнопка профиля в шапке главной (`push`).
- **Нажимается:**
  - профиль в шапке → профиль;
  - «Войти» → шторка B9;
  - пункты → свои экраны (`push`);
  - адрес → карточка адреса;
  - «Добавить адрес» → выбор адреса;
  - «Удалить» → подтверждение;
  - «Подключить Telegram» → вход Telegram;
  - «Выйти» → подтверждение → гость.
- **Не входит (не рисовать):**
  - кошелёк, кэшбэк, вывод средств (A4);
  - «Акции и промокоды» (A1);
  - «Любимый товар» (A5);
  - «Отзывы» (A2);
  - «Уведомления об акциях» (A12);
  - приглашения (A9);
  - регулярные заказы (A7);
  - вход по email, SMS, VK, Яндекс (A17);
  - десктоп (A16).
- **Отличия от Figma:** вход по номеру без СМС и профиль только на устройстве — решение 18.11.2026 (в Figma номер — полноценный аккаунт).
- **Данные (API):**
  - `GET` профиля (компактно);
  - команды «изменить имя», «изменить контакт»;
  - адреса: список, добавить, изменить, удалить — с ревизией;
  - «привязать Telegram»;
  - «выйти»;
  - ошибки: `VALIDATION`, `ADDRESS_LIMIT`, `LINK_CONFLICT`, `VERSION_CONFLICT`.
- **Состояния:**
  - загрузка;
  - ошибка;
  - пустой профиль (нет имени);
  - нет адресов;
  - лимит адресов;
  - ошибка сохранения;
  - конфликт привязки;
  - ошибка выхода.
- **Готово, когда:**
  - чужие данные и адреса недоступны (тест);
  - профиль по номеру не открывается с другого устройства тем же номером (тест);
  - выход очищает сессию на устройстве;
  - адрес из профиля появляется в шторке адреса корзины, а последний использованный подставляется по умолчанию (тест вместе с B7).
