# B13 · Профиль покупателя (основа) — **44**
- **Figma:** 44 (`283:18751`): `profile`, `profile-no-avatar`, `profile-phone-linked`, `guest`, `login-starting`, `login-wait`, `login-error`, `login-expired`, `link-wait`, `link-conflict`, `data*`, `name-*`, `contact-*`, `addresses*`, `address-*`, `logout-*`, `loading`, `error`.
- **Входит:** экран профиля (аватар или инициалы, имя, Telegram или телефон); гость — «Войти» (вход через Telegram из B9) и состояния входа и привязки; **«Мои данные»** — изменить имя и контакт (проверка, ошибка сохранения, «Сохранено»); **«Мои адреса»** — список, добавить (выбор адреса и зоны из B7), изменить, удалить с подтверждением, лимит адресов; пункты «Мои заказы» (B11) и «Избранное» (B12); «Выйти» с подтверждением. Аватар в шапке главной ведёт сюда.
- **Нажимается:** аватар на главной → профиль (`push`); «Войти» → вход через Telegram; «Мои данные», «Мои адреса», «Мои заказы», «Избранное» → свои экраны (`push`); адрес → карточка адреса; «Добавить адрес» → выбор адреса; «Удалить» → подтверждение; «Выйти» → подтверждение → гость.
- **Дополнено по сверке Figma 44 (18.11.2026):** вход по номеру без СМС — MVP (решение 18.11.2026, B9): состояния `login-phone`, `login-phone-valid`, `login-phone-error`, `profile-phone`, `data-phone`, `contact-*-phone`; профиль по номеру — только на этом устройстве. **«Мои адреса»** (дом, работа, свои; лимит) — выбираются в шторке адреса корзины, по умолчанию подставляется последний использованный (решение 18.11.2026, спецификация покупки §3.2).
- **Не входит (не рисовать):** вход по email, SMS (A17); «Акции и промокоды» (A1), «Кошелёк», «Кэшбэк», «Вывод средств» (A4), «Любимый товар» (A5), «Отзывы» (A2), «Уведомления об акциях» (A12) — пункты профиля появятся вместе со своими блоками.
- **Состояния:** по кадрам 44: `loading`, `error`, `profile-empty`, `addresses-empty`, `address-limit`, `logout-error`, `link-conflict` (Telegram уже привязан к другому аккаунту).
- **Готово, когда:** тесты прав: чужие данные и адреса недоступны; гость не видит профиль, только «Войти»; выход очищает сессию на устройстве; адреса из профиля доступны при оформлении (B10).
