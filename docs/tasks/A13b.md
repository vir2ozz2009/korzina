# A13b · Покупатели и история покупок

Подблок 13.1 · [Карта](../blocks/13.1.md) · US-A13b в [later](../stories/later.md).
**Карточка одобрена Андреем 28.11.2026.** Спецификация v1 с Q1–Q4 и коротким локальным планом одобрена 28.11.2026. Следующий этап — холст по передаче в карте; реализация ещё не разрешена.

- **Актуальные правки холста:** [спецификация v2 §16](../specs/customer-offers.md#16-правки-после-просмотра-холста--v2) имеет приоритет над прежним составом формы/размещением/компоновкой ниже; правила денег и прав сохраняются.
- **Источники и контекст:** [исследование](../research/customer-offers.md); [спецификация](../specs/customer-offers.md) §1–2, §6–9. Правила подробно определены там; не придумывать отсутствующие решения.
- **Figma:** 67, узел 871:58638 в файле [Korzina](https://www.figma.com/design/Y8MsoSYwEr373vVvlvXAGJ/?node-id=871-58638). Объём визуальной сверки и отличия перечислены в исследовании; полной сверкой всех кадров не объявлено.
- **Холст:** общий 13.1, после одобрения спецификации; все новые и затронутые состояния 360/390 px.
- **Входит:** Автоматический список по заказам магазина; поиск имени/телефона; карточка с контактами, сводкой O9 и последними заказами; полная история и переходы в существующий заказ/чат; права и безопасное слияние гостя.
- **Нажимается:** Главная → покупатели → поиск → карточка; имя в заказе → карточка → назад; имя/аватар заказа → профиль, Telegram @username в обоих местах; копировать телефон; история и фильтр «В работе»; выбрать заказ для переписки.
- **Не входит:** Выдача предложений — A12; теги, заметки, ручное создание/слияние, импорт, CRM-фильтры и будущая лояльность не входят.
- **Отличия от справочника:** текущий каркас main; история сразу в карточке, выдача одной шторкой вместо обязательного отдельного экрана проверки. Состав карточки одобрен; макет ещё не создан.
- **Данные/API:** серверная личность и магазин; контракт до UI. Операции, поля, ревизии, права, инвалидация и ошибки — спецификация §§6–7, 13–14; экраны/процессы §§11–12.
- **Состояния:** загрузка, пусто, нет совпадений/телефона/выполнений, нет доступа, нет сети, частичная ошибка, изменившиеся данные; для A12 дополнительно гость, несовместимость, чужое/истёкшее/исчерпанное/отозванное предложение, результат уведомления неизвестен. Полный набор — спецификация §§12.1, 14.
- **Готово, когда:** C01–C06 и применимая часть C15–C16 в спецификации покрыты с указанием среды и доказательств. Новые денежные/идентификационные правила не заменяются снимками.
- **Разрешённый результат / СТОП:** сейчас — холст по одобренной спецификации v1 → отдельное одобрение его точной ревизии Андреем. Реализация после одобрения холста; физический план L1–L3 не расширять.
