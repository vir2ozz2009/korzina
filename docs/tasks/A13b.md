# A13b · Покупатели и история покупок

Подблок 13.1 · [План](../PLAN.md) · [История US-A13b](../stories/later.md).

- **Figma:** [67](https://www.figma.com/design/Y8MsoSYwEr373vVvlvXAGJ/?node-id=871-58638)
- **Холст:** нужен. Вид и переходы согласуются на общем холсте подблока 13.1.
- **Входит:** Покупатели: список, поиск по имени и телефону, карточка (заказы, сумма покупок, средний чек, последняя покупка), история заказов, переход в чат.
- **Нажимается:** Найти покупателя по имени или телефону → открыть карточку → посмотреть сумму покупок, средний чек, последнюю покупку и историю → перейти в связанный чат.
- **Не входит и границы:** Создание скидки в карточке покупателя — следующая задача A12.
- **Данные (API):** Список и поиск в границах магазина, сводка покупателя, выборка его заказов и разрешённая ссылка на чат.
- **Состояния:** Пустой список, совпадений нет, нет доступа, история загружается.
- **Готово, когда:** Сверить историю и показатели с заказами тестового покупателя; проверить поиск по телефону и попытку открыть карточку другого магазина.
