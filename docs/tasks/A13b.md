# A13b · Покупатели и история покупок

Подблок 13.1 · [Карта](../blocks/13.1.md) · US-A13b в [later](../stories/later.md).
**Редакция Work 28.11.2026: проект на одобрение Андрея.** Входит в единое согласование подблока, не разрешает код.

- **Источники и контекст:** [исследование](../research/customer-offers.md); [проект правил](../specs/customer-offers.md) §1–2, §6–9. Правила подробно определены там; не придумывать отсутствующие решения.
- **Figma:** 67, узел 871:58638 в файле [Korzina](https://www.figma.com/design/Y8MsoSYwEr373vVvlvXAGJ/?node-id=871-58638). Объём визуальной сверки и отличия перечислены в исследовании; полной сверкой всех кадров не объявлено.
- **Холст:** общий 13.1, после одобрения спецификации; все новые и затронутые состояния 360/390 px.
- **Входит:** Автоматический список по заказам магазина; поиск имени/телефона; карточка с контактами, сводкой O9 и последними заказами; полная история и переходы в существующий заказ/чат; права и безопасное слияние гостя.
- **Нажимается:** Главная → покупатели → поиск → карточка; имя в заказе → карточка → назад; копировать телефон; история и фильтр «В работе»; выбрать заказ для переписки.
- **Не входит:** Выдача предложений — A12; теги, заметки, ручное создание/слияние, импорт, CRM-фильтры и будущая лояльность не входят.
- **Отличия от справочника:** текущий каркас main; история сразу в карточке, выдача одной шторкой вместо обязательного отдельного экрана проверки. Это предложение на одобрение, не уже принятый макет.
- **Данные/API:** серверная личность и магазин; контракт до UI. Нужные запросы/команды, ревизии, права, инвалидация — проект §6–7; точные схемы фиксируются на этапе спецификации.
- **Состояния:** загрузка, пусто, нет совпадений/телефона/выполнений, нет доступа, нет сети, частичная ошибка, изменившиеся данные; для A12 дополнительно гость, несовместимость, чужое/истёкшее/исчерпанное/отозванное предложение, результат уведомления неизвестен. Полный набор — проект правил.
- **Готово, когда:** C01–C06 и применимая часть C15–C16 в проекте правил покрыты с указанием среды и доказательств. Новые денежные/идентификационные правила не заменяются снимками.
- **Разрешённый результат / СТОП:** сейчас — исследование и карточки → одобрение Андрея в Work. Затем точная спецификация → её одобрение → холст → его одобрение. Реализация только после этих решений.
