# S6 · Данные магазина, регион, время, оформление — **69, 88 (только цвет), финал «34 · О магазине»**

- **Figma (справочник Claude):** 69 (`903:58995`); финал «34» (`1380:71016`): «Данные магазина», «Загрузка логотипа», «Широкий логотип», «Файл не принят», «Удаление логотипа», «Витрина с широким логотипом / без логотипа», «Обязательное название», «Контакты магазина», «Ошибка формата», «Контакты на витрине», «Регион, валюта и время», «Выбрать страну», «Выбрать валюту до запуска», «Валюта закреплена», «Выбрать часовой пояс», «Автоопределению нужна точка», «Один заказ в двух часовых поясах», «Проверить зависимые настройки», «Изменения другого сотрудника», «Просмотр без права»; 88 — только цвет витрины.
- **Истории:** M08, M12.
- **Холст:** нужен.
- **Входит:**
  - **Данные:** название (обязательно), логотип (F9; широкий и квадратный; удалить → витрина без логотипа), адрес магазина, контакты — телефон, email, Telegram (необязательны; пустые скрывают «Контакты магазина» на витрине).
  - **Регион:** страна и валюта — только для чтения, меняет админ (решение 2); часовой пояс — по точке магазина или вручную (IANA); «Проверить зависимые настройки» — расписание, интервалы, время на подготовку и отсечка (S4) пересчитываются в новом поясе.
  - **Оформление витрины (в «Ещё → Витрина», решение 1):** пресет или свой цвет (`theme-presets.ts`: `deriveTheme`, `validateCustomColor` на клиенте и сервере) с предпросмотром (`tokens.md` «Оформление магазина»).
  - **Сохранение — простое, как в Shopify и Ecwid** (решение 18.11.2026): при первой правке полоса «Несохранённые изменения · Отменить · Сохранить»; уход с правками — «Выйти без сохранения?»; после сохранения — Toast «Сохранено», изменения сразу на витрине; «Посмотреть на витрине». Изменено с другого устройства — «Данные изменил <кто> в <время>» и «Обновить», введённое не теряется.
- **Решения Андрея 20.11.2026 (сверка карточек блока 7, по образцу Shopify, Square, Uber Eats):**
  1. Место: «Ещё → Настройки» → «Получение заказов» (S4), «Оплата» (S5), «О магазине» (S6). Цвет витрины — в «Ещё → Витрина» (раздел из блока 6), не в «О магазине». Логотип — в «О магазине».
  2. Продавец меняет: название, логотип, адрес, контакты, часовой пояс, цвет. Только админ (Андрей) в админке: страна, валюта, адрес витрины (slug). Валюта закреплена после первого заказа (как в Shopify). У продавца страна и валюта показаны только для чтения с подписью «меняет поддержка».
  3. Пауза приёма заказов — кнопка на «Главной» кабинета (не только в настройках): срок «на 1 час / до конца дня / пока не включу» (конец дня — по поясу магазина), можно отдельно доставку или самовывоз; снятие одним нажатием. Витрина работает, оформить нельзя на приостановленный способ; покупателю «Магазин временно не принимает заказы» (или «Доставка временно недоступна»). Пауза администратора (статус `paused` в админке) — отдельно, продавец её не снимает, в кабинете пометка «Магазин приостановлен администратором». Отпуск — выходные даты в расписании.
  4. AD4 (импорт нейросетью) — отдельный блок 7б после блока 7.
  5. Уровень блока — «Высокое».
- **Нажимается:** поля; «Загрузить логотип» / «Удалить»; страна, валюта, часовой пояс → списки с поиском; пресеты цвета; «Сохранить» / «Отменить»; «Посмотреть на витрине».
- **Не входит (не рисовать):** черновик и публикация витрины, обложки и внешний вид сверх цвета (A14); истории (A3).
- **Отличия от Figma:** без черновика и публикации (в 69 есть) — решение 18.11.2026.
- **Данные (API):** `GET`/`PUT` настроек магазина с ревизией; логотип — F9; валюта меняется, только пока нет операций (`CURRENCY_LOCKED`); ошибки `VALIDATION`, `VERSION_CONFLICT`.
- **Состояния:** загрузка; обязательное название; ошибка формата контакта; логотип не принят; валюта закреплена; автоопределение пояса без точки; конфликт; без права — просмотр.
- **Готово, когда:** валюту нельзя сменить после первой операции (тест); смена пояса меняет показ интервалов покупателю (тест вместе с B8); пустые контакты скрывают блок на витрине; цвет проверяется на сервере тем же `validateCustomColor`.
