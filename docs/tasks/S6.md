# S6 · Данные магазина, регион, время, оформление — **69, 88 (только цвет)**
- Название, логотип, адрес, контакты (телефон и почта необязательны; пустые скрывают «Контакты магазина» на витрине), страна, валюта (фиксация после первой операции), часовой пояс (по точке магазина или вручную, IANA) — правила полей по блоку 69.
- **Сохранение — простое, как в Shopify и Ecwid** (решение Андрея 18.11.2026), без черновика и публикации из макета 69: при первой правке снизу появляется полоса «Несохранённые изменения · Отменить · Сохранить»; уход с экрана с правками — вопрос «Выйти без сохранения?»; после сохранения — Toast «Сохранено», изменения сразу на витрине; «Посмотреть на витрине» открывает витрину. Если данные успели изменить с другого устройства (ревизия), — «Данные изменил <кто> в <время>» и кнопка «Обновить», введённое не теряется. Без права редактирования — только просмотр.
- Оформление витрины: пресет или свой цвет из палитры (`src/shared/theme-presets.ts`: `deriveTheme`, `validateCustomColor` на клиенте и сервере) с предпросмотром (US-M12, `design-system/tokens.md` «Оформление магазина»).
