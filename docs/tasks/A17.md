# A17 · Вход покупателя без Telegram

Блок 25 · [План](../PLAN.md) · [История US-A17](../stories/later.md).

- **Figma:** В плане отдельные исходные группы не назначены.
- **Холст:** нужен. Вид и переходы согласуются в составе блока 25.
- **Входит:** Вход покупателя без Telegram: email-код, SMS, VK ID / Яндекс ID.
- **Нажимается:** Выбрать поддержанный способ входа → подтвердить код email/SMS или войти через VK ID / Яндекс ID → открыть собственную историю на другом устройстве.
- **Не входит и границы:** PWA и браузерные уведомления — A18. Подключение платных каналов требует отдельного решения.
- **Данные (API):** Проверенная идентичность, сессия и привязка аккаунта; правила связывания и стоимость каналов определить до подключения.
- **Состояния:** Неверный или просроченный код, отмена у провайдера, конфликт привязки, уже выполненный вход.
- **Готово, когда:** Проверить вход на втором устройстве и доступ только к своим данным; совпадение неподтверждённого контакта не открывает чужие заказы.
