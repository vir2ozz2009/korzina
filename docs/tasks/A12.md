# A12 · Личные предложения из карточки покупателя

Подблок 13.1 · [Карта](../blocks/13.1.md) · US-A12 в [later](../stories/later.md).
**Редакция Work 28.11.2026: проект на одобрение Андрея.** Входит в единое согласование подблока, не разрешает код.

- **Источники и контекст:** [исследование](../research/customer-offers.md); [проект правил](../specs/customer-offers.md) §1, §3–9. Правила подробно определены там; не придумывать отсутствующие решения.
- **Figma:** 78, узел 1004:61821; связанные 33/44/67/80 в файле [Korzina](https://www.figma.com/design/Y8MsoSYwEr373vVvlvXAGJ/?node-id=1004-61821). Объём визуальной сверки и отличия перечислены в исследовании; полной сверкой всех кадров не объявлено.
- **Холст:** общий 13.1, после одобрения спецификации; все новые и затронутые состояния 360/390 px.
- **Входит:** Личная автоматическая скидка и разовый личный код; цель возвращения как преднастройка; одна шторка выдачи, встроенная сводка и необязательный пример; отзыв/замена/история; предложения в профиле и корзине; серверный расчёт, лимиты, возвраты, права, очередь уведомления.
- **Нажимается:** Дать скидку → значение/условия → выдать; дополнительно — код; посмотреть пример; открыть историю; отозвать; повторить новым предложением; покупатель — использовать код без набора, подтвердить замену прежнего кода.
- **Не входит:** Массовые сообщения — A12b; кэшбэк — A4; любимый товар — A5; личная доставка, N+M/комбо, личная цена позиции, автоматический win-back и CRM не входят.
- **Отличия от справочника:** текущий каркас main; история сразу в карточке, выдача одной шторкой вместо обязательного отдельного экрана проверки. Это предложение на одобрение, не уже принятый макет.
- **Данные/API:** серверная личность и магазин; контракт до UI. Нужные запросы/команды, ревизии, права, инвалидация — проект §6–7; точные схемы фиксируются на этапе спецификации.
- **Состояния:** загрузка, пусто, нет совпадений/телефона/выполнений, нет доступа, нет сети, частичная ошибка, изменившиеся данные; для A12 дополнительно гость, несовместимость, чужое/истёкшее/исчерпанное/отозванное предложение, результат уведомления неизвестен. Полный набор — проект правил.
- **Готово, когда:** C07–C16 и разграничение C02/C06 в проекте правил покрыты с указанием среды и доказательств. Новые денежные/идентификационные правила не заменяются снимками.
- **Разрешённый результат / СТОП:** сейчас — исследование и карточки → одобрение Андрея в Work. Затем точная спецификация → её одобрение → холст → его одобрение. Реализация только после этих решений.
