# O7 · Перенос времени получения — **42, финал «19»**

- **Figma (справочник Claude):** 42 (`255:13715`): `order-current`, `seller-offer`, `counter-*` (встречное предложение покупателя), `confirmed-*`, `day-*` (режим «в течение дня»), `long-*` (длинный интервал), `manual`, `pickup-*`, `buyer-declined`, `buyer-confirmed`, `slot-lost`, `no-slots`, `loading`, `network-error`, `saving`, `unknown-result`, `withdrawn`, `closed`, `original-unavailable`, `other-change-pending`, `timezone-*`, `edit-*` (покупатель сам просит изменить время); финал «19» — «Покупатель подтвердил … / выбрал другой интервал»; финал «16» — «Предложить другое время».
- **Истории:** Z05, R07.
- **Холст:** нужен.
- **Входит:**
  - **Продавец** (карточка заказа O2, «Изменить время»): предложить другой интервал или день — из доступных по расписанию S4, «часовой пояс магазина»; результат виден в заказе и чате.
  - **Покупатель:** «Магазин предлагает другое время» — подтвердить или предложить своё (встречное) из доступного; **сам попросить** перенос из карточки заказа; результат «Время изменено».
  - Предложение можно отозвать; пока оно открыто — старое время в силе; интервал резервируется при подтверждении.
  - Режимы времени — как в B8 (интервалы, в течение дня, длинный интервал, согласование); самовывоз — свои интервалы.
- **Не входит:** изменение состава (O6); чат (O8).
- **Отличия от Figma:** нет.
- **Данные (API):** `proposeTime` (продавец или покупатель) → ось согласования; `answerTime` (принять, встречное, отклонить), `withdrawTime`; доступность — тот же запрос, что B8; ошибки `SLOT_TAKEN`, `CHANGE_EXPIRED`, `ANOTHER_CHANGE_PENDING`, `VERSION_CONFLICT`.
- **Состояния:** нет свободного времени; интервал заняли (`slot-lost`); идёт другое согласование; предложение отозвано; заказ закрыт; ошибка и неизвестный результат.
- **Готово, когда:** старый интервал освобождается, новый занимается ровно один раз (тест); при гонке за интервал один выигрывает (тест); показ в часовом поясе магазина (тест).
