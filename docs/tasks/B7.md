# B7 · Адрес и способ получения — **31, 32, 37 (верх экрана «Получение»)**

Путь покупки по Figma — три шага с крошками «Корзина / Получение / Оплата»: **корзина** (адрес, контакт, «Продолжить») → **«Получение»** (способ, детали адреса, время, комментарий) → **«Оплата»** → «Готово». B7 делает адрес и способ, B8 — время, B9 — контакт, B10 — оплату и оформление.

- **Figma:**
  - 31 (`96:5856`) — мобильные кадры: «адрес доставки открыт» (`96:6028`), «Ввод адреса · подсказки» (`98:5881`), «Геопозиция · ожидание» (`98:6055`), «Адрес найден · проверка» (`98:6221`), «Нет доступа к геопозиции» (`98:6391`), «Адрес не найден» (`98:6559`), «Адрес выбран · условия уточняются» (`98:6730`), «Продолжить без адреса» (`113:6171`).
  - 32 (`106:6003`) — строка «Доставка» в корзине: «Бесплатно» (`106:6008`), фиксированная «50 ₽» (`106:6147`), «Согласуем после заказа · Только товары · доставка отдельно» (`106:6286`).
  - 37 (`154:7872`) — экран «Получение», верх: «Доставка / Самовывоз» (`154:8362`, `154:8712`), адрес с деталями «Кв. · подъезд · этаж · домофон», «Уточнить детали адреса» (`161:10524`), «Адрес · не заполнено обязательное поле» (`161:8507`), «Сохранённый адрес · редактирование с картой» (`154:9754`), «Комментарий курьеру / магазину» (`161:10120`, `161:10321`, `161:9380`).
  - Десктопные кадры — A16.
- **Истории:** K04, K05.
- **Холст:** нужен — меняется одобренная корзина B6 (адрес в шапке корзины, строка «Доставка»). Шторка адреса и экран «Получение» — как в Figma.
- **Входит:**
  - **Адрес в шапке корзины:** «Укажите адрес доставки» → шторка «Адрес доставки». В шторке:
    - поле «Улица, дом, город» с подсказками при вводе;
    - карта Leaflet + OpenStreetMap с подписью «© OpenStreetMap contributors»;
    - «Определить мою позицию» — геопозиция браузера или Telegram;
    - проверка найденного адреса «Проверьте адрес · Исправить адрес · Подтвердить адрес».
  - **Тот же адрес в шапке главной** (Figma 45) открывает ту же шторку.
  - **Геокодер (D12):** открытый геокодер OSM без аккаунта и ключа (Photon для подсказок, Nominatim — запасной). Вызывается только с нашего сервера, через один модуль-адаптер (провайдер можно заменить без правок экранов), с кешем и задержкой ввода, чтобы не превышать правила использования.
  - **Проверка зоны и тариф на сервере:** полигон или радиус зоны магазина → тариф зоны. Строка «Доставка» в корзине проходит путь «Рассчитаем по адресу» → «Проверяем условия» → «Бесплатно» / «50 ₽» / «Согласуем после заказа». Зоны и тарифы берутся из сида до S4.
  - **Экран «Получение» (`push` из корзины):**
    - переключатель «Доставка / Самовывоз», только если у магазина включены оба способа;
    - для доставки — адрес и детали: «Квартира *» обязательна, подъезд, этаж и домофон — нет;
    - для самовывоза — «Забрать по адресу», адрес и график магазина;
    - «Комментарий курьеру» или «Комментарий магазину» — необязательный, в шторке.
  - **Хранение.** Выбранный способ, адрес, детали и комментарий хранятся на сервере вместе с корзиной: переживают перезагрузку и сохраняются при возврате.
- **Нажимается:**
  - адрес в шапке корзины или главной → шторка адреса;
  - подсказка → «Проверьте адрес»;
  - «Подтвердить адрес» → адрес в шапке корзины и пересчёт доставки;
  - «Исправить адрес» и «Изменить адрес» → ввод;
  - «Определить мою позицию» → ожидание → проверка адреса;
  - «Ввести адрес вручную» → ввод;
  - «Попробовать снова» → повтор геопозиции;
  - перетаскивание точки на карте → новый адрес по координатам;
  - на «Получении»: «Доставка / Самовывоз»; адрес › → шторка с картой; «Уточнить адрес» → «Детали адреса»; «Комментарий …» → шторка комментария.
- **Не входит (не рисовать):**
  - промокод и «Любимый товар» в корзине (A1, A5);
  - порог «до бесплатной доставки» и подборка товаров до порога из Figma 32 №4 (A6);
  - время (B8);
  - контакт и вход (B9);
  - «Продолжить» и «К оплате» (B10);
  - настройка зон, тарифов и пункта самовывоза продавцом (S4);
  - список нескольких сохранённых адресов (в Figma нет);
  - десктоп (A16).
- **Отличия от Figma:** нет.
- **Данные (API):** контракт `receiving` в `src/shared/contracts`:
  - способ `delivery | pickup`;
  - адрес: текст, координаты, квартира, подъезд, этаж, домофон;
  - комментарий;
  - результат зоны: `inZone`, вид тарифа `free | fixed | after_order`, `feeMinor`.

  Команды:
  - поиск адреса и обратный геокодинг — через наш сервер к геокодеру с кешем;
  - сохранение получения в корзину с ревизией, как `cart/change`.

  Ошибки: `OUT_OF_ZONE`, `ADDRESS_NOT_FOUND`, `VALIDATION` (нет квартиры), `VERSION_CONFLICT`. Сбой геокодера не стирает введённый текст.
- **Состояния:**
  - подсказки при вводе;
  - адрес не найден — «Не нашли такой адрес»;
  - ожидание геопозиции;
  - нет доступа к геопозиции;
  - адрес вне зоны — «Сюда не доставляем» и «Выбрать самовывоз», если он включён;
  - «Проверяем условия»;
  - карта не загрузилась — ввод только текстом;
  - не заполнена квартира — «Укажите квартиру.», выбранное время сохраняется.
- **Готово, когда:**
  - тесты зоны: внутри, на границе, вне, полигон и радиус;
  - тесты тарифа: `free`, `fixed`, `after_order`;
  - адрес и детали сохраняются после перезагрузки;
  - клиент не обращается к геокодеру напрямую, только через наш сервер;
  - повторный поиск того же адреса не вызывает геокодер (тест кеша);
  - smoke: корзина → адрес → в зоне → строка «Доставка» показывает тариф.
