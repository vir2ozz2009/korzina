# S7 · Бот магазина — **70 (подключение), финал «35 · Бот магазина и уведомления»**

- **Figma (справочник Claude):** 70 (`911:59820`); финал «35» (`1380:94064`): «Бот не подключён», «Ввод токена», «Проверка токена», «Токен не подошёл», «Бот привязан к другому магазину», «Бот работает с другим сервисом», «Telegram недоступен», «Подтвердить найденного бота», «Бот подключён», «Рабочая группа не выбрана», «Добавить бота в группу», «Ждём подтверждение Telegram», «Бот не может писать в группу», «Подтвердить рабочую группу», «События для рабочей группы», «Тестовое сообщение», «Уведомления на паузе», «Смена / отвязка группы», «Бот потерял доступ к группе», «Обновление токена», «Отключить бота», «Подключение доступно владельцу».
- **Истории:** M09.
- **Холст:** нужен.
- **Входит:**
  - **Подключение бота администратором:** ввод токена (BotFather) → проверка → «Подтвердить найденного бота @…» → webhook на Korzina → «Бот подключён». Токен — только в секретах магазина, на экран не выводится.
  - **Рабочая группа:** добавить бота в группу Telegram → подтверждение → какие события присылать (новый заказ, перевод на проверке, сообщение покупателя, перенос времени) → «Отправить тест».
  - **Управление:** владелец сменяет или отвязывает рабочую группу и ставит уведомления на паузу. Администратор меняет токен и отключает бота с подтверждением.
  - Бот магазина — он же вход покупателя через Telegram (B9) и Mini App магазина.
  - **Решение Андрея 19.11.2026:** бота магазина создаёт Андрей в BotFather и подключает **из админки** (карточка магазина → «Бот» → токен → проверка → подтверждение), продавец получает уже готовые сайт и Mini App. В кабинете продавца — просмотр «Бот подключён · @имя» и рабочая группа/события (настраивает владелец). Подключать, менять токен и отключать бота — администратор; продавцу — «Бота подключает администратор Korzina». Передача бота продавцу — вручную через BotFather, вне системы.
- **Нажимается:** в админке «Подключить бота» → токен → «Проверить» → «Подтвердить», «Обновить токен», «Отключить бота». В кабинете владельца «Выбрать группу», переключатели событий, «Отправить тест», «Сменить группу», «Отвязать», «Пауза».
- **Не входит (не рисовать):** сами уведомления продавцу и покупателю и очередь отправки (O4); рассылки (A12b).
- **Отличия от Figma:** ввод и обновление токена, подключение и отключение бота перенесены в админку. Владелец видит статус и настройки рабочей группы.
- **Данные (API):** Администратор вызывает `POST` токена → проверка `getMe` и `setWebhook` на сервере; привязка группы по событию Telegram; настройки событий; тестовое сообщение; ошибки `TOKEN_INVALID`, `BOT_IN_USE` (другой магазин), `TELEGRAM_UNAVAILABLE`, `GROUP_NO_ACCESS`, `FORBIDDEN`.
- **Состояния:** все ошибки токена из финала 35; ожидание подтверждения Telegram; бот не может писать в группу; бот потерял доступ к группе; Telegram недоступен; пауза.
- **Готово, когда:** токен не появляется ни в ответах API, ни в логах, ни в журнале (тест). Сервер разрешает подключать, обновлять и отключать бота администратору платформы и отклоняет эти команды владельца (тест). Один бот нельзя подключить к двум магазинам (тест). Владелец управляет группой и событиями, тестовое сообщение приходит в группу на demo. Отключение бота отключает вход покупателя через Telegram у этого магазина.
