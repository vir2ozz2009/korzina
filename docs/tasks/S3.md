# S3 · Категории, подкатегории, бренды — **63, финал «42 · Категории, бренды»**

- **Figma (справочник Claude):** 63 (`786:57730` и др.); финал «42» (`1429:74944`): «Категории», «Редактировать / Создать категорию», «Категория выключена», «Подкатегории», «Редактировать подкатегорию», «Категория на витрине / скрыта на витрине», «Бренды», «Редактировать бренд», «Бренд выключен», «Добавить бренд», «Бренд на витрине / скрыт на витрине».
- **Истории:** M04.
- **Холст:** нужен.
- **Входит:**
  - **Категории:** список с видимостью и порядком (перетаскивание); создать, изменить, выключить, удалить (с товарами — выбрать категорию для переноса, решение 3 в S2); внутри — подкатегории (те же действия) и «Товары категории» (каталог S2 с фильтром).
  - **Картинка категории:** по умолчанию фото первого товара, можно своё фото; нет фото — знак категории (`photos.md` §2); мозаика категорий на витрине (B2) использует эти данные.
  - **Бренды:** список; логотип или инициалы; создать, изменить, выключить; «Товары бренда»; при удалении бренда — перенос товаров (выбрать другой бренд или «без бренда»).
  - **Предпросмотр «как на витрине»** для категории и бренда.
  - Выключенная категория или бренд скрыты на витрине вместе с входами, товары остаются в каталоге продавца.
- **Нажимается:** строка → форма; «Добавить»; переключатель видимости; перетаскивание порядка; «Товары категории / бренда»; «Удалить» → подтверждение (с переносом товаров).
- **Не входит (не рисовать):** подборки (A3); маленькая витрина (A15).
- **Отличия от Figma:** сохранение как в S6.
- **Данные (API):** списки категорий и брендов; команды создать, изменить, порядок, видимость, удалить с переносом; ревизия каталога растёт (кеш витрины сбрасывается); ошибки `VALIDATION`, `NOT_EMPTY` (удаление с товарами без переноса), `VERSION_CONFLICT`.
- **Состояния:** пусто; загрузка; ошибка; категория без товаров; удаление с товарами; конфликт; без права — просмотр.
- **Решения Андрея 20.11.2026:** раздел «Категории» и «Бренды» — во вкладке «Товары» (переключатель «Товары · Категории · Бренды»); удаление категории и бренда одинаковое — с переносом товаров (подробно — S2, решения 1 и 3).
- **Готово, когда:** удаление категории с товарами переносит их без потерь (тест); выключенная категория не видна покупателю и не находится поиском (тест); порядок на витрине совпадает с кабинетом; удаление бренда переносит товары без потерь (тест).
