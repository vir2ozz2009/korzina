# B9 · Контакт и вход в корзине — **38**
- **Истории:** K03.
- **Входит:** шаг «Контакт»: гость оформляет заказ по имени и телефону без входа (решение D01). Необязательный вход через Telegram (бот магазина: deep link → бот → возврат к оформлению; в Mini App — автоматически). Секретная ссылка на заказ для гостя. Привязка заказов, корзины и избранного устройства к аккаунту после входа (слияние корзины гостя). Кнопка «Войти» в шапке главной.
- **Нажимается:** «Войти» на главной и в шаге «Контакт» → вход через Telegram; «Продолжить без входа» → имя и телефон.
- **Не входит:** экран профиля (B13); вход по телефону, email, SMS, VK/Яндекс (A17; кадры `login-phone*` блока 44 — туда же).
- **Готово, когда:** гость без Telegram оформляет заказ и видит его на своём устройстве и по секретной ссылке; по номеру телефона нельзя получить чужие данные (тест); вход через Telegram после заказа привязывает заказ и сливает корзину (тест: гость → вход → слияние без дублей).
