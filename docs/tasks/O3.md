# O3 · Рабочий день и календарь — **66, финал «01 · Рабочий день и навигация»**

- **Figma (справочник Claude):** 66 (`856:58540`): «Рабочий день · сегодня / завтра», фильтр «На сборке», просроченный заказ, «Календарь · есть заказы / нет / загрузка / ошибка», «Заказ открыт из календаря»; финал «01» (`839:50607`): «Сборка на сегодня», «Список сборки», «Требуют внимания», «Ещё»; «Карточка заказа в стиле Telegram» (`954:61072`) — главная.
- **Истории:** R09.
- **Холст:** нужен.
- **Входит:**
  - **Дополнение Андрея 20.11.2026:** вверху «Главной» — сводка дня: «Сегодня · N заказов · сумма»; «Требуют действия: N — принять N, проверить чек N, решить по оплате N»; «Долги клиентов: N ₽» (из меток оплаты блока 5). Каждая строка открывает «Заказы» с фильтром. Графики и периоды — O9.
  - **Главная кабинета «Рабочий день»** (вкладка «Главная»): «Сегодня / Завтра / Календарь»; фильтр по этапу; **«Требуют внимания · N»** (перевод на проверке, сообщение, перенос времени, просроченный заказ); **«Список сборки»** — что собрать на выбранный день по всем заказам (товар, фасовка, сколько); **«Ближайшие заказы»** — карточки как в O2, «Все заказы ›».
  - **Календарь** — заказы по датам (время магазина), выбрать день → список → карточка заказа; возврат на тот же день.
  - **Покупатель (Figma 45.18, D20):** вне часов работы на главной витрины — «Сейчас закрыто · примем заказ на <ближайшее время>»; приём приостановлен продавцом (S4) — «Магазин временно не принимает заказы».
- **Нажимается:** «Сегодня / Завтра / Календарь»; фильтры; «Требуют внимания» → список; «Список сборки» → экран сборки; заказ → карточка O2; день в календаре.
- **Не входит (не рисовать):** продвижение на главной (A).
- **Отличия от Figma:** нет.
- **Данные (API):** сводка дня одним запросом (по `seller_order_index`, ревизия); список сборки — агрегат по позициям заказов дня; календарь — число заказов по датам месяца.
- **Состояния:** нет заказов на день; загрузка; ошибка; фильтр без результатов; просроченный заказ.
- **Готово, когда:** бюджет SQL «рабочий день без изменений»; список сборки совпадает с суммой позиций заказов дня (тест); даты считаются в часовом поясе магазина (тест).
