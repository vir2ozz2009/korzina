# A18 · Установка кабинета и Web Push

Блок 25 · [План](../PLAN.md) · [История US-A18](../stories/later.md).

- **Figma:** В плане отдельные исходные группы не назначены.
- **Холст:** нужен. Вид и переходы согласуются в составе блока 25.
- **Входит:** Кабинет как приложение (PWA: установка на экран, иконка, офлайн-оболочка) и уведомления в браузере (Web Push, VAPID; на iPhone — только установленное на экран) — для продавцов без Telegram или с компьютера; дублирует уведомления O4.
- **Нажимается:** Продавец устанавливает кабинет на главный экран → включает уведомления в браузере → открывает заказ из сообщения → отключает подписку.
- **Не входит и границы:** Авторизация покупателя A17; обработка заказов офлайн вне объёма офлайн-оболочки.
- **Данные (API):** Манифест, оболочка PWA, подписка устройства и доставка по событиям O4 с проверкой прав магазина.
- **Состояния:** Разрешение отклонено, подписка истекла, офлайн-оболочка, браузер без поддержки; iPhone с установленным приложением.
- **Готово, когда:** Проверить установку и повторный запуск, получение уведомления и переход в нужный заказ. После отзыва доступа устройство не получает данные магазина.
