# A2 · Отзывы и рейтинг товаров

Блок 21 · [План](../PLAN.md) · [История US-A02](../stories/later.md).

- **Figma:** [49](https://www.figma.com/design/Y8MsoSYwEr373vVvlvXAGJ/?node-id=417-35777), [65](https://www.figma.com/design/Y8MsoSYwEr373vVvlvXAGJ/?node-id=805-59862)
- **Холст:** нужен. Вид и переходы согласуются в составе блока 21.
- **Входит:** Отзывы, рейтинг, видимость.
- **Нажимается:** После покупки открыть оценку товара → оставить отзыв → продавец меняет видимость → покупатель видит опубликованный результат.
- **Не входит и границы:** Обращения в поддержку и чат заказа — другие сценарии.
- **Данные (API):** Право оценить купленную позицию, автор, оценка, текст и видимость; публичное представление и рейтинг.
- **Состояния:** Нет доступной покупки, отзыв отправлен, скрыт, список отзывов пуст.
- **Готово, когда:** Проверить право по чужому заказу; после смены видимости сверить список публичных отзывов и рейтинг по согласованному правилу.
