# S1 · Каркас кабинета и вход продавца — **вне нумерации «Архитектура кабинета»**
- Навигация кабинета, переключатель магазинов (если их несколько), главный экран со сводкой.
- **Вход продавца — оба способа до конца:** (1) Telegram через бота платформы (`PLATFORM_BOT_TOKEN`, тестовый бот на demo): кнопка «Войти через Telegram» → бот → одноразовая ссылка обратно в кабинет; в Mini App бота платформы — по `initData`; (2) код на email — реальная отправка через провайдера из D17 вместо заглушки F4 (письмо с кодом и ссылкой, шаблон в стиле Korzina, `Reply-To` поддержки, SPF/DKIM для домена отправителя). Один аккаунт может иметь и Telegram, и email; привязка второго способа — в профиле продавца.
- **Готово, когда:** на demo продавец входит и через тестового бота, и по коду на реальный email; письмо доходит во «Входящие» Gmail и Яндекса (не в спам); повторная отправка кода не чаще раза в 60 с.
