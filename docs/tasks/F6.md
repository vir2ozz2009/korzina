# F6 · Токены, шрифт, тема MagicPath
- **Цель:** подключить готовый `src/styles/tokens.css` и Inter Variable; механизм оформления витрины (`src/shared/theme-presets.ts`: стиль на `<html>` от Worker; тесты: контраст пресетов, `deriveTheme` для светлых, тёмных и ярких цветов, отклонение почти белых; в `/dev/kit` переключатель пресетов и поле своего цвета); создать в MagicPath отдельный проект **«Korzina»** (ID записать в DESIGN.md §5) и перенести в его компоненты токены напрямую из `tokens.css` силами Codex; знак и иконка приложения из `public/brand/korzina.svg`.
- **Также — контекст магазина один раз за запрос** (PERFORMANCE §1, §6): Worker собирает `shop` (из `resolveShop`), флаги и тему оформления в один объект контекста запроса; `requireFeature`, отдача HTML с цветом витрины и `GET /api/shop` берут их оттуда, а не читают D1 заново. Кеш в памяти изолята на 30 с: выключение флага и смена цвета действуют не позже чем через 30 с. Бюджет-тест: повторный запрос того же магазина в пределах 30 с — 0 чтений D1 платформы.
- **Читать:** DESIGN §2, `design-system/tokens.md`, PERFORMANCE §1.
- **Готово, когда:** CSS компонента MagicPath использует токены из `tokens.css`; классы `bg-primary`, `text-title-2`, `rounded-xl` работают; на demo видна страница с палитрой и типографикой.
