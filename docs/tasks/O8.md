# O8 · Чат по заказу — **43, финал «02 · Заказы, исполнение и чат»** · *e2e*

- **Figma (справочник Claude):** 43 (`267:15825`): `inbox-active`, `inbox-closed`, `chat`, `draft`, `sent`, `sending`, `send-error`, `unknown-result`, `offline`, `empty-*`, `chat-completed`, `chat-cancelled`, `time-offer`, `replacement-offer`, `applied-changes`, `topup`, `refund-request`, `general`, `loading`, `load-error`, `history*`, `unavailable`, `empty-inbox`, `contacts-unset`, `photo-*`, `refund-sent`, `message-limit`, `auth`, `auth-phone`, `waiting-reply`; финал «02» — «Переписка по заказам», «Чат по заказу», продавец.
- **Истории:** Z06, R10.
- **Холст:** нужен.
- **Входит:**
  - **Покупатель:** «Чат с магазином» из карточки заказа и иконка в шапке витрины; список переписок (активные выше, завершённые); сообщения текстом и **фото**; в чате — **карточки событий заказа**: предложение времени (O7), предложение замены (O6), доплата (O5b), запрос реквизитов возврата (O5b), «изменения применены»; гость без входа — вход (B9).
  - **Продавец:** иконка сообщений с числом непрочитанных в шапке кабинета; «Переписка по заказам» (непрочитанные и ожидающие ответа выше); чат из карточки заказа; из чата — открыть заказ.
  - Живая доставка сообщений — тот же поток изменений, что O2; уведомление продавцу в Telegram — O4.
  - Лимит длины и частоты сообщений; переписка закрывается через N дней после завершения заказа (только чтение).
- **Нажимается:** «Чат с магазином» / «Чат по заказу»; поле ввода, «Отправить»; «Фото»; карточка события → её действие (подтвердить время, ответить на замену, оплатить, указать реквизиты); переписка в списке → чат.
- **Решения Андрея 23.11.2026 (сверка блока 10, D21):**
  1. **Чата без заказа нет** (D21). Написать магазину без заказа — через контакты в «О магазине». Figma `general` не рисуется. Тест «D21 сообщение без заказа — FORBIDDEN».
  2. **Текст и фото.** Тест «O8.2 фото — через F9, чужое фото не прикрепить».
  3. **После завершения или отмены заказа** писать можно ещё 7 дней, затем переписка только для чтения (`CHAT_CLOSED`). История не удаляется: она нужна для споров по деньгам. Тест «O8.3 через 7 дней после завершения — CHAT_CLOSED, история видна».
  4. **Уведомление продавцу о новом сообщении** — по таблице ролей блока 8 (`Ещё → Уведомления`), отдельный столбец «Сообщения»; покупателю — через бот магазина или бот Korzina (блок 9 §11.7).
- **Не входит:** рассылки (A12b); общий чат без заказа (в Figma `general` — **вопрос Андрею**: нужен ли чат без заказа в MVP).
- **Отличия от Figma:** нет.
- **Данные (API):** сообщения заказа (курсор), `send` с `Idempotency-Key`, фото — F9; непрочитанные — счётчик хранится, а не считается (PERFORMANCE §5); ошибки `MESSAGE_LIMIT`, `CHAT_CLOSED`, `FORBIDDEN`.
- **Состояния:** пусто; черновик; отправка; ошибка; неизвестный результат; офлайн; лимит; контакты магазина не заданы; переписка закрыта; загрузка и ошибка истории.
- **Готово, когда:** сквозной тест обеих ролей: заказ → принятие → замена с согласием → доплата → выдача; покупатель и продавец видят одно состояние; повтор отправки не дублирует сообщение (тест); чужой чат недоступен (тест).
