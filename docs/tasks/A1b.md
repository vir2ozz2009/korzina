# A1b · Количество в подарок (N+M)

Подблок 12.2 · [План](../PLAN.md) · [История US-A01b](../stories/later.md).

[Спецификация 12.2 и нумерованные сценарии](../specs/promo-quantity-and-bundles.md).

- **Figma:** [33](https://www.figma.com/design/Y8MsoSYwEr373vVvlvXAGJ/?node-id=118-6234), [81](https://www.figma.com/design/Y8MsoSYwEr373vVvlvXAGJ/?node-id=1033-62189)
- **Холст:** нужен. Вид и переходы согласуются на общем холсте подблока 12.2.
- **Входит:** Акция «N+M» (например, «2+1 · третья в подарок»): форма продавца (в Figma нет — Codex собирает экран из UI-кита и выкладывает на холст MagicPath, вы одобряете, как любой экран) и сторона покупателя — promo.md §10. [Правила продвижения](../stories/promo.md), §4–6, 10.
- **Нажимается:** Создать правило с N, M, подходящими фасовками и сроком → опубликовать → добавить в корзину неполную, затем полную группу.
- **Не входит и границы:** Набор с фиксированной ценой — A11. Форму продавца согласовать на холсте.
- **Данные (API):** Параметры группы, лимит на заказ, состав подходящих позиций и результат расчёта по строкам.
- **Состояния:** До подарка не хватает единицы; полная группа; конкурирующая цена по акции; количество уменьшилось.
- **Готово, когда:** Для N=2 и M=1 две единицы не дают подарок, из трёх подходящих бесплатна самая дешёвая. Проверить две группы, лимит и удаление единицы.

Проверить стабильный порядок подарков, лимит групп, недоступную единицу и конкуренцию за те же фасовки с комбо. При известном тарифе сравнивать полный итог.

На холсте 12.2 вход по цели «Увеличить сумму заказа» и прямой выбор открывают одну форму. В результате показать число завершённых групп и подаренных единиц по [общей спецификации](../specs/promo-discounts.md#11-результаты-предложения).
