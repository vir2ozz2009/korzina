# CTX-2 · Инструкции, маршруты и пилотный навык

Андрей 28.11.2026 поручил выполнить весь план аудита промптов. База: `22fc67d`.

## Входит

1. Ограниченный docs-PR: убрать отменённые нормы, уточнить Git, проверки, источники и область СТОПов.
2. Docs-PR: короткие маршруты по типу работы, единственные источники процедур, передача и шаблоны заданий; обновить внешнее описание проекта.
3. Пилот `korzina-demo-recheck`: создать и проверить персональный навык, сохранить переносимую копию для Codex в `.agents/skills`; проверить положительные/отрицательные запросы и сценарии без live-мутаций.
4. Отдельный PR scripts/CI: дешёвая проверка изменённых Markdown-ссылок/якорей, формата навыка и предупреждение о росте входа. Исполняемые файлы не включать в docs-only. Проверить регрессии валидатора и классификатора.
5. Разовая сравнительная проверка маршрутов и независимые пробы навыка; доступные метрики записать, не выдавать символы за оплаченные токены.

## Не входит

Код продукта, пересмотр одобрений/приёмок, prod/Lavka, ослабление денежных проверок, полный архитектурный аудит, автоматическое изменение настроек на Mac, дорогие проверки LLM в CI.
