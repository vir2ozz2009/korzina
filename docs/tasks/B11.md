# B11 · Заказ после оформления и «Мои заказы» — **40, 45 (карточка заказа на главной)**

- **Figma (справочник Claude):**
  - 40 (`206:10072`): `accepted`, `packing`, `packed`, `courier`, `pickup`, `completed`, `pending`, `cancel-confirm`, `cancelled`, `refund`, `loading`, `error`, `help`, `catalog`, `catalog-closed`, `catalog-multiple`, `active1002/1003`, `orders`, `history`, `history-detail-*`, `repeat-basket`, `success-courier`.
  - 40 доп. (`227:18646`): `empty-active/completed`, `loading-*`, `error-*`, `history-more*`, `history-end`, `list-stale`, `repeat-*`.
  - 45: 45.17 «Заказ · ждём магазин».
  - Кадры `offer`, `due`, `delivery-*`, `refunded` — O5b; 45.15–45.16 («нужно выбрать замену / время») — O6, O7.
- **Истории:** Z01, Z02, Z03, Z07.
- **Холст:** нужен — все экраны новые.
- **Входит:**
  - **Карточка активного заказа на главной и в каталоге** — под шапкой: номер, этап, время получения. Нажатие открывает карточку заказа. Если активных заказов несколько — список карточек и счётчик. Завершённый или отменённый заказ с главной исчезает и остаётся в истории.
  - **Карточка заказа:**
    - номер и полоса этапов: Принят → Собираем → Готов к выдаче → Передан курьеру → Завершён (у самовывоза нет этапа курьера; «Отменён» отдельно);
    - получение: способ, адрес или пункт, дата и время;
    - состав по снимку заказа: фото, название, фасовка, количество, цена;
    - итог: товары, доставка, итого; при оплате курьеру — «Итого магазину» и «Доставку оплачиваете курьеру · …»;
    - способ и статус оплаты: «Оплатите при получении» / «Чек отправлен, магазин проверит» / «Оплачено»;
    - «Связь с магазином» — контакты из «О магазине», чат — O8;
    - «Повторить заказ»;
    - «Отменить заказ» — только до передачи курьеру, при самовывозе — до выдачи (D05);
    - «Заменить подтверждение оплаты» — пока перевод на проверке (решение 18.11.2026).
  - **«Мои заказы»**: вкладки «Активные / Завершённые», карточка в списке (номер, дата, этап, сумма), подгрузка истории «Показать ещё». Вход — из профиля (B13), с «Готово» и с карточки заказа на главной.
  - **Повтор заказа:**
    - проверка текущих цен и остатков, затем перенос в корзину; одинаковые позиции объединяются в пределах остатка, текущая корзина не стирается;
    - новая цена — явно принять;
    - часть товаров недоступна — добавить доступные и показать, что не добавлено.
  - **Доступ** — только свои заказы этого магазина. Профиль по номеру видит заказы только этого устройства, Telegram — на всех устройствах (решение 18.11.2026).
- **Нажимается:**
  - карточка на главной → карточка заказа (`push`);
  - заказ в списке → карточка заказа;
  - «Показать ещё» → следующая страница;
  - «Отменить заказ» → подтверждение «Отменить заказ №…?» → «Заказ отменён»;
  - «Повторить заказ» → проверка → корзина;
  - «Связь с магазином» → шторка контактов;
  - «Заменить подтверждение оплаты» → выбор файла;
  - «К покупкам» → главная.
- **Не входит (не рисовать):**
  - доплата, оплата доставки после согласования, реквизиты для возврата (O5b);
  - ответ на замену и перенос времени (O6, O7) — карточки «нужно выбрать замену / время» на главной;
  - чат (O8);
  - живое обновление статуса без открытия экрана (O2);
  - уведомления в Telegram (O4);
  - отзывы о заказе (A2);
  - регулярные заказы (A7);
  - добавить товары к текущему заказу (A10);
  - десктоп (A16).
- **Отличия от Figma:** нет секретной ссылки на заказ (решение 18.11.2026). Статус «Отменён» показывает «Оплата не требуется» или «К возврату <сумма>» — реквизиты для возврата появятся в O5b.
- **Данные (API):**
  - `GET` активных заказов покупателя: компактно, для главной; ревизия, без перечитывания, если ничего не изменилось (PERFORMANCE §4);
  - `GET` «Мои заказы» по вкладке с курсором;
  - `GET` заказа по id — снимок из B10 плюс текущие этап и оплата;
  - команда `cancel` с `Idempotency-Key` → `CANCEL_NOT_ALLOWED`, если этап уже прошёл;
  - команда `repeat` → результат проверки и новая корзина (как `cart/change`);
  - замена чека — загрузка F9 и команда `replaceProof`, пока `pending_review`.
- **Состояния:**
  - загрузка;
  - пусто «Активных заказов нет» / «Завершённых заказов нет»;
  - ошибка с «Повторить»;
  - ошибка подгрузки истории — уже загруженное не пропадает;
  - устаревшие данные — «Обновлено <время>»;
  - отмена: подтверждение, «Отменяем…», «Заказ уже передан — отменить нельзя»;
  - повтор: «Проверяем…», цена изменилась, остатка меньше, частично доступно, ошибка (корзина не меняется).
- **Готово, когда:**
  - тесты прав: чужой заказ недоступен; профиль по номеру не видит заказы с другого устройства;
  - отмена только в разрешённом этапе, повтор отмены не отменяет дважды; остаток и интервал освобождаются один раз;
  - повтор заказа не дублирует позиции и не превышает остаток;
  - бюджет SQL «активные заказы без изменений»;
  - smoke: оформить → главная показывает активный заказ → карточка → отмена.
