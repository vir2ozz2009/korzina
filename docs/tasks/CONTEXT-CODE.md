# CONTEXT-CODE · Устранение подтверждённых дублей

Разрешено Андреем 27.11.2026 в рамках дальнейшей оптимизации контекста. Исполнитель кода — облачный Codex; использовать результаты текущего архитектурного аудита, не запускать второй полный аудит.

## Входит

- На свежем main подтвердить конкретный дубль из аудита: пути/символы, одинаковое правило, все потребители. Исторический аудит на 0566290 сам по себе не доказывает наличие дубля сейчас.
- Выбрать минимальное изменение по ответственности; общий денежный расчёт сохранять серверным. Пример и настоящая корзина могут иметь разные источники данных при общем расчёте — это не повод слить состояния.
- Согласовать владение файлами с активной реализацией 12.3; пересекающееся изменение включить в её работу либо отложить до её merge. Чужой checkout/ветку не менять.
- Один ограниченный рефакторинг на PR; сохранить контракты и поведение, обновить карту затронутого блока. Проверки по TESTING и существующие тесты денег/прав/заказа; видимое изменение требует установленной проверки превью.

## Не входит

Массовое дробление по длине файлов, новая универсальная архитектура, ослабление тестов, prod, повторный аудит всего репозитория. Похожий код без совпадающей ответственности не объединять.

## Готово

Подтверждённый дубль устранён, все потребители используют общий источник, проверки зелёные; отчёт содержит исходные/итоговые пути и ограничение результата. Если дублей по доступным доказательствам нет, сообщить это без фиктивного рефакторинга. Документальная подготовка не считается завершением этой задачи.
