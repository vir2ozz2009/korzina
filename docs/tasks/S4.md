# S4 · Получение: доставка, самовывоз, расписание — **60, финалы «39 · Условия доставки», «41 · Карта, время получения»**

- **Figma (справочник Claude):** 60 (`682:52272` и др.); финал «39» (`1414:73686`): «Получение заказов», «Условия доставки», «Доставка всегда бесплатна», «Расчёт после заказа», «Доставку оплачивают курьеру», «Условия самовывоза»; финал «41» (`1428:74704`): «Карта · город / радиус / своя зона», «Проверить адрес на карте», «Адрес внутри / за пределами зоны», «Точка самовывоза», «Самовывоз глазами покупателя», «Время получения», «Разные интервалы по дням», «Получение в течение дня», «Согласование времени», «Интервал вне часов». Порог и промокод на доставку («39 · 03–04») — A6.
- **Истории:** M05, M06.
- **Холст:** нужен.
- **Входит** — экраны настроек для всех параметров из `docs/specs/purchase.md` §10 (сейчас они в демо-данных):
  - **Пауза приёма заказов** — см. решение 3 ниже (кнопка на «Главной» кабинета, срок, по способам).
  - **Способы получения:** доставка, самовывоз или оба; **точка самовывоза** — адрес (на карте или текстом), часы, «как увидит покупатель».
  - **Зоны доставки** — способ задания (решение 18.11.2026): **на карте** (город, радиус или своя зона, «Проверить адрес на карте»), **списком районов** (название + тариф) или **адрес текстом без проверок** (одна цена); платформенный флаг `maps` выключает карту для всех магазинов.
  - **Тариф зоны:** бесплатно, фиксированная сумма или «расчёт после заказа».
  - **Кому платят за доставку:** магазину или курьеру напрямую (D18): фиксированная сумма или «по тарифу службы».
  - **Обязательные поля адреса:** квартира, подъезд, этаж, домофон.
  - **Время получения:** режим — интервалы, в течение дня или «согласуем после заказа»; расписание по дням недели (разные интервалы по дням); вместимость интервала; вместимость дня по желанию; **время на подготовку** и **отсечка дня**; исключения (выходные даты); предупреждение «Интервал вне часов работы».
  - Сохранение как в S6.
- **Решения Андрея 20.11.2026 (сверка карточек блока 7, по образцу Shopify, Square, Uber Eats):**
  1. Место: «Ещё → Настройки» → «Получение заказов» (S4), «Оплата» (S5), «О магазине» (S6). Цвет витрины — в «Ещё → Витрина» (раздел из блока 6), не в «О магазине». Логотип — в «О магазине».
  2. Продавец меняет: название, логотип, адрес, контакты, часовой пояс, цвет. Только админ (Андрей) в админке: страна, валюта, адрес витрины (slug). Валюта закреплена после первого заказа (как в Shopify). У продавца страна и валюта показаны только для чтения с подписью «меняет поддержка».
  3. Пауза приёма заказов — кнопка на «Главной» кабинета (не только в настройках): срок «на 1 час / до конца дня / пока не включу» (конец дня — по поясу магазина), можно отдельно доставку или самовывоз; снятие одним нажатием. Витрина работает, оформить нельзя на приостановленный способ; покупателю «Магазин временно не принимает заказы» (или «Доставка временно недоступна»). Пауза администратора (статус `paused` в админке) — отдельно, продавец её не снимает, в кабинете пометка «Магазин приостановлен администратором». Отпуск — выходные даты в расписании.
  4. AD4 (импорт нейросетью) — отдельный блок 7б после блока 7.
  5. Уровень блока — «Высокое».
- **Нажимается:** переключатель «Приём заказов»; способы; зоны → способ задания → карта / районы / текст; тарифы; поля адреса; расписание по дням → интервалы; «Проверить адрес»; «Посмотреть как покупатель»; «Сохранить».
- **Не входит (не рисовать):** порог бесплатной доставки, подборка и промокод на доставку (A6); акции (A1).
- **Отличия от Figma:** режимы «списком районов» и «адрес текстом» и пауза приёма — решения Андрея 18.11.2026 (в Figma их нет); без черновика.
- **Данные (API):** `GET`/`PUT` настроек получения с ревизией — ровно те поля, что читают B7, B8 и B10 (`receiving`-настройки из спецификации покупки §10); проверка адреса на карте — тот же серверный модуль геокодера (D12); ошибки `VALIDATION` (пересечение интервалов, интервал вне часов), `VERSION_CONFLICT`.
- **Состояния:** загрузка; нет ни одного способа (предупреждение: покупатели не смогут оформить); адрес вне зоны при проверке; интервал вне часов; конфликт; без права — просмотр.
- **Тесты решений 20.11.2026 (каждый с номером решения в названии):**
  - реш. 3: пауза «на 1 час» снимается сама через час; «до конца дня» — в 00:00 **по поясу магазина**, не UTC; «пока не включу» — только вручную;
  - реш. 3: пауза только доставки — самовывоз оформляется, доставка отклоняется `checkout` (и наоборот); пауза снимается одним действием;
  - реш. 3: при паузе администратора продавец не может её снять (`FORBIDDEN`), оформление закрыто; снятие паузы продавца не снимает паузу администратора;
  - реш. 3: заказ, начатый до паузы, на оформлении получает понятный отказ, уже оформленные заказы не меняются;
  - выходные даты закрывают эти дни для оформления;
- **Готово, когда:** изменения настроек сразу меняют поведение покупки (тесты вместе с B7, B8, B10: зона, тариф, режимы времени, пауза); изменение не ломает уже оформленные заказы (снимок условий в заказе); при выключенном флаге `maps` карта недоступна ни продавцу, ни покупателю.
