# S9 · Первый запуск и тестовая покупка — **86, 72, финалы «24 · Первый запуск», «33 · Тестовая покупка»**

- **Figma (справочник Claude):** 86 (`1094:63211`, `1099:63253`); финал «24» (`1294:59696`): «Первый вход», «Продолжить настройку», «Проверка получения», «Настройки готовы», «Проверка перед открытием», «Тестовая покупка завершена / выявила проблему», «Обязательная настройка изменилась», «Нет права открыть магазин», «Не удалось открыть», «Результат открытия проверяется», «Магазин открыт», «Первый рабочий день», «Покупатель открыл ссылку до запуска», «Платформа ещё не назначила адрес», «Временный адрес назначен», «Открытие только для заявок»; финал «33» — «Тестовая витрина / корзина / получение / оплата / заказ оформлен / результат».
- **Истории:** M11.
- **Холст:** нужен.
- **Входит:**
  - **Чек-лист готовности на главной кабинета:** данные магазина (S6) → хотя бы один товар (S2) → способ получения (S4) → оплата (S5) → тестовая покупка (необязательна) → «Открыть магазин»; каждый пункт ведёт в настройку и обратно.
  - **Проверка перед открытием** и **открытие одной командой** без двойного открытия; «Результат открытия проверяется» при сбое связи.
  - **Тестовая покупка:** обычные экраны покупателя с полосой «Тестовый режим»; «Оформить» выполняет **проверку оформления без записи** (`checkout` в режиме dry run: все проверки B10, но ни заказа, ни резерва, ни списания); оплата имитируется; ничего не попадает в заказы, деньги и статистику, не меняет остатки и не шлёт уведомления. После изменения настроек предлагается повторить.
  - **Покупатель до запуска:** по ссылке — «Магазин скоро откроется».
- **Нажимается:** пункты чек-листа; «Пройти тестовую покупку»; «Открыть магазин» → подтверждение.
- **Не входит (не рисовать):** «Открытие только для заявок» (A8); адрес витрины от платформы (AD1, AD3).
- **Отличия от Figma:** нет.
- **Данные (API):** `GET` готовности магазина (список пунктов и их состояние); `checkout` с `dryRun: true`; команда `openShop` (идемпотентная); ошибки `NOT_READY` (с пунктами), `FORBIDDEN`.
- **Состояния:** пункт не выполнен; тестовая покупка нашла проблему; обязательная настройка изменилась после проверки; нет права открыть; не удалось открыть; результат проверяется.
- **Готово, когда:** новый магазин из сида проходит чек-лист и тестовую покупку и принимает реальный заказ; после тестовой покупки в базе нет записи заказа, остатки и слоты не изменились (тест); двойное «Открыть» не открывает дважды (тест).
