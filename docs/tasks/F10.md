# F10 · CI, превью и скрипты проверки
- **Цель:** скрипты `check:fast` (типы + Biome + `check:arch`) и `test:related` (тесты по изменённым относительно `main` файлам); Vitest без лишней изоляции файлов, где это безопасно (сейчас ~7 с экономии); GitHub Action — `npm run check` один раз на ветку задачи, e2e — по метке `e2e` и раз в сутки; превью-версия Worker на ветку; Playwright-заготовка с одним smoke-тестом. Workers Builds тесты не повторяет.
- **Защита от раздувания (в `npm run check`):** `knip` — падает на неиспользуемых файлах, экспортах и зависимостях; бюджет размера сборки — JS первого экрана витрины — цель 135 / потолок 160 КБ gzip (PERFORMANCE.md §7), каждый ленивый чанк ≤ 60 КБ gzip (скрипт читает отчёт Vite); служебные страницы `/dev/*` и демо-экраны недоступны в prod-сборке (только local и demo).
- **Читать:** `TESTING.md`.
- **Готово, когда:** `knip` и бюджет размера проходят без исключений; PR показывает статус и ссылку на превью; `check:fast` ≤ 20 с, `check` ≤ 90 с — время записано в PROGRESS.md.
