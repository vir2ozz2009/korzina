# B4 · Карточка товара и фасовки — **47**
- **Figma:** 47 (`364:23971`) — в этой задаче: `tomato*`, `variants-*`, `soldout*`, «Все фасовки закончились», `minimal`, `rich`, `rich-scrolled`, `no-photo`, `photo-error`, `loading`, `error`, `unavailable`, `price-changed`, `stock-changed`, `viewer*`, `info*`, `share*`, `croissant*`, `milk*`, `cucumber`, `avocado`, `carrot`, `bread`, «Фасовки на плитке / …», «Фасовки · ещё ничего не добавлено», «Много фасовок», «Длинные названия», «500 г · две упаковки», «Главная · все фасовки закончились»; **не делать и не показывать** (другие блоки): `tomato-liked` (B12), `personal`, `benefit-guest` (A12, A5), `cashback*` (A4), `reviews-*`, «Следующие отзывы · …» (A2), `story-*` (A3). Варианты «· фото 2» — те же кадры со вторым фото галереи.
- **Истории:** C05.
- **Входит:** галерея (листание, точки, по нажатию — полноэкранный просмотр целиком, закрытие свайпом вниз); название; выбор фасовки на экране (чипы; смена фасовки меняет цену, старую цену, скидку и остаток; галерея томатов сохраняет текущее фото); остаток «Всего доступно N шт.» при малом остатке; краткое описание и «Подробнее о товаре» — шторка (описание, состав, хранение — что заполнено); нижняя кнопка «Добавить» → «− N +» с лимитом; «Поделиться»; рекомендации «Ещё из категории» (до 4 плиток той же категории; без текущего товара, других фасовок его группы, скрытых и закончившихся; нет подходящих — блока нет; ручной выбор продавцом — S2); галерея 1–6 фото (одно фото — без счётчика и листания); старая цена зачёркнута и процент — только при действительной старой цене; бренд — ссылка на товары бренда; пустые поля (бренд, описание, состав, характеристики) скрываются вместе с отступами; 4+ фасовок или длинные названия — чипы прокручиваются, выбранная видна. Разные фасовки — разные строки корзины; выбор 1 кг не заменяет уже добавленные 500 г. «Назад» возвращает в реальный источник (главная, категория, фильтр, бренд, поиск) с прежней позицией; прямая ссылка без истории — выход в магазин. Плавающая «Корзина» стоит над нижней кнопкой и ничего не перекрывает.
- **Нажимается:** фото → полноэкранный просмотр; чип фасовки → смена фасовки; «Подробнее» → шторка; «Добавить», «−», «+» → корзина; «Поделиться» → в Telegram — `shareURL`, в браузере — системное меню или копирование ссылки (ссылка на этот товар этого магазина); плитка рекомендации → её карточка (`push`); «Корзина» (компактная, справа от «Добавить» — components.md) → экран корзины (B6).
- **Не входит:** избранное-сердце (B12); отзывы, «С этим берут» по истории покупок, нейро-подбор (A).
- **Состояния:** скелетон шаблона `product`; нет в наличии — кнопка «Нет в наличии» неактивна; скрытый или удалённый товар по ссылке — «Товар больше недоступен» и «На главную»; ошибка — «Повторить».
- **Готово, когда:** smoke: плитка → карточка → смена фасовки → «Добавить» ×2 → назад → на плитке «− 2 +» той же фасовки; прямая ссылка из «Поделиться» открывает карточку; кнопку «Добавить» ничто не перекрывает; бюджет SQL карточки.
