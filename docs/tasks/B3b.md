# B3b · Все товары, фильтры и сортировка — **46**
- **Истории:** C04.
- **Figma:** 46 — «Все товары» (`353:26582`), фильтры (`353:26581`), сортировка (`353:24282`, `353:24510`, `353:24738`), с фильтрами (`353:24121`, `353:24966`, `353:25166`), «0 товаров» (`353:25323`), фильтры выключены (`353:25991`), загрузка/ошибка/пусто (`353:25713`, `353:25853`, `353:25921`).
- **Входит:** экран «Все товары» с вкладками «Все товары · Категории · Бренды»; в общем `ProductList` (B3) — кнопка «Фильтры» (шторка по Figma 46: цена «от — до», «Бренд» → «Все бренды ›», «Только в наличии», «Сбросить» и «Показать N товаров»); **плюс строка «Категория» → «Все категории ›» тем же видом, что «Бренд», над брендом — решение Андрея 18.11.2026, в Figma её нет**; в категории строка «Категория» показывает её подкатегории, сортировка (по умолчанию, сначала дешевле, сначала дороже, по названию), чипы выбранных фильтров с «×» и «Сбросить», счётчик «N товаров». Всё это сразу работает и в категории, и в бренде. Выбранное хранится в адресе (`?sort=&min=&max=&brands=&cat=&inStock=`): «назад», «поделиться» и перезагрузка сохраняют выбор. Вход на «Все товары» — «Все ›» справа от заголовка «Товары» на главной (как у «Категорий») и «Все товары ›» на «Все категории».
- **Сервер:** порядок по умолчанию — из кешируемого документа, как сейчас. Сортировка и фильтр по цене — запрос к базе магазина по индексу минимальной цены доступной фасовки: возвращает id товаров страницы и счётчик, описания — из кеша документа. **Сортировать и фильтровать на клиенте по загруженной странице нельзя** (PERFORMANCE §1.4). Курсор учитывает ключ сортировки. Бюджет SQL — тест.
- **Нажимается:** вкладки → «Все товары» / «Все категории» / «Все бренды» (`tab`); «Фильтры» → шторка → «Показать N товаров»; сортировка → шторка выбора; «×» у чипа → снять фильтр; «Сбросить» → все фильтры сняты.
- **Не входит:** выключение фильтров продавцом — настройка в S (до неё фильтры включены; кадр `filters-off` — поведение при выключенном флаге, флаг `catalogFilters`); фильтры по другим полям (A).
- **Состояния:** по кадрам 46: «0 товаров» с «Сбросить фильтры»; загрузка, ошибка, пустой магазин.
- **Готово, когда:** тесты: сортировка по цене учитывает только доступные фасовки и текущие цены; фильтр + сортировка + курсор дают без пропусков и повторов; smoke: категория → фильтр «до N» → товар → назад — фильтр и прокрутка на месте.
