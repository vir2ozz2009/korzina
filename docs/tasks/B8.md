# B8 · Время получения — **37**

- **Figma:** 37 (`154:7872`), мобильные кадры:
  - «Получение · нужно выбрать время / всё заполнено» (`154:8020`, `154:8191`), самовывоз (`154:8712`, `154:8887`);
  - шторка «Когда привезти заказ / Когда заберёте заказ» (`154:9062`, `154:9287`, `154:9516`);
  - режимы магазина: «Только день» (`158:8105`, `158:8282`, `158:9340`), «Договоримся после заказа» (`158:8459`), разные интервалы по дням недели (`158:8634`, `158:8811`, `158:9547`, `158:9758`), одно длинное окно (`158:8988`, `158:9969`);
  - «Нет свободных дат» (`158:9165`), «Интервал уже занят» и «Другой доступный интервал» (`161:8678`, `161:10751`), «Проверяем время» (`161:8857`), «Ошибка проверки времени» (`161:9032`), «Другой интервал выбран» (`161:9553`).
- **Истории:** K06.
- **Холст:** нужен — блок «Когда привезти» и шторка выбора времени новые.
- **Входит:**
  - Блок «Когда привезти» («Когда заберёте» для самовывоза) на экране «Получение». Значение «Выберите день и время ›» или выбранное: «Завтра, 8 ноября · 10:00–13:00 ›».
  - Шторка выбора: чипы «Сегодня / Завтра / Другой день», заголовок дня, «Доступное время по расписанию магазина», интервалы (занятые неактивны), «Выбрать <интервал>», «Назад».
  - Три режима магазина:
    - день и интервал;
    - только день — «Привезём в течение дня, без выбора часов»;
    - «Договоримся после заказа» — без даты и времени, «Магазин свяжется с вами».
  - Интервалы задаются по дням недели. Время показывается и считается в часовом поясе магазина. Расписание и вместимость берутся из сида до S4.
  - Выбор хранится с получением в корзине (B7). Перед «К оплате» сервер проверяет доступность. Резерв интервала делается при оформлении (B10).
- **Нажимается:**
  - «Когда привезти ›» → шторка;
  - чип дня → интервалы дня;
  - «Другой день» → список доступных дней;
  - интервал → выбран;
  - «Выбрать …» → закрыть шторку;
  - «Назад» → закрыть без изменений;
  - «Обновить доступность» и «Повторить проверку» → новая проверка;
  - «Выбрать другое время» → шторка.
- **Не входит (не рисовать):**
  - «Как можно скорее» — не делаем (решение Андрея 18.11.2026, в Figma 37 нет);
  - настройка расписания продавцом (S4);
  - перенос времени после заказа (O7).
- **Отличия от Figma:** нет.
- **Данные (API):** `GET` доступных дней и интервалов на 7 дней вперёд. Ответ:
  - режим магазина `slots | day | after_order`;
  - дни: дата, доступен ли день;
  - интервалы: `id`, начало, конец, `available`;
  - часовой пояс магазина.

  Выбор сохраняется командой получения (B7) с ревизией. Ошибки: `SLOT_TAKEN`, `VERSION_CONFLICT`.
- **Состояния:**
  - «Проверяем доступность…»;
  - нет свободных дат — «Обновить доступность», адрес и корзина сохранены;
  - выбранный интервал занят — «Выбрать другое время», адрес и контакт сохранены;
  - ошибка проверки — «Повторить проверку», выбор сохранён;
  - день без интервалов неактивен.
- **Готово, когда:**
  - тесты расписания: интервалы по дням недели, вместимость (последнее место), переход через полночь;
  - часовой пояс магазина отличается от часового пояса покупателя;
  - режимы `day` и `after_order`;
  - бюджет SQL запроса интервалов;
  - smoke: «Получение» → шторка → интервал → значение на экране.
