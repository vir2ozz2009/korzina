# B8 · Время получения — **37**
- **Истории:** K06.
- **Входит:** выбор дня (ближайшие 7) и интервала по расписанию магазина и вместимости (занятые интервалы неактивны); время показывается в часовом поясе магазина; «Как можно скорее», если включено у магазина; расписание — из сида до задач S. Резерв интервала — при оформлении (B10).
- **Нажимается:** день → интервалы этого дня; интервал → выбран; «Готово».
- **Не входит:** настройка расписания продавцом (S); перенос времени после заказа (O).
- **Состояния:** нет свободных интервалов на день — «Свободного времени нет», ближайший свободный день подсвечен; магазин закрыт сегодня — день неактивен.
- **Готово, когда:** тесты расписания и вместимости, переход через полночь и часовой пояс магазина ≠ покупателя.
