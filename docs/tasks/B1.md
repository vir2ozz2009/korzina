# B1 · Модель каталога + сид
- **Цель:** таблицы categories, brands, products, variants, media с индексами под запросы витрины; каталог разделён на публичный документ (кеш Worker по `catalogVersion` + `ETag`) и оперативные данные (цены, остатки, доступность) без серверного кеша; компактная форма плитки и полная форма карточки; сид из Lavka `server/demo-catalog.json` + фото (`design-system/photos.md`). Раздел каталога в `shop-spec.ts` (CONVENTIONS «Описание магазина»).
- **Читать:** DOMAIN «Каталог», PERFORMANCE §1–2, §6.
- **Готово, когда:** при неизменной версии каталог отдаётся без вызова DO (тест); остаток никогда не берётся из кеша; бюджеты «оперативные данные» и «карточка товара» проверены тестами; планы запросов без `SCAN`; скрытые и без остатка ведут себя по правилам.

Индекс задач и блоков — [`docs/PLAN.md`](../PLAN.md). Шаблон карточки — [`README.md`](README.md).
