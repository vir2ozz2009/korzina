# L2 · Прод-окружение
- Отдельные ресурсы prod, `*.korzina.app`, домены магазинов, мониторинг ошибок.
- **Резервные копии:** ежедневно — экспорт базы каждого магазина (DO SQLite) и D1 платформы в отдельный бакет `korzina-backups` (другой аккаунт или регион хранилища); файлы R2 — ежедневная копия новых и изменённых объектов туда же; хранение 30 дней ежедневных + 12 месячных. Проверка восстановления одного магазина из копии на тестовом окружении — обязательна перед запуском и раз в месяц (задача по расписанию с отчётом).
- Выпуск — только по решению Андрея.
