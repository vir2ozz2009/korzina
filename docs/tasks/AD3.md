# AD3 · Серверный журнал и адрес черновика
- **Холст:** редактирование адреса внутри карточки по [§9.12](../specs/seller-admin.md#9-решения-андрея-19112026).
- **Цель:** атомарный серверный журнал (US-AD07) и смена адреса только в статусе черновика (US-AD08).
- **Журнал магазина:** общий слой команд F3 пишет событие в той же транзакции. Задачи S2–S7, O и A передают разрешённую разницу. Хранение 12 месяцев, уборка по alarm (PERFORMANCE правило 23).
- **Готово, когда:** изменение и запись журнала откатываются вместе. Адрес черновика проходит общий валидатор, после открытия заблокирован.
