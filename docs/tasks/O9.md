# O9 · Статистика продаж — **68 (кадры «Статистика · …»), 62 (статистика товара)**
- **Входит:** «Деньги → Статистика продаж»: выручка (выполненные заказы после скидок и проведённых возвратов, по дате выполнения), число заказов, средний чек (округление только при показе; нет заказов — «—»); сравнение с прошлым периодом той же длины (пунктир; ноль в прошлом — без процента; выключается); график с интервалами по длине периода (часы / дни / недели / месяцы), таблица «Данные по дням»; популярные товары в штуках. Статистика товара из его карточки (62): продано, заказы, выручка, фильтр по фасовке. Считается на сервере по таблице дневных итогов магазина (день × показатели, товар × день): обновляется в той же транзакции, что выполнение заказа и проведение возврата (O1, O5); при появлении O9 один раз заполняется из уже выполненных заказов. Не из страниц заказов на клиенте (PERFORMANCE правило 4). Таблица растёт на одну строку в день — уборка не нужна, но её объём — в тесте.
- **Нажимается:** показатель → график этого показателя; точка → значения обеих серий; период → тот же выбор, что в O5; товар → статистика товара с тем же периодом; продажи / число заказов → выполненные заказы за период.
- **Состояния:** по кадрам 68: загрузка и ошибка графика (фильтр доступен), «Нет продаж», «Нет данных для сравнения».
- **Готово, когда:** пример 68: 18 960 против 15 800 = +20 %, 24 против 20 заказов = +20 %; возврат уменьшает выручку того дня, когда заказ выполнен; бюджет SQL — тест.
