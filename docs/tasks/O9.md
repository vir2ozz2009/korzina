# O9 · Статистика продаж — **68 (кадры «Статистика · …»), 62 (статистика товара)**
- **Холст:** нужен.
- **Входит:** «Главная → Статистика»: выручка (выполненные заказы после скидок и проведённых возвратов, по дате выполнения), число заказов, средний чек (округление только при показе; нет заказов — «—»); сравнение с прошлым периодом той же длины (пунктир; ноль в прошлом — без процента; выключается); график с интервалами по длине периода (часы / дни / недели / месяцы), таблица «Данные по дням»; рейтинг всех товаров в штуках. Статистика товара прямо из карточки списка «Товары» (62): продано, заказы, выручка, фильтр по фасовке и недельный ориентир по фактическим продажам (§14.4). Считается на сервере по таблице дневных итогов магазина (день × показатели, товар × день): обновляется в той же транзакции, что выполнение заказа и проведение возврата (O1, O5); при появлении O9 один раз заполняется из уже выполненных заказов. Не из страниц заказов на клиенте (PERFORMANCE правило 4). Таблица растёт на одну строку в день — уборка не нужна, но её объём — в тесте.
- **Нажимается:** карточка «Статистика» → подменю «Статистика продаж» / «Обзор продаж»; одноимённое действие в карточке списка «Товары» → отчёт товара; показатель → график этого показателя; точка → значения обеих серий; период рейтинга → 1–4 недели или свой интервал; товар → статистика товара с тем же периодом; продажи / число заказов → выполненные заказы за период.
- **Состояния:** по кадрам 68: загрузка и ошибка графика (фильтр доступен), «Нет продаж», «Нет данных для сравнения».
- **Решения 24.11.2026** — неполные показатели старых периодов и учёт назначения возврата. [Спецификация §10.2–10.4](../specs/money-and-sales.md#102-отчёт-с-неполной-историей).
- **Не входит:** редактирование остатков, список заказов с недостачей, просмотры и эффекты продвижения, вход из редактора товара или с витрины. Подсказка «Докупить» с учётом нехватки и остатка отложена по [решению Андрея](../specs/money-and-sales.md#144-отчёт-товара).
- **Готово, когда:** сценарии 20–23 в §7 покрывают §14; пример 68: 18 960 против 15 800 = +20 %, 24 против 20 заказов = +20 %; возврат уменьшает выручку того дня, когда заказ выполнен; бюджет SQL — тест.
