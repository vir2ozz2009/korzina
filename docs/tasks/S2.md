# S2 · Товары, фасовки, остатки, фото — **62, финал «40 · Товары»**

- **Figma (справочник Claude):** 62 (`741:55138` и др., см. SCREENS); финал «40 · Товары · карточка, фото и фасовки» (`1414:76656`): «Товары и видимость», «Заканчиваются», «Каталог пуст», «Поиск без результатов», «Новый товар», «Создать категорию из формы», «Остаток без лимита», «Фото прикреплены в форме», «Изменить фото обложки», «Фото не прочиталось», «Все фото удалены», «Фасовки товара», «Скрыта фасовка», «Все фасовки скрыты», «Управление остатком», «Остаток изменил другой сотрудник», «Товар скрыт целиком», «Проверить обязательные поля», «Выйти без сохранения», «Полная карточка глазами покупателя».
- **Истории:** M02, M03.
- **Холст:** нужен.
- **Входит:**
  - **Список товаров:** поиск; фильтры «На витрине / Скрытые / Заканчиваются»; строка — фото, название, цена, остаток, видимость; массовая смена наличия; «Добавить товар».
  - **Одна форма создания и редактирования:** название, описание, состав и хранение; категория (можно **создать новую прямо из формы**), бренд; фото (F9, `PhotoPicker`): порядок перетаскиванием, первое — обложка, новые в конец, предпросмотр плиткой витрины (`photos.md` §3); цена и старая цена; **фасовки** — название (повтор в товаре — ошибка у поля, DOMAIN «Каталог»), цена, остаток или «без лимита», видимость каждой фасовки; рекомендации «выключены / автоматически / выбрать вручную (до 12)» (47).
  - **Видимость:** скрыть товар целиком или отдельную фасовку (остальные остаются); «Все фасовки скрыты» = товар не на витрине.
  - «Посмотреть глазами покупателя» — карточка витрины.
  - Изменения сразу на витрине; сохранение — как в S6 (полоса «Несохранённые изменения», «Выйти без сохранения?»).
- **Нажимается:** строка → форма; «Добавить товар»; фильтры; массовая смена наличия; фото → просмотр, перетаскивание, удаление; «+ фасовка»; «Создать категорию»; «Сохранить» / «Отменить»; «Посмотреть на витрине».
- **Не входит (не рисовать):** статистика товара (O9); отзывы и рейтинг (A2); акционная цена в рамках акций (A1, A11); изготовление на заказ (A8); импорт и экспорт (AD4, A13).
- **Отличия от Figma:** сохранение без черновика и публикации (решение 18.11.2026, как S6).
- **Данные (API):** список товаров продавца (курсор, фильтры, поиск по индексу); `GET` товара; команды «создать», «изменить» (с ревизией), «видимость», «остаток» (массово); фото — F9; ошибки `VALIDATION` (поле), `DUPLICATE_VARIANT_NAME`, `VERSION_CONFLICT` («Остаток изменил другой сотрудник»).
- **Состояния:** загрузка; каталог пуст; поиск без результатов; нет заканчивающихся; ошибка загрузки; фото не прочиталось (HEIC и др.); обязательные поля не заполнены; не удалось сохранить; конфликт ревизии; без права — только просмотр.
- **Готово, когда:** скрытая фасовка не видна покупателю и не попадает в корзину (тест); повтор названия фасовки отклоняется (тест); конфликт ревизии не теряет введённое; изменения видны на витрине сразу (кеш каталога сбрасывается, PERFORMANCE); Андрей проверяет HEIC и загрузку фото с телефона.
