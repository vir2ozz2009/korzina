# R2 · CI на черновиках и незавершённое на demo (≈25 минут, перед B3b)
- `.github/workflows/check.yml` и `e2e.yml`: `types: [opened, synchronize, reopened, ready_for_review]` и условие `if: github.event.pull_request.draft == false` у задач. `concurrency` с отменой устаревшего прогона — оставить.
- **Незавершённое на demo — отменено** (решение Андрея 18.11.2026, `design-system/components.md` «Элементы будущих блоков»): элементы будущих блоков не показываются нигде; `Unfinished`, `HomeUnfinished` и `SHOW_UNFINISHED` убираются из кода (PROGRESS «Мелкие правки»).
- **Готово, когда:** пуш в черновой PR не запускает `Check`; перевод в «Ready for review» запускает один раз.
