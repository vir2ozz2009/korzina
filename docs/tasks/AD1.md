# AD1 · Вход администратора, список и создание магазина
- **Холст:** нужен — экраны админки новые (Figma нет; вид — по шаблонам `list` и `form`).
- **Цель:** роль `platform_admin` в D1 и команда `npm run admin:grant`; раздел `/admin` с проверкой роли; список магазинов; мастер создания из трёх шагов и экран результата с приглашением.
- **Важно:** мастер вызывает тот же серверный сервис `createShop`, что и `npm run shop:create` из F2. Если в F2 логика живёт только в CLI — сначала вынести её в `server/platform/` (без изменения поведения CLI), затем подключить к API. Вторую реализацию создания магазина не писать.
- **Читать:** `stories/platform-admin.md` (US-AD01–03), ARCHITECTURE §4–7, `design-system/navigation.md` «Админка платформы».
- **Готово, когда:** на demo Андрей создаёт магазин через `/admin`, получает ссылку-приглашение, продавец входит по ней в кабинет; тесты: без роли — `FORBIDDEN`, двойное создание — один магазин, занятый и зарезервированный slug отклоняются, в D1 хранится только хеш приглашения.
