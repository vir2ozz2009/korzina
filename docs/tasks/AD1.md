# AD1 · Доступ администратора, реестр и создание магазина
- **Холст:** [блок 4, §9.12](../specs/seller-admin.md#9-решения-андрея-19112026).
- **Цель:** отдельный доступ администратора по D15 из профиля покупателя, реестр `/admin` и раскрываемая в нём форма «Название», «Адрес витрины», «Страна». Устаревшая сессия возвращается через B9.
- **Важно:** форма вызывает тот же серверный сервис `createShop`, что и `npm run shop:create` (F2). Если логика живёт только в CLI, вынести её в `server/platform/` и сохранить поведение CLI.
- **Читать:** US-AD01–03, ARCHITECTURE §4–7, `design-system/navigation.md` «Админка платформы».
- **Готово, когда:** Андрей создаёт черновик, попадает в карточку и передаёт приглашение. Повтор команды создаёт один магазин. Занятый и зарезервированный адрес отклоняются. Без допуска D15 пункта в профиле нет, сервер отвечает `FORBIDDEN`. В D1 хранится хеш токена приглашения.

Индекс задач и блоков — [`docs/PLAN.md`](../PLAN.md). Шаблон карточки — [`README.md`](README.md).
