# Шаблоны экранов

Каждый экран в `navigation.md` использует один шаблон. Шаблон — компонент в `src/app/templates/`, который уже содержит шапку, область прокрутки, закреплённый низ, safe-area и состояния (загрузка, пусто, ошибка с повтором). Экран передаёт ему только данные и содержимое слотов.

Восемь шаблонов покрывают все 100 экранов первой версии. Новый шаблон — только решением Андрея.

## Общие правила шаблонов

- Шапка: `back` (стрелка; в Telegram прячется, работает BackButton), заголовок, до двух иконок действий. На корнях вкладок — без стрелки.
- Закреплённый низ поднимается над клавиатурой и над нижней панелью вкладок; учитывает safe-area.
- Состояния данных показывает `QueryBoundary` шаблона: скелетон по форме слотов → данные | пусто (`EmptyState` с действием) | ошибка (`ErrorState` + «Повторить»). Экран не рисует их сам.
- Команды (сохранить, оформить, сменить этап) показывают ожидание на кнопке; ошибка — тост или текст под кнопкой, введённые данные не теряются.
- Ширина: на телефоне 100%; на десктопе колонка `max-w-[480px]` по центру до задачи A16.
