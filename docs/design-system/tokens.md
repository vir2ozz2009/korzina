## Сетка и размеры

- Экран 390: боковой отступ 12, между секциями 12 (на главной 14), сетка товаров — 2 колонки, зазор 8.
- Карточка-секция: белая, `rounded-xl` (24), внутренний отступ 16 (кабинет) / 20 (корзина, крупные блоки).
- Управляющие элементы: 44 — стандарт (кнопка, иконка-кнопка, капсула цены, поле); 48 — закреплённая покупка и плавающие кнопки; 60 — CTA с подзаголовком; 36 — малый степпер в строке корзины. Иконка 22 внутри кнопки 44.
- Кнопки и капсулы — всегда `rounded-pill`. Фото — `rounded-md` (16). Плитки категорий и брендов — `rounded-lg` (20).
- Тени нет у карточек (белое на сером). Тень `shadow-float` — только у плавающих кнопок и закреплённой панели при прокрутке под ней.

## Оформление магазина: пресет или свой цвет

Продавец выбирает цвет витрины в **Настройки → Оформление витрины** (`/seller/settings/appearance`): один из пресетов или **свой цвет из палитры**. Код — `src/shared/theme-presets.ts` (единственный источник); в settings магазина хранится `ShopTheme`: `{ preset: "herb" }` или `{ custom: "#1e88e5" }`.

**Что меняется.** Только акцентные токены витрины: `--primary`, `--primary-foreground`, `--primary-soft`, `--primary-strong`, `--primary-text`, `--ring`. Нейтральные цвета, шрифт, радиусы, размеры, цвета статусов — общие для всех магазинов. Кабинет продавца всегда в цветах Korzina.

**Свой цвет — продавец задаёт один цвет, остальное вычисляется** (`deriveTheme`), поэтому витрина читаема при любом выборе:
- текст на кнопке: белый, если контраст ≥ 3:1 (как у пресетов), иначе тёмный `#1a1a1a` (≥ 4.5:1) — например, жёлтые кнопки получат тёмный текст;
- `--primary-text` (акцентный текст на белом: цена со скидкой, «+» в капсуле): сам цвет, если контраст ≥ 3:1, иначе затемнённый до ≥ 4.5:1;
- `--primary-strong`: затемнённый до ≥ 4.5:1 с белым; `--primary-soft`: 8% цвета на белом;
- почти белые цвета (контраст с белым < 1.3) не принимаются (`validateCustomColor` на клиенте и сервере): кнопки слились бы с карточками.

**Правила для компонентов** (без них свой цвет сломает витрину):
- заливка акцентом → `bg-primary` + текст `text-primary-foreground` (никогда не `text-white`);
- акцентный текст на светлом фоне → `text-primary-text` (не `text-primary`);
- мягкая подложка → `bg-primary-soft`; акцентные ссылки → `text-primary-strong`.

**Применение.** Worker при отдаче HTML витрины ставит `style="<themeStyle(theme)>"` на `<html>` — цвет верный с первого кадра; клиент применяет то же значение из `GET /api/shop`. В MagicPath тема «Korzina» = пресет «Малина»; в `/dev/kit` есть переключатель пресетов и поле своего цвета для проверки всех компонентов.
