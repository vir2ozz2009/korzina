# Эталонные экраны

Три экрана показывают все повторяющиеся паттерны витрины. Остальные экраны собираются «как эталон, только с другими данными и слотами». Для кабинета эталон — карточка заказа (632:51098): тот же язык карточек-секций на сером фоне.

Разбор: шаблон → слоты → компоненты кита. Чего нет в первой версии — помечено «позже».

## 1. Главная — шаблон `home` · 311:19906

Фон `background`. Шапка закреплена, контент прокручивается под ней, отступы 12, между секциями 14.

| Слот | Содержимое |
|---|---|
| header | `StoreHeader` (адрес → `/checkout/address`; логотип → `/about`; чат → `/chats`; аватар → `/profile`). Ниже — истории (позже, A3) |
| sections[0] | Вход «Любимый товар» (`ListItem compact`) — позже, A5 |
| sections[1] | `SectionHeader` «Категории · Все ›» + мозаика `CategoryTile` с горизонтальной прокруткой. В первой версии раскладка автоматическая (крупные — первые категории); настройка геометрии продавцом — позже |
| sections[2] | `SectionHeader` «Товары» + сетка `ProductTile` 2 колонки |
| sections[3] | `SectionHeader` «Бренды · Все ›» + лента `BrandTile` (если есть бренды с доступными товарами) |
| sections[4] | `ListItem card` «О магазине ›» с подписью «Контакты, часы работы и условия получения» |
| поверх | `FloatingActions`: «Поиск» (в макете «Нейропоиск» — в первой версии обычный поиск) и «Корзина · сумма» |

Пусто (нет товаров): `EmptyState` «Магазин готовит витрину». Ошибка: `ErrorState` на весь контент, шапка остаётся.

## 2. Карточка товара — шаблон `product` · 364:24000

Фон `card`. Контент: отступы 12, зазор 16.

| Слот | Содержимое |
|---|---|
| header | `Header` на белом: назад, название магазина, «Поделиться», «В избранное» (сердце, заполненное при выбранном) |
| gallery | `Gallery` квадрат |
| info | название `title-1`; фасовка `text-meta` subtle; ссылка на бренд/категорию `text-label` muted «Лавка ›»; `Price display`; «Всего доступно N шт.» `text-caption` subtle (только если остаток учитывается и меньше 10); выбор фасовки `ChipGroup` (если >1); описание `text-body` `foreground-body`; `Button secondary md full` «Подробнее о товаре ›» → `Sheet` |
| related | `SectionHeader` «С этим покупают» + 2 `ProductTile` (позже настраивает продавец; в первой версии — товары той же категории) |
| buyBar | `StickyFooter` (белый, скруглённый верх) + `AddToCart lg` на всю ширину |

Скрытый или удалённый товар по ссылке: `EmptyState` «Товар больше недоступен» + «На главную».

## 3. Корзина — шаблон `checkout` · 90:5839

Фон `background`. Карточки-секции `Card lg` с зазором 12.

| Слот | Содержимое |
|---|---|
| header | В макете заголовок «Корзина» и × внутри первой карточки. В шаблоне: `Header` с заголовком «Корзина» и закрытием (= назад) — единообразно с остальными экранами |
| sections[0] | Кнопка `secondary md full` «Укажите адрес доставки» (или выбранный адрес и способ получения) |
| sections[1] | «Ваш заказ» `title-2` → `ProductRow cart` × N → `Divider` → строка «Доставка · 50 ₽» (сумма с сервера; если неизвестна — «рассчитает магазин») |
| sections[2] | Промокод `InputWithAction` — позже, A1 |
| sections[3] | «Любимый товар» — позже, A5 |
| предупреждения | Над «Ваш заказ»: изменилась цена / нет в наличии (`ListItem` с `StatusPill warning`) |
| cta | `StickyFooter` на сером + `Button primary xl full` «Продолжить · 239 ₽» / подзаголовок «К адресу и времени» |

Пусто: `EmptyState` «В корзине пока пусто» + «В каталог».

## 4. Как собирать остальные экраны

1. Найди экран в `navigation.md` → шаблон и эталон.
2. Открой эталон в Figma, разложи на слоты шаблона как в таблицах выше.
3. Каждый элемент — компонент кита. Нет подходящего → сначала в кит и `/dev/kit`, потом в экран.
4. Значения из макета, которых нет в токенах, сводятся по таблице нормализации `tokens.md`.
