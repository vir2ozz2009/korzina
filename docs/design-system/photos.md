# Фото товаров и категорий

**Решение Андрея, 17.11.2026:** вырезку фона не делаем. Исходник сохраняется. При показе можно скрыть пустые поля вокруг предмета. **Предмет на фото никогда не обрезается и не растягивается** (одобрено Андреем на ревизии B2, 17.11.2026): `object-contain`; единый вид дают цвет краёв, рамка предмета и мягкий край — без обработки пикселей фото.

## 1. Хранение (F9)

- Одно фото — один исходный вариант (после сжатия, конвертации HEIC и очистки EXIF) плюс размеры для показа (160, 400, 800, 1600).
- Никаких вариантов «без фона», полей `display`, оценки качества вырезки.
- Два поля, вычисляются **один раз при загрузке в браузере** (PhotoPicker, уменьшенная копия), сервер фото не обрабатывает; для сида — в сиде:
  - `edgeColor` — средний цвет пикселей по периметру (hex). Нет — белый.
  - `contentBox` — рамка предмета `{x, y, w, h}` в долях: границы, где пиксели отличаются от `edgeColor` больше порога (~12 по каналу), плюс отступ 4%. Нет — всё фото.

## 2. Показ (F11, ждёт одобрения на холсте)

- Плитка товара, строки корзины и заказа, галерея и плитки категорий используют `contain`. У `ProductImage` нет варианта `fit="cover"`. Плитка товара и галерея используют квадрат 1:1 (`shape="square"` по умолчанию).
- Сначала убираем пустые поля по `contentBox`. Если рамка предмета отсутствует, используем всё фото. Вписываем результат по центру с полем 8% с каждой стороны. Предмет занимает около 85% рамки по ограничивающей стороне.
- Масштаб равен минимуму из коэффициента вписывания (84% ширины и высоты зоны) и ×2 от исходного размера рамки предмета. Если предел ×2 срабатывает, предмет занимает меньшую долю и остаётся по центру.
- Рамку товара заливаем `edgeColor` текущего фото. Края самого фото растворяются в фон на 10 px с помощью `mask-image`. Пока фото загружается, используем `bg-input`. При смене кадра галереи фон берём из нового кадра.
- Плитка категории остаётся белой (`card`). В форматах 1×1 и 1×2 зона фото находится под подписью, в форматах 2×1 и 2×2 — справа на высоту плитки с отступом 8 px. Подпись вверху слева занимает до двух строк. Зона изображения учитывает область подписи. Фото вписывается по тому же правилу масштаба и занимает около 85% зоны по ограничивающей стороне при любом формате. Фото прижато к низу, у широких плиток — к правому нижнему углу. Края растворяются в белый фон маской около 8 px. Текущая сетка и иконка при отсутствии фото сохраняются.
- Полноэкранный просмотр показывает исходное фото целиком через `contain` на тёмном фоне с жестом увеличения.

## 3. Продавцу (S2, S3)

- При загрузке — предпросмотр фото в настоящей плитке витрины, чтобы было видно, как фото впишется.
- Подсказка в форме: «Лучше всего — товар крупно, по центру, при дневном свете; фон белый или однотонный».
- Для демо-сида выбираем фото с предметом по центру на белом фоне. Заменяем курицу на бумаге и томаты с фоном до краёв. Пересчитываем `edgeColor` и `contentBox` для каждого фото сида, включая дополнительные кадры галереи.
- Картинка категории — фото первого товара категории по умолчанию или своё фото.
