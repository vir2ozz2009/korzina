# Фото товаров и категорий: единый вид при любых фото продавцов

Проблема: продавцы снимают на разном фоне (белый, кремовый, стол, ладонь). Если вставлять такое фото в белую или серую карточку, видна «рамка в рамке» и разнобой оттенков.

Решение: каждое фото товара хранится в двух вариантах, а компонент сам выбирает режим показа.

## 1. Два варианта при загрузке (F9)

- **`original`** — исходное фото (после сжатия и очистки EXIF).
- **`cutout`** — объект без фона (прозрачный PNG/WebP), создаётся **один раз при загрузке** через Cloudflare Images `segment=foreground` и сохраняется в R2 рядом с оригиналом. На лету фон не вырезаем — это дорого и медленно.
- Сервер оценивает качество вырезки (доля непрозрачных пикселей, объект не обрезан краем кадра). Плохая вырезка (пустая, «рваная», объект во весь кадр) → `cutout` не предлагается.
- В `media` хранится режим показа: `display: "cutout" | "photo"`. По умолчанию — `cutout`, если вырезка хорошая, иначе `photo`.

## 2. Как показываем (компонент `ProductImage`)

| Режим | Как выглядит | Где |
|---|---|---|
| `cutout` | Объект без фона, `object-contain`, по центру, с внутренним отступом ~8%, на фоне контейнера `bg-input` (на белой карточке) | Плитка, строки корзины и заказа, галерея, плитка категории |
| `photo` | Фото целиком заполняет контейнер, `object-cover`, без внутренней рамки и полей; скругление только у контейнера | Те же места, когда вырезки нет (фото на столе, «атмосферные» снимки) |
| Полноэкранный просмотр | Всегда `original`, `object-contain` на тёмном фоне, жест увеличения | По нажатию на галерею |

- Форма и скругления задаются контейнером: строки/корзина/заказ — квадрат 80×80 `rounded-md`, галерея — квадрат `rounded-xl`, плитка — 179×142 `rounded-md`; `overflow-hidden`. У изображения нет своего скругления или рамки, оно занимает 100% ширины/высоты.
- Для каждого размера контейнера передаются `srcset`/`sizes` с источником ≥2×, без апскейла маленького оригинала.
- Внутри одной ленты (главная, категория) все плитки одной высоты и с одним фоном контейнера — разные режимы рядом выглядят единообразно.
- Плитка категории: картинка — `cutout` выбранного товара, внизу справа, как в макете 45 (мозаика). Если продавец не выбрал картинку категории — берётся `cutout` первого товара категории с хорошей вырезкой; если таких нет — нейтральная иконка категории, без пустой белой плитки.

## 3. Что видит продавец (S2, S3)

- После загрузки — предпросмотр «Без фона» / «Как есть» в виде настоящей плитки витрины; выбран рекомендуемый вариант, продавец может переключить.
- Подсказка в форме: «Лучше всего — товар крупно, на однотонном фоне, при дневном свете».
- Для картинки категории — выбор товара из категории или загрузка своего фото (тоже с вырезкой).

## 4. Ограничения

- Вырезка — бета-функция Cloudflare; если она недоступна или вернула ошибку, фото показывается в режиме `photo`, загрузка не падает.
- Вырезка тарифицируется как преобразование изображения, но выполняется один раз на фото при загрузке.
- Демо-данные (сид B1) — сразу с вырезанными версиями.
