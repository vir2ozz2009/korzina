## Окружение demo

По решению владельца Korzina развивается как самостоятельная платформа, которая может заменить Lavka. До отдельного решения публикуем только на `demo.korzina.app`. Целевой источник публикаций — `main` репозитория `vir2ozz2009/korzina`; схема Workers Builds и команды подключения описаны в README. Worker `korzina-demo` создан отдельно, без bindings на существующие сервисы. Основной домен и приложения Lavka не менялись.

Закреплены совместимые версии `cf` и Cloudflare Vite plugin: незакреплённый plugin rc генерировал Build Output v1, который установленный cf ещё не читает. Проверены TypeScript, сборка Vite и dry run чтения 20 файлов из Build Output v0 (включая служебный файл assets). Ссылка «Поделиться» использует адрес текущего магазина вместо MagicPath.

Продолжение публикации 16.11.2026: рабочая копия обновлена fast-forward до `c1130875c96541f520991e6b93297dbdfe32775d` из `origin/main`. Повторная установка зависимостей с доступным для записи кэшем (`npm ci --cache /workspace/.npm-cache --no-audit --no-fund`), TypeScript, сборка Vite и dry run прошли на Node.js 24.22.1. Build Output содержит 20 файлов, bindings отсутствуют.

Через плагин Cloudflare выполнено подключение Custom Domain `demo.korzina.app` к `korzina-demo`, затем привязка повторно прочитана через API. До изменения на этом имени не было DNS-записей. Эта запись отправляется в `main` для проверки автоматического запуска без ручного API-триггера. Результат следует проверять в Workers Builds по соответствующему commit hash и источнику `push`. Автопубликация подтверждается только успешной сборкой от push, а не одной настройкой.

Публикация подтверждена логами Builds и API deployment; проверка HTTP и браузерного сценария на домене остаётся незавершённой из-за описанных сетевых ограничений. Нужно открыть магазин и проверить изображения, фото 1/2, избранное, количество с лимитом, переход в каталог и корзину, пересчёт и восстановление после перезагрузки. Не переносить проверку прототипа MagicPath на опубликованный домен без отдельного прохода.
