# Как добавить новую функцию (после первой версии)

1. **История.** Новая строка в `stories/README.md` + критерии приёмки в файле раздела (или в `later.md` → перенести в раздел). Без критериев не начинаем.
2. **Нарезка.** Функция больше одной задачи → режем на части, каждая полезна сама по себе (сначала сервер и правило, потом экран покупателя, потом настройка продавца). Части — в `PLAN.md`.
3. **Флаг.** Новый ключ в `src/shared/flags.ts`:
   - `kind: 'addon'` — подключается магазину по запросу навсегда;
   - `kind: 'rollout'` — базовая функция, которую выкатываем постепенно: `off` → пилотные магазины → все → флаг удаляется отдельной задачей.
   Любой флаг — аварийный выключатель: выключение прячет функцию, данные не удаляются.
4. **Срез.** Код только в `src/features/<x>`, `server/modules/<x>`, `src/shared/contracts/<x>.ts`. Экраны — из `src/ui` и шаблонов; дизайн — через холст MagicPath (`DESIGN.md` §5).
5. **Описание магазина.** Если функция хранит настройки или данные магазина — добавить их раздел в `shop-spec.ts` (CONVENTIONS «Описание магазина»), чтобы магазин с этой функцией собирался из файла.
6. **Расходы.** Нужен платный сервис или функция — сначала решение по `COSTS.md` (варианты с ценой на 1 / 10 / 100 магазинов), потом код.
7. **Проверки.** Тесты на каждое правило истории; `npm run check` (включая `check:arch`).
8. **Выпуск.** Влили в `main` → demo. Включили флаг пилотному магазину → проверили → раскатили.
9. **Запись.** Статус истории, строка в `PROGRESS.md`; если функция — `addon`, строка в таблице флагов `ARCHITECTURE.md` §6 не нужна: реестр — `flags.ts`.

Раз в 10 задач — задача-аудит: `check:arch` и `knip` без исключений, нет дублей компонентов и логики, нет мёртвых флагов `rollout` и демо-кода, бюджет размера сборки соблюдён и цель опущена храповиком (PERFORMANCE.md §7), реестр `COSTS.md` актуален (прогноз ₽/мес на 1 / 10 / 100 магазинов), документы соответствуют коду. В отчёт — таблица: строк кода по разделам, крупнейшие файлы, зависимости, размер JS, число тестов и время `check` — с прошлым аудитом для сравнения.
