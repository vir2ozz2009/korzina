## Сценарии приёмки

| История | Карточка | Проверка |
|---|---|---|
| [US-A01](../specs/promo-discounts.md#7-приёмка) | [A1](../tasks/A1.md) | Выбор цели и «Все виды акций» открывают общие формы. У точного номера заказа есть разовое право с оформления; результаты в карточке учитывают выполненные заказы. При равной выгоде выигрывает автоскидка; проигравший код остаётся введённым и не расходуется. Два одновременных оформления на последнее применение не превышают лимит. Отключение меняет открытую корзину, оформленный заказ сохраняет итог. |
| [US-A01b](../specs/promo-quantity-and-bundles.md#7-приёмка) | [A1b](../tasks/A1b.md) | Для N=2 и M=1 две единицы не дают подарок, из трёх подходящих бесплатна самая дешёвая. Проверить две группы, лимит и удаление единицы. |
| [US-A11](../specs/promo-quantity-and-bundles.md#7-приёмка) | [A11](../tasks/A11.md) | Проверить комплект и корзину с тем же общим количеством, но другой фасовкой; после удаления обязательной позиции сумма пересчитана, причина видна. |
| [US-A06](../specs/promo-free-delivery.md#7-приёмка) | [A6](../tasks/A6.md) | Переход через порог в обе стороны обновляет остаток и доставку. Единственный введённый код доставки совместим с автоматической скидкой на товары; поздний тариф использует сохранённый резерв по условиям оформления. |
| US-A04 | [A4](../tasks/A4.md) | Повтор события не удваивает начисление. При отмене освобождается резерв, при возврате одной строки восстанавливается только её доля. Проверить округление начисления вверх и максимума списания вниз. |
| US-A05 | [A5](../tasks/A5.md) | Выбор сохраняется при повторном входе. После исключения товара доступен другой выбор; после выключения скрыты входы, открытая корзина пересчитана. |
| US-A13b | [A13b](../tasks/A13b.md) | Сверить историю и показатели с заказами тестового покупателя; проверить поиск по телефону и попытку открыть карточку другого магазина. |
| US-A12 | [A12](../tasks/A12.md) | Другой покупатель не получает выгоду по чужому коду. После отзыва причина видна в корзине; бот учитывает настройку уведомлений. |
| US-A09 | [A9](../tasks/A9.md) | До выполнения условия награды нет. После выполнения сверить скидку другу и награду пригласившему; повтор события не создаёт вторую награду. |
| US-A07 | [A7](../tasks/A7.md) | Изменение расписания согласованно отображается у обеих ролей. Повтор обработки одного срока не создаёт дубликат. Для обычной покупки скидка за расписание недоступна. |
| US-A14 | [A14](../tasks/A14.md) | До публикации покупатель видит прежний порядок. После успешной публикации видит новый; ошибка сохраняет последнюю опубликованную версию. |
| US-A03 | [A3](../tasks/A3.md) | Проверить путь от публикации до карточки доступного товара; черновик скрыт у покупателя, недоступная позиция не добавляется в корзину. |
| US-A12b | [A12b](../tasks/A12b.md) | Публикация акции сама не запускает рассылку. Рост аудитории требует подтверждения; повтор временной ошибки не дублирует успешную доставку. Уточнить границы отзыва уже отправленного сообщения в спецификации. |
| US-A02 | [A2](../tasks/A2.md) | Проверить право по чужому заказу; после смены видимости сверить список публичных отзывов и рейтинг по согласованному правилу. |
| US-A08 | [A8](../tasks/A8.md) | Покупатель и продавец видят одну заявку и одни условия; повтор отправки не создаёт вторую заявку. Момент превращения заявки в заказ зафиксировать в спецификации. |
| US-A10 | [A10](../tasks/A10.md) | Повтор подтверждения не удваивает позиции. При смене статуса между просмотром и подтверждением сервер повторно проверяет допустимость; при отказе сохраняет корзину. |
| US-A13 | [A13](../tasks/A13.md) | Открыть файл и сверить позиции, остатки и заказы с исходными данными. Проверить пустой магазин и попытку получить чужую выгрузку. |
| US-A15 | [A15](../tasks/A15.md) | Проверить на одном и пяти товарах выбор фасовки, количество и итог корзины. На границе с обычным каталогом позиции корзины сохраняются. |
| US-A16 | [A16](../tasks/A16.md) | Проверить обе роли на широкой и мобильной ширине; смена ширины сохраняет выбранный заказ и содержимое корзины. |
| US-A17 | [A17](../tasks/A17.md) | Проверить вход на втором устройстве и доступ только к своим данным; совпадение неподтверждённого контакта не открывает чужие заказы. |
| US-A18 | [A18](../tasks/A18.md) | Проверить установку и повторный запуск, получение уведомления и переход в нужный заказ. После отзыва доступа устройство не получает данные магазина. |
