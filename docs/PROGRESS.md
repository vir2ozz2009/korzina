Принципы: проверяем **поведение, а не вид** (снимков пикселей нет — TESTING §7); данные — демо-магазин `test2`, время заморожено; каждый тест назван по правилу или строке приёмки спецификации (`П2`, `§7.5`), чтобы его можно было удалить вместе с правилом; без повторов в цикле и без `retries`. Один PR «test: главная и корзина», Codex «Высокое». Источники: `docs/specs/catalog.md` §6–§7, `docs/specs/purchase.md` (корзина §3.1, §5–§7), `docs/PERFORMANCE.md` §6, `docs/TESTING.md`.
