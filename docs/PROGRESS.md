## F1 · Проверки и решения

- `check:arch`: токены вместо цветов и px-классов, границы импортов, лимит 250 строк, отсутствие прямого API в маршрутах и арифметики денег в фичах. Есть тесты на разрешённый код и нарушения.
- API проверяется в Workers runtime через `@cloudflare/vitest-plugin` — актуальное имя пакета `@cloudflare/vitest-pool-workers`.
- Локальный браузер: 390 × 844, страница Korzina и перезагрузка без ошибок JavaScript и горизонтальной прокрутки; health 200, неизвестный API 404. У F1 нет переходов, загрузки данных и продуктовых состояний.
- Сохранён путь Workers Builds: `npm run build` → `npx cf deploy --prebuilt`. Для существующего `cloudflare.config.ts` нужны `cf@1.0.0-rc.0` и `@cloudflare/vite-plugin@2.0.0-rc.0`; это исключение из правила стабильных версий ради совместимости с настроенным деплоем. Остальные зависимости стабильные, версии закреплены в `package-lock.json`.
- MagicPath: не применяется к F1, макет и ревизия не создавались. Историй F1 в индексе нет; статусы историй не менялись.
- Осталось: автоматическая сборка и проверка на demo после push в `main`.
