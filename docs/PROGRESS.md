Для существующего `cloudflare.config.ts` нужны `cf@1.0.0-rc.0` и `@cloudflare/vite-plugin@2.0.0-rc.0`; это исключение из правила стабильных версий ради совместимости с настроенным деплоем. Остальные зависимости стабильные, версии закреплены в `package-lock.json`.
