## Как вести этот файл

- Здесь только: текущая задача, следующий шаг, одна строка на задачу (статус, 1–2 предложения итога, ссылка на коммит, время по часам). Файл читается в начале каждого чата — держи его до ~6 КБ.
- Подробный отчёт задачи (решения, проверки, ID ресурсов, замеры) — `docs/progress/<ID>.md`, не длиннее 60 строк. Его не читают по умолчанию.
