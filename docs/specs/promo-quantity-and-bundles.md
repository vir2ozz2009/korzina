# 12.2 · Количество в подарок и комбо-наборы

## 0. Рамки

[A1b · N+M](../tasks/A1b.md) → [A11 · Комбо](../tasks/A11.md), один холст и одна приёмка подблока. Оба вида появляются в действующем разделе «Продвижение». Применяются [общие экраны и контракты 12.1](promo-discounts.md), [правила продвижения](../stories/promo.md) и [сквозные примеры](../progress/block-12-preparation.md).

## 1. Путь

«Акции» → «Создать акцию» → «Увеличить сумму заказа» или «Все виды акций» → «2+1» или «Комбо-набор» → форма → проверочная корзина → публикация → карточка предложения. «Назад» возвращает введённые условия, черновик после повторного открытия загружается с сервера. Из фильтра списка возвращаемся в тот же фильтр. Прямой вход защищён теми же правами, что и список.

Покупатель добавляет фасовки обычным способом. Подходящая группа автоматически получает подарок. Для комбо покупатель вводит код в уже существующую строку корзины. Нажатие на объяснение скидки показывает состав, количество и фактически применённые цены. Возврат сохраняет корзину.

В карточке действующей акции общие строки и переходы по [спецификации результатов](promo-discounts.md#11-результаты-предложения), для подарка и набора — показатели §10 той же спецификации.

## 2. Данные

Расширить предложение из 12.1. Для N+M хранить целые N и M больше нуля, селектор подходящих фасовок и опциональный лимит полных групп **на заказ**. Для комбо — точные variantId, требуемое количество каждой фасовки, положительная цена комплекта в валюте магазина, код и версия. Позиции одной фасовки суммировать по количеству. Из серверного расчёта — зачтённые единицы, подарки, недостающее количество, основание, распределённые суммы и итог. Фасовка вне продажи или без остатка не заполняет группу. Удалённая фасовка старого заказа остаётся в его снимке.

Скелетон, пусто, сеть и повтор, изменение версии, запрет повторного нажатия и возврат фокуса — по [12.1 §3](promo-discounts.md). Для количества — цифровая клавиатура. Подарок и недостача подписаны словами. При двух одинаковых единицах с разной итоговой ценой видны обе цены и соответствующие количества.

## 4. Сервер и команды

Сохранение, проверочный расчёт, публикация и отключение расширяют команды 12.1. Проверить магазин, роль, флаг, версию, валюту, состав и количества. Код комбо занимает общее пространство кодов. Расчёт только читает условия. Оформление атомарно проверяет доступность полных групп и сохраняет назначение скидки на каждую единицу, суммы и применение кода. Использовать существующие версию расчёта, ключ повтора, лимиты и [бюджет запросов](../PERFORMANCE.md). Изменение цены, остатка, состава, срока или кода сбрасывает расчёт текущей корзины. Уведомления о публикации в блок не входят.

## 5. Ошибки и восстановление

| Причина | Что показать / действие |
|---|---|
| Пустой состав, нулевое N/M/количество, повтор фасовки в форме | Подсветить строку, вернуть фокус для исправления; для уже выбранной фасовки редактировать её количество |
| Исчерпан остаток / пропала фасовка | Вернуть свежий состав и объяснение возле строки. При росте итога запросить подтверждение покупки по B10 |
| Неполный комплект, проигрыш автоматики, неверная замена | Для неполного комплекта назвать недостающее, для проигрыша — «Скидка магазина выгоднее». Неверная попытка замены сохраняет прежний код. Ноль расходов до фактического применения |
| Конфликт версии / нет сети | Предложить обновить условия или повторить. Старый ответ и повтор публикации не подменяют действующее предложение |

## 6. Правила

1. Для N+M сервер сортирует подходящие единицы по обычной цене по убыванию, при равенстве использует стабильный идентификатор фасовки. Разбивает на полные группы из N+M. В каждой M самых дешёвых бесплатны. При ограничении брать группы по тому же порядку. Одна единица не участвует в двух выигравших группах.
2. Один код комбо даёт цену на **один полный комплект за заказ**. Остаток корзины, включая второй полный комплект, оценивается по своим правилам. Фасовки сопоставлять по идентификаторам. Цена комплекта не увеличивает сумму покупателя.
3. При пересечении рассматривать комплект целиком и совместимые предложения на остальных единицах. Сравнивать итог покупателя с доступной доставкой. При равенстве сначала цена по акции, затем автоматическое предложение перед ручным. Цена товара со скидкой, подарок и доля скидки комбо не складываются на одной единице.
4. Для набора зафиксировать стоимость его строк пропорционально обычным ценам по правилу распределения 12.1; в снимке сохранять количество и оплаченные доли. Денежный возврат по строке использует сохранённую долю. Отключение акции или удаление фасовки не пересчитывает проведённую продажу.

## 7. Приёмка

| № | Дано → действие → результат | Где |
|---|---|---|
| 1 | Багет 200 ₽, масло 150 ₽ → 350 ₽; добавить круассан 100 ₽ → 350 ₽ и круассан в подарок. Убрать масло → 300 ₽ | холст, smoke |
| 2 | Цены 200/190/180/100/90/80 ₽, любая последовательность → подарки 180 и 80 ₽, к оплате 580 ₽. При лимите одна группа → 660 ₽. Проверить также N=1, M=2 | сервер-тест, холст |
| 3 | В составе набор с фасовкой 500 г → заменить на 250 г при том же числе единиц → комплект неполный. Вернуть фасовку → виден новый итог, товар не добавляется сам | холст, smoke |
| 4 | Две одинаковые тройки по 450 ₽, цена комбо 320 ₽, других акций нет → 320 + 450 = 770 ₽. При активном 2+1 сравнить вариант комбо + подарок (670 ₽) с двумя автоматическими группами (подарки 150 и 100 ₽). Итог 650 ₽, код не расходуется | холст, сервер-тест |
| 5 | Набор 200 + 100 за 240 ₽ → доли 160 и 80 ₽. Возврат второй позиции → 80 ₽ по снимку; частичный возврат не восстанавливает код. Для бесплатной единицы денежный возврат по ней 0 ₽ | сервер-тест |
| 6 | На остатке две единицы из трёх → пересчитать без подарка; одновременное оформление или повтор запроса не списывает остаток либо лимит дважды. Отдельно сверить на 12.3 случай, когда набор лишает бесплатной доставки | сервер-тест, smoke |
| 7 | Магазин убрал после оформления строку набора 200 + 100 за 240 ₽ с оплаченной долей 80 ₽ → оставшаяся стоит 160 ₽. До оформления удаление той же фасовки пересчитывает условия набора | холст, сервер-тест |
| 8 | Оба пути создания ведут к тому же предложению. Выполненный заказ с двумя полными тройками → один заказ, две группы, две единицы в подарок; при двух полных комбо и одном выигравшем коде комбо → один проданный комплект. Из результата открывается этот заказ | холст, сервер-тест |

## 8. Не входит

Автоматическое добавление товара в корзину, персональная выдача A12, настройка тарифа или кода доставки A6. Будущие функции не появляются в меню.
