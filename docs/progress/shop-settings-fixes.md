# Блок 7 · Исправления локальной проверки

Исправления экранов опираются на одобренную ревизию MagicPath `474756805352898560`.

| Сценарий | Исправление | Регрессионная проверка |
| --- | --- | --- |
| 03 · §12.3 | На demo прямой поиск адреса через Photon вернул `GEOCODER_UNAVAILABLE`. Убрали принудительную локаль. При ручной проверке в кабинете после сбоя или пустого результата Photon система пробует Nominatim, затем проверяет точку по геометрии черновика. Ошибка поиска и отсутствие адреса показываются отдельно. | `fulfillment.test.ts` проверяет запасной поиск и повтор из кеша. |
| 05 · US-M05 | После выключения поля самовывоза нет в JSON. Сервер теперь применяет это как отключение. | `seller-settings.test.ts` проверяет сохранение, недоступность самовывоза покупателю и повторное включение с новым адресом. |
| 06 · §12.4 | На `test2` осталось окно самовывоза 09:00–20:00 из демо-расписания блока 2. Кабинет показывал «2 часа» как значение по умолчанию. Теперь он показывает сохранённое окно. После явного выбора «2 часа» расписание делится на двухчасовые окна. Последнее заканчивается в 20:00. | `shop-settings.spec.ts` сверяет окно в кабинете с API покупателя. `seller-settings.test.ts` проверяет сохранение старого окна и переход на 2 часа. |
| 12 · §12.6 | Шапка выделяет названию доступную ширину и переносит длинное название. Предпросмотр кабинета использует тот же компонент. | `shop-settings.spec.ts` проверяет, что название помещается на 360, 390 и 412 px и открывает «О магазине». |
