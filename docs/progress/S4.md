# S4 · Сервер получения заказов

Настройки доставки, часы работы и паузы сохраняются отдельными командами с ревизией и ключом повтора. Команды проверяют право в текущем магазине. Настройки применяются к расчёту и оформлению через существующие API покупки.

| Решение | Проверка |
| --- | --- |
| §9.3 · Пауза по способу и сроку | `seller-settings.test.ts` проверяет отказ по старому расчёту доставки, доступность самовывоза, час, местную полночь и ручное снятие. |
| §11.2, §12.3 · Доставка без карты | Тариф первой зоны применяется без точки. Границу города кешируем, при отсутствии контура возвращаем центр. |
| §11.3 · Права | Сотрудник читает настройки и может ставить паузу с правом «Заказы». Доставка и часы изменяются владельцем. |
| §11.6 · Минимум | B10 отклоняет расчёт при сумме ниже порога, настройки оплаты сохраняются. |
| §12.4 · Часы | Интервалы нарезаются внутри заданных часов, выходные даты сохраняются. |
| §13.3, §13.5 · Публичный статус | Видимая пауза отдаёт плашку, тихая отдаёт только недоступность способа оформления. |

Экраны S4 и сквозная проверка блока идут после серверов S5 и S6.
