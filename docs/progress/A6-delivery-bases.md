## Почему на 550 ₽ показывалась льгота без кода

Ошибка воспроизведена на прежнем исходнике с чистым браузерным состоянием: автоматический порог 600 ₽, базовый тариф 120 ₽, удалить огурцы из готового примера → товары 550 ₽, поле «Промокод» пустое, но доставка 0 ₽ «по промокоду».

В `DeliveryExample.tsx` в расчёт автоматического примера всегда передавался `[draft]` редактора кода с принудительным status=active. В свежем состоянии draft имел `code=''`, минимум `''` (то есть 0), пустые сроки. В `mock.ts` поиск `find(x.code === c.code)` сопоставлял две пустые строки. На 550 ₽ автоматическая акция не срабатывала, зато этот несуществующий введённый код ошибочно считался подходящим. После открытия другого черновика результат зависел от скрытого редакторского состояния. Это ошибка прототипа, не установленный дефект расчёта приложения.

Теперь непустой нормализованный введённый код — обязательное условие поиска и льготы. В автоматическом примере список кодов пуст; пример кода получает только снимок конкретного непустого кода. Компонент примера больше не читает другой редактор через props. Снимок включает минимум, срок, базовый тариф и учебную дату; каждый вход собирает его заново.

## Что изменено в путях и данных

1. Автоматическая «Бесплатная доставка от суммы» — самостоятельная плитка/карточка/форма в общем «Продвижении», со своим сроком, результатами и отключением. Коды из неё не создаются.
2. «Создать акцию» → «Все виды акций» → «Промокод» → «Выгода: Бесплатная доставка». Использованы общие форма, поля, сводка и предпросмотр; избыточная строка «Способ применения: по промокоду» удалена.
3. «Ещё → Доставка и самовывоз»: базовая цена бесплатно / фиксированная сумма / посчитаем после заказа; получатель оплаты, «Покупатель увидит». Ссылка открывает единственное предложение `auto-delivery`, а не отдельные поля порога в S4. Порог/срок/статус хранятся в записи акции; редактор держит только её временный ввод.
4. Исходный ноль — основание базового тарифа: «Доставка уже бесплатна», без расхода/резерва кода и результатов кампаний. Неизвестная цена сохраняет обещание по подходящему основанию, а не превращается в ноль.
