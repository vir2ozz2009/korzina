# S2 · Сервер каталога продавца

Холст блока 6, ревизия `474506689824059392`, одобрен Андреем 20.11.2026.

| Решение | Проверка |
|---|---|
| §9.2, §11.1 | Скрытые товары участвуют в фильтре остатков. Нулевой остаток, поиск без учёта регистра, продолжение и устаревание страницы |
| §9.3, §11.8 | После удаления карточка недоступна, снимок заказа и фото сохранены |
| §9.4, §9.5 | Покупка меняет ревизию остатка. Описание и цена сохраняются, остаток остаётся серверным. Вторая покупка вызывает новый конфликт |
| §11.5, §13.3 | Повтор названия фасовки отклоняется. Ручные рекомендации сохраняют порядок, скрытые товары исключаются |
| §11.7 | Повтор не применяет запись дважды. Чужой магазин и отозванное членство не дают выполнить команду |
| §12.5, §13.1, §13.2, §13.4 | Пауза сохраняет остаток. Расчёт полуночи использует пояс магазина. Старая покупка отклоняется при добавлении и оформлении. Команда возвращает неприменившийся товар |
| §12.7, §13.5 | Копия скрыта, фото и остаток сохранены, доступен фильтр «Без категории» |

Существующие бюджеты SQL checkout и каталога сохранены. Версия выдачи кабинета учитывает запись заказа и изменения остатков, не меняя версию публичного документа при обычной покупке. Команды продавца обновляют публичную ревизию.

Для хранения товаров без категории используется скрытая служебная запись. API кабинета возвращает `null`, все покупательские входы по прежнему идентификатору категории остаются совместимы.
