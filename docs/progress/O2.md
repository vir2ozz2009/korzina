# O2 · Заказы в кабинете продавца

Андрей одобрил MagicPath `474382164977393664`. Кабинет на 390 px использует компоненты Korzina и реальные API заказов. [Отчёт холста](seller-orders-canvas-check.md)

| Решение | Проверка |
| --- | --- |
| §9.0, §9.5, §9.7, §12 | «счётчики всего магазина и фильтра по номеру, ревизия без чтения строк» и сквозной путь с сигналом WebSocket о новом заказе |
| §9.2, §11.4, §12.4 | «сборка, выдача в долг и повтор, доплата снимает долг у обеих ролей» |
| §9.3, §10.6 | «документ чека закрыт по праву, исправление сохраняет автора, время и прежнее поступление» |
| §10.10, D05 | «покупатель в “Оформлен” отменяет оплаченный заказ и видит сумму возврата» |
| §4.4 | Совпавшая ревизия списка — 1 SQL. Карточка продавца — в пределах 4 SQL. Бюджет B10 — в прежнем пределе 15 SQL |
| §8 TESTING | Сценарий B10 расширен для локального Worker. Обе роли проходят выдачу с оплатой и в долг. В браузере проверены оригинальные байты PDF, дата исправления и переход с плашки доплаты |
