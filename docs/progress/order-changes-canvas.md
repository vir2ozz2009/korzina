Один интерактивный мобильный компонент 390 × 844. «Состояния» под экраном переключают роли и примеры. Переключатель роли сохраняет текущий заказ, выбор примера возвращает его к исходным данным примера.

Основной маршрут проверен на 390 px в опубликованной ревизии и на 360 px в локальной сборке. Проверены Inter Variable в поле и на кнопке шторки, кириллица и отсутствие горизонтальной прокрутки. Фотографии товаров проверены локально: CDN MagicPath был недоступен из среды проверки. Данные и ошибки на холсте демонстрационные.

## Что я решил сам

- В карточке продавца собрал действия блока перед деталями заказа, чтобы «Изменить состав», «Изменить время» и «Чат по заказу» открывались с одного места.
- Для возврата удалённой строки в черновик использовал «Вернуть строку», для завершённого отказа от переноса — «Время осталось прежним». Фото в чате добавляется компактной кнопкой рядом с «Отправить».

## Чего не хватило в спецификации

- Формулировка результата для «Оставить прежнее время» в §11.5. Для ограничения встречных шагов использовано правило §9.7: после встречного предложения продавца покупателю доступно «Подходит», при отсутствии ответа прежнее время сохраняется.
- По карточкам видны варианты Figma, исключённые решениями блока: общий чат, вопрос о предпочтениях замены при оформлении, отдельная оплата доплаты и отдельный ввод реквизитов возврата.
