# O8 · Сервер переписки по заказу

Переписка использует события заказа и адресные сигналы для обеих ролей. Отправка, привязка фото, непрочитанные и постановка уведомления в очередь выполняются одной транзакцией. Настройки уведомлений учитывают право «Чат».

| Правило | Проверка |
| --- | --- |
| §9.11, US-Z06 | «Доступ только своему заказу, повтор записывает сообщение и уведомление один раз». |
| §9.12, §11.7 | «Чужое фото запрещено, лимит считает символы». |
| §9.13 | «Через 7 дней переписка открывается только на чтение». |
| US-R10 | «Отметка чтения не поглощает новое сообщение». |
