# Блок 4 · Выпуск на demo

Миграции D1 `0006`–`0009` применены по разрешению Андрея. S1 и AD1–AD3 влиты после CI и smoke на превью. [AD2](https://github.com/vir2ozz2009/korzina/pull/88) · [AD3](https://github.com/vir2ozz2009/korzina/pull/89)

Команда Cloudflare Builds для `main` запускает `npm run platform:setup` перед `cf deploy --prebuilt` и smoke после публикации. Команда превью остаётся `npm run preview:upload` и применяет миграции к отдельной D1.

Вход на основной demo-витрине использует тестового бота платформы, пока у витрины нет своего бота. Переход в Telegram подтверждает B9 через webhook и возвращает пользователя к той же браузерной сессии. Доступ администратора затем проверяет аккаунт, список допуска, роль в D1 и срок сессии.

Первый запрос входа проверяет имя тестового бота, настраивает webhook на `/api/platform/telegram` и проверяет его адрес в Telegram API. Настройка повторяется при изменении конфигурации. Секрет webhook хранится в настройках Worker.
