## Предложенный diff внешних инструкций Work

Внешние файлы проекта Work недоступны из Git и не изменены; их текущий текст и фактическую автоматическую загрузку подтвердить невозможно. Следующие строки — конкретная предлагаемая замена раздела старта/чтения, а не утверждение о применённом внешнем diff:

```diff
- На старте прочитай AGENTS.md, PROGRESS.md и все общие документы целиком.
+ Обнови main, прочитай корневой AGENTS.md, короткий docs/PROGRESS.md; для подготовки/реализации — карточку задачи.
+ Выбери маршрут этапа в docs/context/README.md; для продуктовой задачи CTX-1 читать не обязательно.
+ Локальная перепроверка: актуальная передача → остаток чек-листа → нужные фикстуры; старые отчёты/спецификации — только под конкретный пробел или противоречие.
+ Ищи точные ID историй с границами; читай небольшими порциями и используй уже прочитанные разделы; расширяй по реальной зависимости денег, прав, изоляции, повторов и возвратов.
+ Подробные процедуры — нужный раздел docs/WORKFLOW.md; история — ссылки из PROGRESS, без чтения архива по умолчанию.
+ Work готовит продуктовые решения/спецификацию; облачный Codex — согласованную сборку; локальный Codex — demo и физический iPhone; принимает Андрей.
+ Figma — справочник Work. Для Codex — спецификация, UI-кит, токены и принятый main; проект MagicPath сверить с действующим DESIGN §5 перед холстом.
+ В отчёте перечисли основные реально прочитанные разделы и причины расширения карты.
```

Рекомендация Work: синхронизировать только после сверки точного внешнего текста; это снижает дублирование, не меняя продукт/объём приёмки. Если снаружи иной ID MagicPath или иной процесс, зафиксировать расхождение и решение Андрея до зависимой работы. Безопасная документационная часть CTX-1 от этого не зависит. Старые материалы/решения не удалять, project_doc_max_bytes не увеличивать.
