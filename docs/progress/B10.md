# B10 · Расчёт, оплата и оформление

Сервер хранит короткоживущий расчёт и сверяет его перед оформлением. Итоги считаются в минимальных единицах валюты. Минимум проверяется по товарам. Пауза приёма закрывает запись заказа. При оплате курьеру магазин получает стоимость товаров.

Одна транзакция занимает вместимость, списывает конечный остаток, фиксирует заказ и событие outbox и удаляет оформленные строки корзины. Повтор возвращает сохранённый ответ по тому же ключу. Снимок заказа доступен своему покупателю, при входе Telegram заказ гостя привязывается к аккаунту.

Чек связан с исходным расчётом. Оформление с чеком переводит оплату в «на проверке». Изменение суммы или реквизитов фиксируется для сверки. Уведомление продавца получает событие из outbox при подключении обработки заказов.

Проверены конфликт за последний товар, повтор, снимок, изоляция заказов, минимум, VND и RUB, исходный чек и бюджет оформления. Сквозной путь проверяется после подключения экранов.
