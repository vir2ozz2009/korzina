# BL-8 · Стабильность CI

- **Адрес магазина.** Тест запускает команды на D1 с четырьмя нужными миграциями и двумя магазинами. Он проверяет занятый и зарезервированный адреса, откат при сбое записи журнала, повтор команды и блокировку адреса после активации. Уведомления и запуск фоновой очистки не относятся к сценарию адреса. Очистку покрывает `cleanup.test.ts`.
- **Браузерный набор.** В трассе #131 ответы 429 пришли с обычных маршрутов API с `Retry-After` и `X-Request-Id`. В полном локальном прогоне тот же лимит вызвал сбой B10: перезагрузка заказа получила 429 с `Retry-After: 7`. Общий бюджет для превью и локального режима E2E — 240 запросов/мин на IP. На demo и prod действует 120. Пороги защищены тестом `rate-limit.test.ts`. [Трасса #131](https://github.com/vir2ozz2009/korzina/actions/runs/44746327486/artifacts/14633033648)
- **Chromium.** Check, E2E и Demo smoke скачивают версию Chromium из Playwright без `apt`. В журнале зависшего запуска Check не дошёл до скачивания браузера. [Лог Check](https://github.com/vir2ozz2009/korzina/actions/runs/44717017342/job/136222890808)
- **Локальный сценарий Telegram Web.** Chromium блокирует вложение loopback-страницы с внешнего origin. Локальная фикстура открывает кабинет `127.0.0.1` из `localhost`, сохраняя проверку cross-site iframe и входа без cookies.

Критерий закрытия BL-8 — три зелёных Check подряд на PR с кодом.
