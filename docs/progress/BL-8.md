# BL-8 · Стабильность CI

- **Адрес магазина.** Тест запускает команды на D1 с четырьмя нужными миграциями и двумя магазинами. Он проверяет занятый и зарезервированный адреса, откат при сбое записи журнала, повтор команды и блокировку адреса после активации. Уведомления и запуск фоновой очистки не относятся к сценарию адреса. Очистку покрывает `cleanup.test.ts`.
- **Превью.** В трассе #131 ответы 429 пришли с обычных маршрутов API с `Retry-After` и `X-Request-Id`. Предыдущий замер 138 браузерных запросов за минуту включал перехваченные запросы. Причина отдельного таймаута B10 остаётся неподтверждённой. Общий бюджет превью — 240 запросов/мин на IP, demo и prod — 120. Пороги защищены тестом `rate-limit.test.ts`. [Трасса #131](https://github.com/vir2ozz2009/korzina/actions/runs/44746327486/artifacts/14633033648)
- **Chromium.** Check, E2E и Demo smoke скачивают версию Chromium из Playwright без `apt`. В журнале зависшего запуска Check не дошёл до скачивания браузера. [Лог Check](https://github.com/vir2ozz2009/korzina/actions/runs/44717017342/job/136222890808)
