# B8 · Время получения

Сервер строит семь дней по часовому поясу магазина и отдельному расписанию доставки и самовывоза. Интервалы учитывают время на подготовку и лимит, выбор дня — отсечку и лимит даты. Режим «после заказа» возвращает расписание без дат.

Выбор времени сохраняется с ревизией корзины и сбрасывается при смене способа. Вместимость проверяется при сохранении выбора, место занимает только запись заказа (B10). Счётчики брони истекают через существующую очистку Shop. Она выполняет один дополнительный индексный DELETE.

Проверены переход через полночь, отсечка, оба варианта лимита, конкурентное занятие последнего места, очистка и бюджет выборки из двух SQL. Экран и сквозной smoke относятся к следующим шагам блока.
