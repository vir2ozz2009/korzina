## N1 — управляемая потеря запроса и ответа

Нужен Safari Web Inspector Mac, подключённый к **физическому** Safari/WebView iPhone. Перед прогоном подтвердить, что выбран правильный клиент и следующая команда проходит через `window.fetch`. Если Telegram не предоставляет inspectable WebView, оставить его N1 ⏸ и передать ограничение в Work; Chromium/подмена ответа API его не закрывают. Отключение Wi-Fi, прерывающее Mirroring, не использовать как доказательство.

В консоли только своей вкладки установить следующий временный перехватчик. Он не пишет тела, адреса, токены или ключи в журнал/файл; хранит один запрос только в памяти до `restore()`. В инспекторе не печатать объект Request. `arm()` разрешён только для своей корзины/своего заказа. Тела и cookie не переносить в отчёт.

```js
const clarityNetwork = (() => {
  const original = window.fetch;
  let armed, saved;
  window.fetch = async function(input, init) {
    const request = new Request(input, init);
    const url = new URL(request.url);
    if (url.origin !== location.origin || request.method !== 'POST' || url.pathname !== armed?.path)
      return original.call(this, input, init);
    const mode = armed.mode;
    armed = undefined;
    saved = request.clone();
    if (mode === 'request') throw new TypeError('Failed to fetch');
    const response = await original.call(this, input, init);
    if (!response.ok) return response;
    throw new TypeError('Failed to fetch');
  };
  return {
    arm(path, mode) {
      if (!['/api/cart', '/api/checkout'].includes(path) || !['request', 'response'].includes(mode)) throw Error('fixture');
      armed = { path, mode };
    },
    async replay() { if (!saved) throw Error('No request'); const r = await original.call(window, saved.clone()); return { status: r.status }; },
    restore() { window.fetch = original; armed = saved = undefined; }
  };
})();
```

1. `arm('/api/cart','request')` → изменить количество: ошибка/повтор доступны, серверная ревизия и количество не изменились. Повторить штатной кнопкой UI: ровно одно изменение и актуальная шторка. Затем `arm('/api/cart','response')` → новое количество: сервер сохранил, UI получил ошибку; штатный повтор возвращает актуальное количество без второго изменения. Сверить ревизии до/после и число действий, не только текст ошибки.
2. Свой заказ: `arm('/api/checkout','response')` → оформить наличными. Сервер создал заказ, клиент потерял ответ. Штатный «Проверить ещё раз» возвращает тот же номер, второго заказа нет. Добавить товар нового заказа, явно выбрать самовывоз; `await clarityNetwork.replay()` повторяет **тот же** сохранённый запрос/ключ оформления. Тот же номер, выбор/тариф новой корзины не сброшены. Отдельно `arm('/api/checkout','request')` или реальная ошибка доступности → старый выбор сохранён, заказа нет. Снимки iPhone до/после плюс обезличенный серверный номер/ревизия; API-журнал отдельно от физического UI. Завершить `restore()`.

## L1 — настоящая legacy-фикстура

В том же demo DO создана **отдельная** корзина `customer='guest:cc-d1-legacy-20261127'`, свои berry/milk × 1, revision 0, `receiving={"receiving":{"mode":"pickup"},"receivingUpdatedAt":1}`. Ни `explicitMode`, ни `selectionVersion` не записаны. Рабочие корзины не правились. Реальный GET `/api/receiving?shop=lavka` на временной своей сессии вернул HTTP 200, revision 0, `effectiveMode=delivery`, `receiving=null`; это API-подготовка, не физический PASS. Временная legacy-сессия отозвана, файл токена удалён; сама изолированная фикстура оставлена для допрогона.

Перед физическим шагом локальный Codex создаёт случайный 64-hex токен **только локально**, SHA-256 от него и строку sessions(kind=guest, subject=точно этот customer, expires_at=текущее время+15 минут) через Cloudflare SQL API указанного demo namespace, без публикации токена. Установить cookie `korzina_customer_korzina-demo-lavka` только в отдельной учебной вкладке/контексте физического Safari; Telegram L1 требует отдельного контролируемого WebView-контекста. Исходную пользовательскую cookie не заменять. Открыть корзину, снять фактические доставка/тариф/запрос адреса; явно выбрать pickup → refresh → pickup сохранён. Записать SQL-форму фикстуры, клиент/SHA/снимок, затем отозвать точный token_hash. При невозможности изолированной cookie оставить L1 данного клиента ⏸. Не добавлять продуктовый endpoint для legacy.
