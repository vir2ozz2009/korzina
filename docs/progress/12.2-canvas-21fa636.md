# 12.2 · Как покупатель видит лимит комбо

Собрано из main `21fa636`. [Опубликованная ревизия `476616484060278784`](https://designs.magicpath.ai/v1/fierce-storm-4875?revisionId=476616484060278784&history=design) того же компонента `476596446154604544` в «Платформе корзины».

Проверка §7 №11 пройдена на 360 и 390 CSS px в изолированном примере и покупательской корзине опубликованного холста. «Завтрак» стоит 220 ₽ вместо 250 ₽, других акций нет. В карточке до добавления виден текст «До 2 наборов по этой цене за заказ» рядом с ценой. При отсутствии лимита строки нет. На плитке осталась короткая метка.

| Состояние | Подпись и подсказка | Экономия | Итог |
| --- | --- | ---: | ---: |
| 1 пара, лимит 2 | «1 набор по акции», «Можно собрать ещё 1 набор по 220 ₽» | 30 ₽ | 220 ₽ |
| 2 пары | «2 из 2 наборов по акции», подсказка исчезла | 60 ₽ | 440 ₽ |
| 3 пары | «2 из 3 наборов по акции. Лимит — 2 на заказ», лишняя пара по обычной цене | 60 ₽ | 690 ₽ |
| Обратно к 2, затем к 1 паре | При двух подсказки нет, при одной вернулась | 60 → 30 ₽ | 440 → 220 ₽ |
| 3 пары без лимита | «3 набора по акции», строки лимита нет в корзине и шторке | 90 ₽ | 660 ₽ |

Дополнительно проверен публичный промокод. До применения видны цена и предел, полученная скидка не показывается, одна пара стоит 250 ₽. После одного ввода кода пройден тот же путь с лимитом 2, повторно вводить код не нужно.
