# 13.1 · Короткая локальная проверка — максимум 10 минут

Решение Андрея 28.11.2026: проверить основную доработку суперточечно, не проходить весь блок. План подготовлен на этапе спецификации и одобрен Андреем вместе с ней 28.11.2026; это не отчёт о выполнении и не одобрение будущего холста.
Источник поведения — [спецификация](../specs/customer-offers.md); лимит и остановка — [TESTING §5](../TESTING.md#проверка-изменений-максимум-10-минут). Этот файл — единственный список физических сценариев 13.1; C01–C21 не переносить сюда целиком.

## Когда и кто
- Короткий объём зафиксирован и одобрен. После холста/реализации облачный Codex подставляет точные ссылки, учебные ID, ожидаемые суммы, release SHA и ссылки на актуальные автотесты.
- Передача локальному — после проверенного demo; не сейчас. Облачный Codex сверяет фактический diff и готовность фикстур; уточняет шаги без добавления новых физических сценариев. Новый существенный риск — отдельное объяснение в Work, не молчаливое расширение.
- Локальный Codex на Mac использует реальный iPhone через «Видеоповтор iPhone». Продавец — Safari, покупатель — Telegram Mini App с уже доступными учебными сессиями; каждый путь один раз, без повторения в обоих клиентах/на двух ширинах.
- Если доступен только один клиент, пройти доступное в нём, указать ограничение; Telegram Back не объявлять проверенным в Safari. Не заводить второй Telegram-аккаунт и не тратить прогон на настройку окружения.

## Готовность до передачи
Облачный Codex готовит один изолированный demo-магазин и одного подтверждённого учебного покупателя с прежним заказом; владельца-продавца; один обычный товар без других скидок; самовывоз/доставку 0 и оплату без внешнего списания. Фикстуры не затрагивают реальные магазины/покупателей, prod или Lavka.
В передаче — прямые ссылки на нужные экраны и короткие шаги подготовки/уборки, без секретов/PII. Учебный пример: корзина 100 000 VND; автоскидка 10% → 90 000 VND; отдельный код −5 000 → 95 000 VND. Для другой валюты подставить проверенные эквивалентные числа один раз; вручную валюты не перебирать.
Товар, доступность оформления, пустая от посторонних акций корзина и выбранные получение/оплата проверены облачным Codex. Физические входы не считать готовыми без фактической сессии. Уведомления об акциях у учебного покупателя выключены; рассылку не запускать.
Локальный таймер включает проверку сессий и всю собственную подготовку. Долгая настройка/создание данных на устройстве не выносится за таймер.

## Только три сценария
Время — плановый бюджет, не измеренная длительность. Цель — завершить раньше; верхняя граница всего поручения 10 минут.

| Этап | Время | Что сделать → ожидаемый результат |
|---|---:|---|
| Подготовка | 1 мин | Проверить demo-магазин, доступные роли/сессии, указанную сборку одной штатной попыткой; открыть переданные ссылки. Недостаток сведений о SHA отдельно от результата поведения |
| L1 · Покупатель → выдача | 2 мин | Продавец: открыть переданный исходный заказ → имя или аватар → карточка покупателя → Back в тот же заказ, затем вернуться в карточку. Попутно виден Telegram @username при наличии; отдельного прогона контактов нет. «Дать скидку» → 10%, остальные значения по умолчанию → «Выдать скидку». Одна новая разовая скидка видна в карточке; клавиатура/нижняя кнопка не мешают завершить |
| L2 · Автоскидка → заказ | 2 мин | Покупатель: профиль → предложения → видна эта скидка, Back возвращает в профиль. Открыть подготовленную корзину: автоматически 90 000 вместо 100 000, без ввода кода. Оформить один учебный заказ без внешней оплаты → в заказе тот же итог, разовая больше недоступна. Не проводить заказ через сборку/выдачу/завершение |
| L3 · Продвижение → код → отзыв | 2 мин | Продавец: «Акции → Создать → Личное предложение» → выбрать того же покупателя → выдать разовый код −5 000. Покупатель: добавить тот же товар после L2, в предложениях «Использовать» → единое поле кода, итог 95 000. Продавец отзывает эту же запись; покупатель возвращается в корзину → после актуализации код больше не даёт выгоду, итог 100 000 и объяснение. Второй заказ не оформлять |
| Восстановление | 2 мин | Отменить только созданный учебный заказ до выдачи; отозвать восстановившуюся разовую скидку L1, если она снова действует; убрать свои товары/код из учебной корзины, закрыть временные сессии. Историю не удалять, исходный заказ/чужие данные не трогать |
| Резерв | 1 мин | Только задержки/одна повторная попытка текущего шага; не дополнительные проверки |

L1/L2 — приоритетный основной путь; L3 — второй вход и одна существенная граница (отзыв). При задержках сокращается выполненный объём, а не время на уборку. К восьмой минуте новые тестовые действия прекратить и перейти к восстановлению; если всё проверено раньше, завершить раньше.
Не оформлять заказ, если не остаётся времени на безопасную отмену. Дефект зафиксировать одним коротким описанием/снимком, перейти к независимому доступному шагу, если он есть; не начинать расследование/исправление в этом поручении.
На десятой минуте проверки остановить. Если неожиданно осталась необходимая уборка, выполнить только её и отдельно указать превышение. Невыполненное — «не выполнено в лимит» или конкретная причина; не PASS и не основание автоматически запустить ещё 10 минут.

## Что локально не повторяем
Не прогонять все C01–C21, старый остаток 12.x, все роли/магазины, все цели/валюты/сроки, возвраты, гонки, истечение в полночь, все акции/наборы, уведомления бота, глубокую пагинацию, все ошибки и матрицу ширин.
Деньги/изоляция/права/идемпотентность/возвраты сохраняют обязательное автоматическое покрытие в реализации. Замена постоянной, согласие/очередь и редкие UI-состояния — адресные серверные/UI-тесты облачного Codex, визуальные состояния — холст/preview. Не назначать вместо этого полный ручной прогон в другом окружении.
Если обязательные автоматические проверки не прошли, облачный Codex исправляет свою реализацию; это не повод переложить весь объём на локального. Успешный короткий прогон подтверждает основной путь, не все требования блока.
