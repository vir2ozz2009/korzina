## Что собрать

1. Один интерактивный компонент, мобильный экран 390 × 844 без рамки телефона; экраны переключаются, не стоят рядом. Сохранить действующий стиль и незатронутые элементы main, включая принятые правки CART-CLARITY.
2. Продавец: оба входа в единые условия; автоматический порог; «Промокоды на доставку» → существующий список с фильтром → создание/редактирование самостоятельных кодов. Два кода с разными условиями, независимое отключение. Пример перед публикацией, возврат к исходному экрану и результаты по своему основанию льготы.
3. Покупатель: адрес/получение, переход через порог в обе стороны, один код и подтверждение замены; бесплатная доставка по коду без лишнего добора. Недостигнутое условие кода — у кода.
4. Поздний тариф: явное обещание бесплатной доставки по коду либо сумме, затем подтверждение исходного тарифа продавцом и отсутствие доплаты покупателю. Отличать неизвестную стоимость от нуля и от недоступного адреса.
5. Панель состояний вне интерфейса: загрузка/нет связи/повтор, конфликт версии, ошибки кода, самовывоз, прямой платёж курьеру, уже нулевой тариф, отсутствие адреса. Управляемые поля, работающие кнопки, шторки, Back, сохранение введённого при ошибках.
6. Числовые примеры и видимые переходы — §7, сценарии 1–13. Гонки/повторы транзакций на холсте не объявлять проверенными: показать предусмотренный результат, серверные доказательства относятся к реализации.
