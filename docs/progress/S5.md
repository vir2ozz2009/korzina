# S5 · Сервер способов оплаты

Продавец с правом «Деньги» сохраняет порядок и параметры способов оплаты с проверкой ревизии. Покупатель получает включённые способы. Оформление повторно сверяет настройки и сохраняет выбранный способ в заказе.

| Решение | Проверка |
| --- | --- |
| §11.3 · Право «Деньги» | `seller-payments.test.ts` проверяет запрет записи и отсутствие реквизитов в чтении без права. |
| §12.5 · Свои способы | Сквозной тест API проверяет порядок, покупку способом без чека, отказ по выключенному способу и сохранение его снимка в прежнем заказе. |
| §13.4 · Картинка для оплаты | Тест входного файла проверяет лимит 1 МБ и отказ для PDF. Проверки наличия QR нет. |

Существующие покупки наличными и переводом покрыты тестами checkout.
