# B7 · Адрес и способ получения

Серверная часть. API показывает включённые способы и часы самовывоза, проверяет границу зоны и возвращает тариф. Три последних адреса хранятся в сессии устройства.

Геокодер использует секрет Cloudflare `GEOAPIFY_API_KEY`, кеширует результат по магазину и нормализованному адресу. Без ключа доступна ручная точка. Проверки Geoapify используют заглушку.

Четыре API-теста покрывают зону, тариф, повторную загрузку адресов, изоляцию сессии и кеш геокодера. Проверка интерактивного пути — после подключения утверждённого экрана.
