# B7 · Адрес и способ получения

Серверная часть по одобренной ревизии MagicPath `473826311530500096`. API сохраняет способ, адрес, обязательные детали и комментарий с ревизией корзины. Недавние адреса доступны только текущей сессии покупателя. Пункт и часы самовывоза берутся из настроек магазина.

В режиме карты сервер проверяет полигон или радиус и сравнивает тарифы пересекающихся зон. Покупатель может подтвердить ручной адрес без точки с поздней стоимостью. Для выбора района применяется его тариф, для свободного адреса без карты действует единый тариф. Получатель оплаты доставки передаётся отдельно.

Геокодер использует Photon и запасной Nominatim для обратного поиска. Нормализованные запросы кешируются по магазину. Без карты конечная точка геокодера закрыта.

Локальные проверки: `check:fast`, семь тестов получения, тарифов, карты, сохранения, изоляции и геокодера. Путь через интерфейс проверяется при подключении экрана.
