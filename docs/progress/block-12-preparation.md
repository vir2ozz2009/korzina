## Что уже определено

- Из подходящих скидок на одну позицию выбирается самая выгодная, при равенстве — цена по акции. Минимум для товарного кода проверяется после скидок на подходящие позиции, без доставки. По умолчанию код действует на позиции с обычной ценой.
- На корзину применяется одна скидка. При одинаковой выгоде побеждает автоскидка. Проигравший код остаётся введённым и не расходует лимит. Код доставки может сочетаться с автоматической товарной скидкой, когда доставка платная и покупатель платит магазину.
- Корзина покупателя и проверочная корзина продавца используют один расчёт. При оформлении подтверждаем возросший итог. Действительно применённый код расходуется один раз, даже при повторе запроса или гонке за последнее применение. Суммы и основания фиксируются в заказе для последующего возврата. Скидки округляются вверх до целой единицы валюты в пределах базы и лимита. [Расчёт заказа](../DOMAIN.md#расчёт-заказа-b6-b10-скидки--a-storiespromomd) · [Правила и статусы](../stories/promo.md)

## Корзины для сверки

| Условия | Ожидаемый результат |
|---|---|
| 12.1. Кофе 500 ₽ по обычной цене. Автоскидка 10%, товарный код на 50 ₽ | Покупатель платит 450 ₽. Выигрывает автоскидка, код остаётся введённым. Если изменить код на 70 ₽, выиграет код и итог станет 430 ₽ |
| 12.2. Для «2+1» подходят багет 200 ₽, масло 150 ₽ и круассан 100 ₽. Других акций нет | С багетом и маслом — 350 ₽. С тремя товарами — тоже 350 ₽, круассан бесплатен. Если убрать масло, оставшиеся два товара стоят 300 ₽ |
| 12.3. Тариф 120 ₽, порог 600 ₽. До скидок в корзине 599, 600 или 601 ₽, скидок на товары нет | При 599 ₽ до порога 1 ₽ и к оплате 719 ₽. При 600 и 601 ₽ доставка 0 ₽. Активный код доставки при корзине 599 ₽ снижает итог до 599 ₽; удаление кода возвращает 719 ₽ |
| Все три подблока вместе. Багет, масло и круассан участвуют в «2+1» и наборе по коду «ЗАВТРАК» за 320 ₽. Мёд 200 ₽, автоматическая скидка 10% только на мёд. Доставка 120 ₽, автоматический порог 600 ₽. Код «ДОСТАВКА» разрешён от 500 ₽ | С «ЗАВТРАК»: набор 320 ₽ + мёд 180 ₽ + доставка 120 ₽ = 620 ₽. При замене на «ДОСТАВКА» набор теряет цену по коду, снова действует «2+1»: 350 ₽ + мёд 180 ₽ + доставка 0 ₽ = 530 ₽. В корзине и при оформлении один код. Без кода итог 650 ₽ |
| Стоимость товаров после скидок на позиции 620 ₽, автоматический порог доставки 600 ₽. Единственный код снижает сумму заказа на 50 ₽ | Доставка остаётся бесплатной, итог 570 ₽. Код на доставку для этого не нужен |

## Решения Андрея от 25.11.2026

1. Для набора и «2+1» сравнивать допустимые варианты и выбирать меньший итог. Одной единице назначается одна позиционная скидка. Сравнивать набор целиком. При равенстве действует правило приоритета цены по акции, между набором по коду и равным автоматическим «2+1» выигрывает автоматическая акция.
2. Одно поле ввода и максимум один введённый промокод на корзину, общий для скидки на товары, набора и доставки. Покупатель может убрать или заменить код. При замене показать новый итог перед подтверждением; при ошибке ввода сохранить прежний код. Автоматические предложения и бесплатная доставка по порогу продолжают рассчитываться по своим условиям.
3. Порог бесплатной доставки считать по товарам после скидок на позиции и до общей скидки на корзину. В стоимость товаров для порога доставка не входит.
4. Для нескольких групп «2+1» сортировать подходящие единицы по обычной цене по убыванию и дарить самую дешёвую единицу каждой полной тройки. При ценах 200, 190, 180, 100, 90, 80 ₽ подарки стоят 180 и 80 ₽, итог 580 ₽ независимо от порядка добавления.

5. Владельцу и управляющему доступно управление акциями. В админке один переключатель «Акции» на магазин, по умолчанию выключен.
6. В истории подтверждённого покупателя для первого / N-го заказа считать только выполненные заказы этого магазина. Личный лимит проверять отдельно.
7. Один промокод комбо даёт скидку на один комплект за заказ. Второй комплект участвует в подходящих автоматических акциях.
8. Полная отмена до выдачи восстанавливает оба лимита кода. Поздний тариф резервирует применение и завершает его по снимку. [Сценарии](block-12-compatibility.md)

9. При удалении отсутствующей позиции магазином после оформления сохранить скидки остальных товаров и бесплатную доставку. Заказ на 600 ₽ без хлеба за 50 ₽ становится заказом на 550 ₽. Новую цену замены согласовывает покупатель.

## Кабинет продавца

[Сравнение шести сервисов и предлагаемая структура](block-12-market.md) — вход в раздел, создание акций, два способа бесплатной доставки, замена кода и порядок реализации.

- Нижняя вкладка «Акции» открывает раздел «Продвижение», список предложений и кнопку «Создать акцию». «Скидки», «Промокоды», «2+1», «Комбо-наборы» и «Бесплатная доставка» доступны при создании и как фильтры списка. Разделы появляются по мере выпуска 12.1–12.3. Цена конкретной фасовки по-прежнему доступна в карточке товара. При подготовке холста проверить полные подписи нижнего меню на 360 и 390 px вместе с «Деньги» и «Ещё».
- В «Настройки → Получение заказов → Условия доставки» и в «Продвижение → Бесплатная доставка» открываются одни условия магазина с учётом прав сотрудника. Доступны две независимые возможности. «Бесплатно от суммы» включает автоматический порог. «По промокоду» даёт выбрать или создать код доставки и задать для него «Минимальная сумма товаров» (необязательно). Можно включить обе возможности: достаточно выполнения одной из них. Тариф и плательщик берутся из настроек доставки.
- Пример: автоматически от 1 500 ₽, с кодом «ДОСТАВКА» от 800 ₽. Для товаров на 900 ₽ доставка бесплатна с кодом, на 1 500 ₽ — автоматически. В списке «Промокоды» открывается тот же код доставки. Изменение, отключение, черновик и публикация используют один объект предложения и действующие права. Настройка продавца действует внутри включённой функции магазина.

Ориентиры: Shopify поддерживает автоматическую бесплатную доставку и код с минимальной суммой, WooCommerce позволяет использовать порог или купон. Общий экран управления и один код в корзине — решения для Korzina. [Shopify](https://help.shopify.com/en/manual/discounts/discount-types/free-shipping) · [WooCommerce](https://woocommerce.com/document/free-shipping/)

Для спецификаций сохранить отдельные проверки на равенство, купон без расхода при проигрыше, лимит последнего применения, повтор оформления, удаление фасовки, изменение адреса и сверку суммы после частичного возврата с сохранёнными строками. Порог для промокода и порог бесплатной доставки проверять по отдельности.
