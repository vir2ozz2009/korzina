# S6 · Сервер данных и оформления магазина

Данные и цвет витрины сохраняются владельцем с проверкой ревизии. Публичный ответ и HTML получают актуальный профиль. Валюта закрепляется после первого заказа, независимо от состояния оплаты.

| Решение | Проверка |
| --- | --- |
| §9.2, §11.3 | `profile-settings.test.ts` проверяет права, запрет менять страну, валюту и slug, публикацию контактов, конфликт и вычисление пояса по точке. |
| §11.1 | `card.test.ts` проверяет блокировку валюты после первого неоплаченного заказа. |
| §11.4 | Смена пояса перестраивает доступность B8 и переносит границы действующих пауз до конца дня. |
| §12.6 | Сервер сохраняет форму и изображение логотипа. Публичный профиль отдаёт логотип, HTML использует его в карточке ссылки. |
| US-M12 | Проверка цвета на сервере переиспользует `validateCustomColor`. API витрины возвращает сохранённый цвет. |

Пояс по точке вычисляется локально на сервере по базе `tz-lookup`.
