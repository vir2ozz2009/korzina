## `VERSION_CONFLICT` в сквозном прогоне

«Собрано 0 из 1» видно и до принятия заказа. В Chromium задержали отправку `accept` до чтения заказа тестом: тест прочитал `placed` с ревизией 0, принятие сохранило `accepted` с ревизией 1, прямой запрос `recordPayment` из теста отправил 0 и получил HTTP 409 `VERSION_CONFLICT`.

Сквозной шаг теперь дожидается успешного ответа `accept` и появления действий сборки, затем читает ревизию для записи оплаты и проверяет полученную сумму. Повторов запросов в шаге нет.
