# D1 · Telegram BackButton

На main обнаружен воспроизводимый путь потери обработки: после входа с `tgWebAppData` переходы роутера убирают hash, а Reload Page заново вычисляет признак Telegram по текущему URL. Без признака мост не подключается и нажатие BackButton не обрабатывается. Это объясняет наблюдаемый симптом, но неизвестный SHA клиента и отсутствие диагностики на телефоне не позволяют утверждать, что именно этот путь вызвал физический отказ.

Признак настоящего запуска сохраняется на время сессии вкладки; подписанный `initData` не сохраняется этим изменением и авторизация им не подменяется. Автопроверка покрывает Reload после удаления hash, исходную цепочку вкладок, один возврат на главную с `shop=test2` и возврат из вложенной категории. Проверка имитирует SDK и не является физической проверкой Telegram.
