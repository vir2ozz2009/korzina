# Блок 4 · Приёмка на demo

19.11.2026. Андрей подтвердил, что админка открывается из профиля. В demo D1 есть действующая сессия администратора. Гостевой запрос к реестру возвращает HTTP 403, к кабинету продавца — HTTP 401. Smoke витрины и загрузки приложения прошёл. [Demo](https://demo.korzina.app)

Переход в приложение и возврат из него ждут проверки на iPhone Safari и Android Chrome. [PR #92](https://github.com/vir2ozz2009/korzina/pull/92) |
