# Правка адреса доставки после #234

Подсказка, карта, геопозиция и текущий адрес корзины открывают общую форму. При «Куда угодно» ручной текст сохраняется без проверки. В режиме зон сохраняется проверка доставки. Правка квартиры, подъезда, этажа, домофона или комментария оставляет метку, правка улицы сбрасывает её.

| Запрос | Проверка кода в AddressSheet.test.tsx | QA1, Chromium 390 px |
| --- | --- | --- |
| 1 · Заполняемая форма и метка | Подсказка и карта заполняют форму | (а) правка квартиры, (б) геопозиция |
| 2 · Любой ручной адрес | Адрес сохраняется без запроса проверки | (в) ввод без подсказок |
| 3 · Сохранённый адрес | Поля сохранённого адреса редактируются | (г) сохранённый адрес, (д) возврат с самовывоза |
| 4 · Сброс точки | Квартира и подъезд сохраняют точку, улица сбрасывает | (а), (б), (г) |
| 5 · Зона | Точка вне зоны отклоняется, внутри сохраняется | (е) правка адреса в зоне |
