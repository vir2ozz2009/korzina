## Как проверялось

Разовая Python-проверка вне репозитория: взят `git show c211708:docs/PROGRESS.md`, разделён по исходным заголовкам; каждый фрагмент сопоставлен архивному, URL приведены к абсолютным путям внутри репозитория и сравнены строки. Для перенаправленных якорей использован обратный адрес PROGRESS. Результат: 19/19 равны; добавлены только исторические предупреждения. Для всех относительных Markdown-ссылок в изменённых/новых документах проверены путь и целевой заголовок. Новые scripts/CI не добавлялись. Дополнительно diff сверяет отсутствие изменений вне docs/ и AGENTS.
