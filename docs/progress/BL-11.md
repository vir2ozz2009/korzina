# BL-11 · Сквозные проверки и CI

Playwright регистрирует 10 сценариев вместо 20 (18 на момент записи бэклога плюс две последующие проверки). Прежние проверки выполняются в шагах с прежними названиями. Для проверок с самостоятельными фикстурами создаются отдельные браузерные контексты.

| Было | Стало |
|---|---|
| Каталог B3, поиск B5, список и блюда B5b | «Каталог: категории, поиск и список», три шага |
| Корзина П2 и изменение цены/остатка §3.1 | «Корзина: изменения количества и предложения», два шага с меткой `@home-cart` |
| `checkout-recovery`, регрессия 04 | Первый шаг B10, отдельный контекст, включая прогон при паузе demo |
| Рабочий день 01–03, 05–06, 08 и 09, публичное время и пауза | «Блок 9 · регрессии рабочего дня и уведомлений», шаги в `workday.spec.ts`; отдельный локальный сценарий сохраняет создание заказа, сборку и очередь |
| Browser login покупателя, вход Mini App без шторки | «Вход в Telegram: buyer», два шага |
| Browser login продавца, кабинет Telegram Web без cookie §9.12 | «Вход в Telegram: seller», два шага. Локальный третий шаг проверяет приглашение сборщика |
| Админка | Серверные тесты прав, идемпотентности и изоляции |

Приглашение создаётся через интерфейс владельца, а учебный получатель проходит настоящее погашение токена и получает отдельную сессию. У сборщика есть «Заказы» без сумм и нет пункта «Сотрудники». Ссылка после приёма отклоняется для второго Telegram ID, а прежняя открытая сессия получает отказ при попытке открыть заказ после отзыва. Telegram-обмен имитируется только в локальном Worker e2e.

## Удаление превью

**Preview cleanup** запускается, когда PR в `main` закрывают или вливают. Workflow читает скрипт из `main`, сверяет исходный репозиторий и точное имя ветки, проверяет открытые PR перед удалением и удаляет только Preview внутри Worker `korzina-demo`. Повторный запуск безопасен, в том числе когда превью уже отсутствует. Для запуска нужен секрет репозитория GitHub Actions `CLOUDFLARE_PREVIEW_CLEANUP_TOKEN` с разрешением Cloudflare Workers Scripts Write для аккаунта Korzina.
