# Блок 7 · Экраны настроек магазина

Формы и покупательские состояния подключены к серверам S4–S6 по [одобренной ревизии `474756805352898560`](https://designs.magicpath.ai/v1/purely-star-2749?revisionId=474756805352898560&history=design).

- «Ещё» открывает доставку, часы, оплату, данные магазина и витрину. Цвет открывается из витрины. Формы сохраняют по ревизии и оставляют введённое при конфликте.
- На «Главной» продавец ставит и снимает паузу по способу. На витрине видна обычная плашка. При тихой паузе подпись появляется на оформлении у остановленного способа.
- Покупка получает актуальный тариф, способы оплаты и публичные данные, включая логотип. Тариф, инструкция, требование чека и доступность повторно проверяются при оформлении.

Сквозная проверка `e2e/shop-settings.spec.ts` использует локальную сессию продавца для записи и чтения через Worker. На превью тот же сценарий проверяет переходы кабинета и делает снимки с тестовыми ответами API. Покупательский smoke на превью использует настоящий Worker.
