# Блок 6 · Локальная проверка каталога продавца

Перед прогоном сверь `build-revision` на demo и зелёный Demo smoke. Запиши дату, коммит, браузер или модель телефона, slug тестового магазина и номера созданных тестовых заказов. Используй отдельные сессии продавца и покупателя. [Demo](https://demo.korzina.app) · [Спецификация](../specs/seller-catalog.md) · [Одобренный холст, ревизия 474506689824059392](https://designs.magicpath.ai/v1/calmly-path-7720)

В «Результат» запиши ✅, ❌ или «Заблокировано». Для ❌ приложи снимок без личных данных и шаг воспроизведения. Для блокера укажи отсутствующую сессию, устройство или данные.

| № | Действие | Ожидаемый результат | Результат |
|---|---|---|---|
| 01 | В кабинете открыть «Товары», сменить раздел, отфильтровать список и вернуться из карточки. Проверить переключение магазина. | Три раздела находятся в одной вкладке. Возврат восстанавливает список, фильтр и прокрутку. Данные соответствуют текущему магазину. | |
| 02 | Создать товар. Из формы создать категорию, заполнить цену и остаток, сохранить. Открыть получившийся товар на витрине. Создать ещё один «Без категории». | Черновик сохраняется при создании категории. Оба товара доступны на витрине и находятся поиском. Товар без категории не добавляет плитку в мозаику. | |
| 03 | Проверить три статуса и видимость фасовки. Товар с остатком снять «До завтра», затем вернуть. У нулевого остатка попробовать число и «Без лимита». | В строке один статус. У скрытого только «Показать». Пауза сохраняет остаток, возврат нулевого требует выбора. На старой открытой витрине добавление и оформление недоступного товара отклоняются. | |
| 04 | Из двух строк открыть «Действия». Изменить или удалить одну строку во второй сессии. Применить действие в первой. Отдельно проверить перенос и подтверждение удаления. | Холст и кабинет показывают семь действий. При конфликте видны конкретные товары. Для удаления показано число товаров. | |
| 05 | Во время редактирования купить одну штуку. Затем сохранить новое описание и новый остаток. Повторить покупку перед подтверждением. | Описание сохраняется. Показан актуальный остаток, вторая покупка вызывает новый конфликт, старое число не записывается автоматически. | |
| 06 | Выбрать три ручные рекомендации и переставить. Одну скрыть, вторую удалить. Вернуть режим «Автоматически», затем отключить рекомендации. | В ручном режиме остаются выбранные видимые товары в заданном порядке. Выключенный режим убирает рекомендации. | |
| 07 | Создать подкатегорию и бренд. Проверить фото или инициалы. Скрыть родителя и бренд, затем удалить дерево с переносом. | Входы скрыты, товары находятся и покупаются. Перенос затрагивает товары родителя и потомков. | |
| 08 | «Ещё → Витрина». Выбрать размер, перетащить плитку, сохранить. Сверить главную покупателя и порядок категорий в кабинете. | Размер и порядок совпадают на обоих экранах. Мозаика из двух рядов прокручивается вбок. | |
| 09 | iPhone Safari и Android Chrome. В форме товара загрузить фото, на iPhone попробовать HEIC, поменять порядок и кадр. Открыть исходник и карточку покупателя. | Обложка первая, кадр сохраняется, исходник целиком. В Portrait поля и кнопки доступны при открытой клавиатуре. | |
| 10 | Открыть кабинет из Telegram и перейти на «Товары». Проверить назад из формы, включая несохранённый ввод, и вход в другом магазине. | Подтверждение выхода сохраняет черновик при отмене. Telegram и браузер остаются в выбранном магазине. | |
