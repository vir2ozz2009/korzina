# QA1 · Регрессии на demo

Учебный [магазин e2e](https://demo.korzina.app/?shop=e2e) работает в VND и Asia/Ho_Chi_Minh с семью товарами, доставкой «Куда угодно», самовывозом, наличными и учебным переводом. Владельцу соответствует отдельный аккаунт demo без подключённого Telegram. Настройки получения восстанавливаются до и после прогона, созданные заказы отменяются с возвратом товара. Реальных переводов нет.

Workflow «Регрессии» запускается на demo в 04:00 МСК и по кнопке Run workflow. Для первого прогона до вливания выбрать в «E2E» ветку `task/QA1` и цель `regressions`. Каждый шаг имеет лимит 30 с, job — 15 минут. Трассы и HTML-отчёт хранятся 7 дней после отзыва учебной сессии. При сбое workflow открывает issue с меткой `regression` и ссылкой на запуск.

GitHub Actions получает 15-минутную сессию через Worker `korzina-demo-regressions-auth` с D1 demo. Worker разрешает OIDC-идентичности штатного workflow из `main` и первого ручного запуска из `task/QA1`. Сессия привязана к единственному учебному магазину и отзывается по завершении.
