# O7 · Сервер переноса времени

Предложение времени использует общую ось с заменами. Свободное окно проверяется при предложении и принятии. При принятии новый резерв и освобождение старого проходят одной транзакцией. В заказе хранится актуальное предложение, в истории — каждый переход.

| Правило | Проверка |
| --- | --- |
| §9.7–§9.8, §11.5, §12.4 | «Встречный выбор закрывает предыдущий, старое время действует до принятия». |
| §9.9, US-Z05, US-R07 | «Потеря слота оставляет старое время и резерв, повтор успешного ответа резервирует один раз». |
| §11.6 | «Продавец сразу ставит свободное время заказу без окна, цена сохраняется». |
