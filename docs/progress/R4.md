# R4 · Логи Cloudflare без лишнего объёма

Карточка влита в [PR #83](https://github.com/vir2ozz2009/korzina/pull/83), `ca5d5ee`.

В `cloudflare.config.ts` для demo и превью явно включены Workers Logs без выборки и выключены invocation logs. Приложение пишет внутренние ошибки через `console.error` и метрики API для 1 % запросов. Трассировки по-прежнему собираются для 1 % запросов.

Версия `cf` из lockfile поддерживает `invocationLogs` и преобразует его в `observability.logs.invocation_logs` при сборке конфигурации.

Изменение `cloudflare.config.ts` запускает существующий Demo smoke. Приёмка после публикации также включает проверку Workers Logs по времени и идентификатору запроса.
