Использовать iPhone Mirroring; для K1 — настоящую полноразмерную клавиатуру iPhone. При недоступном шаге оставить ⏸ с причиной. API, автоматический браузер, Safari и Telegram — четыре отдельных источника доказательства.

D1 первым: категория → корзина с учебным комбо и посторонним товаром → прокрутить → открыть пояснение → Safari Back: шторка закрыта, та же корзина, состав/количество/получение/тариф/прокрутка сохранены, фокус вернулся на вход. Повторно открыть → крестик → открыть → жест вниз → открыть → Back. После каждого закрытия следующий обычный Back должен сразу вернуть в исходную категорию; снова войти в корзину. Циклы не добавляют пустые шаги истории. Проверить также Telegram BackButton и Back в примере продавца. Не заменять физический Back вызовом JS.
