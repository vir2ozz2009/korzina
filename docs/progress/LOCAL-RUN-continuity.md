# Анализ преждевременных остановок · 28.11.2026

Андрей поручил проверить причины и закрепить полный локальный прогон без произвольных остановок. Основание: повторные ответы исполнителя признают выполнимый остаток без установленных блокеров. Приёмки A6/B3 не закрыты.

## Подтверждённые дефекты инструкций

| Источник | Проблема | Исправление |
|---|---|---|
| WORKFLOW «Передача после каждой итерации» | Не определена завершённость итерации; формулировка допускает передачу после нескольких действий | Передача после согласованного этапа; промежуточный прогресс без окончания работы |
| TESTING §5 | Выпускной smoke 2–3 минуты расположен рядом с физической приёмкой без явного разграничения | Указаны исполнитель и неприменимость лимита к физическому прогону |
| A6-local-check | Старое требование отдельного поручения Work и облачный СТОП во входе локального чек-листа | Прямое поручение локальному на весь объём; старый процедурный барьер убран |
| B3-category-fit | Запрет автоматически присоединять A6 не пояснял уже согласованный единый прогон | A6 P01–P16 + B3 1–5 объединены только по текущему поручению |
| Маршрут и завершение | Нет явной проверки выполнимого остатка по подпунктам/средам перед финальным ответом | Единое условие завершения TESTING §5 и ссылки из входных документов |

Навык korzina-demo-recheck предназначен для точечной перепроверки, не для первичной приёмки; он ссылается на TESTING/WORKFLOW и не должен сужать явно заданный объём. Его требование разделять результат и SHA совместимо с продолжением при неизвестной версии.

Это возможные причины ошибочного чтения, не доказательство внутренней причины остановок агента. Полный журнал его действий и технических лимитов не получен; выдумывать ограничение сессии нельзя. Инструкции не гарантируют исполнение, но теперь нарушение проверяемо: финальный ответ при доступном незавершённом подпункте не соответствует условию завершения.
