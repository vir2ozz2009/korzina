# Блок 10 · Чек-лист локальной проверки

Холст одобрен Андреем 23.11.2026. Используйте [ревизию §17](https://designs.magicpath.ai/v1/glad-noon-3666?revisionId=475578003183771648&history=design) и [спецификацию](../specs/order-changes.md). Проверка проводится на [demo](https://demo.korzina.app) после зелёного smoke. У каждого сценария поле результата пустое до прогона.

Откройте кабинет магазина и его витрину в разных профилях браузера. Войдите покупателем через Telegram. Для сверки прав подготовьте владельца и сотрудника с ограниченными правами. Оформляйте тестовые заказы. Если в выбранном магазине другие цены, запишите его фактические суммы. Точные числа из §17.1 проверяет серверный тест. Записывайте URL, номер заказа, браузер или устройство, ожидаемое и фактическое поведение и снимок экрана при расхождении.

| № | Что сделать | Ожидаемый результат | Результат |
| --- | --- | --- | --- |
| 01 | Оформить заказ доставки и заказ самовывоза. Принять один в кабинете. Открыть карточки обеих ролей. | Этапы совпадают. При оформлении сохраняется привычный путь. В карточке видны название выбранного способа оплаты, время магазина и действия по заказу. | |
| 02 | В оплаченном заказе отметить товар «Нет в наличии», ввести 0. На другой строке указать часть исходного количества. Отменить одну отметку и поставить обратно. | У отмеченных строк меняются метки со знаком. Итог пересчитывается при каждом действии. После отправки отсутствие и уменьшение применяются сразу, показывается единый возврат. В «Товарах» затронутый отсутствующий товар недоступен до завтра, его можно вернуть раньше. | |
| 03 | В заказе «Томаты 120 000, сыр 50 000, другие товары 180 000» с подтверждённой оплатой 350 000 отметить томаты как отсутствующие и предложить четыре упаковки молока по 100 000 вместо сыра. Сверить черновик, отправить, открыть изменения с главной и из заказа покупателя. | Черновик показывает 350 000 → 580 000 ₫. После отправки обе роли видят 350 000 → 230 000 ₫ и возврат 120 000 ₫. У замены метка +350 000 ₫ и ожидание. Карточки показывают 50 000 ₫ за всю строку сыра и 400 000 ₫ за всю строку молока. | |
| 04 | Повторить 03 в двух заказах. В одном нажать «Согласен», во втором «Не нужно». В заказе с двумя заменами ответить по одной и сделать паузу. | При согласии 350 000 → 580 000 ₫, доплата 230 000 ₫. При отказе 350 000 → 180 000 ₫, возврат 170 000 ₫. Пересчёт виден обеим ролям без перезагрузки. Вторая замена остаётся открытой. | |
| 05 | В неоплаченном заказе предложить замену дешевле, с равной ценой и с запасом ниже предложенного. При подборе открыть товар, изменить количество и вернуться назад. Коснуться обеих карточек товаров у покупателя и вернуться. | В итогах неоплаченного заказа видны «было → стало». Метка показывает разницу со знаком и исчезает при равной цене. Количество по умолчанию исходное, превышение остатка останавливает выбор. Возврат сохраняет состояние экрана и фокус. | |
| 06 | Попытаться убрать единственную позицию. В другом заказе предложить замену единственной позиции и нажать «Не нужно». Проверить ещё один заказ после 30 минут без ответа. | Для удаления последней позиции открывается штатная отмена. Отказ и истечение срока отменяют заказ при пустом составе и открывают полный возврат подтверждённой оплаты. Просроченную карточку можно открыть для просмотра результата. | |
| 07 | В открытой замене завершить сборку, нажать передачу курьеру или выдачу. Отметить другую строку и попробовать предложить время. После ответа завершить заказ и снова открыть его. | Сборка доступна. Под передачей показана подпись, на нажатие появляется «Сначала дождитесь ответа по замене». Другая строка меняется сразу. Второе согласование закрыто до ответа. После передачи изменения состава и времени недоступны. | |
| 08 | Покупателю с доплатой открыть выбор способов. Проверить перевод на карту или QR, сумму, прикрепление чека, наличные и «Оплатить иначе». Продавцу записать доплату и выдать заказ. | Сумма доплаты совпадает у обеих ролей. Список содержит включённые способы. Видны реквизиты или QR, чек доступен продавцу. При наличных показано, кому передать деньги. Запись оплаты закрывает доплату. | |
| 09 | Продавцу предложить покупателю другое время. У покупателя открыть «Выбрать другое время», вернуться и открыть снова. Отправить своё окно. Продавцу выбрать «Предложить другое», затем проверить «Подходит» и альтернативную ветку «Оставить прежнее время». | Возврат без отправки сохраняет предложение. Каждый отправленный выбор закрывает предыдущий. У покупателя снова доступны оба ответа. До согласия действует прежнее время. После согласия обе роли видят новый слот, сумма прежняя. | |
| 10 | Покупателю самому попросить перенос. Проверить отзыв автором, пустое расписание, занятый слот и заказ без времени. Повторить для режима «в течение дня» и длинного интервала. | Отзыв сохраняет время и резерв. При занятом окне видна ошибка и можно выбрать снова. Для заказа без окна продавец сохраняет свободное время сразу. День и часы отображаются по часовому поясу магазина. | |
| 11 | Открыть переписки с витрины, из заказа покупателя, из шапки кабинета и карточки продавца. В другом магазине открыть список и попробовать перейти по чужому номеру. До входа открыть чат по прямой ссылке. | Вход возвращает в нужную переписку. Список покупателя показывает номера заказов текущего магазина. Чужой чат закрыт. Для общения без заказа доступны контакты магазина. | |
| 12 | Написать текст, загрузить фото, удалить из черновика, загрузить вновь и отправить. Открыть фото обеими ролями. Перед отправкой вернуться назад и снова открыть чат. Повторить при потере сети. | Черновик сохраняется до отправки. После выхода из аккаунта черновик прежнего пользователя очищается. Повтор с исходным ключом даёт одно сообщение. Фото доступно участникам своего заказа. История сохраняет порядок событий. | |
| 13 | Открыть несколько переписок. Отправить новое сообщение, пока продавец читает предыдущие. Проверить счётчик, приоритет, «Ждёт ответа», догрузку и возврат. | Непрочитанные сверху, дальше порядок по времени. Прочтение старого сообщения сохраняет более новое непрочитанным. После разрыва связи новые записи появляются при восстановлении. | |
| 14 | У владельца, управляющего, сборщика и бухгалтера проверить «Ещё → Уведомления → Сообщения». Получить сообщение покупателя, выключить уведомления или отозвать право, отправить ещё одно. Ответить покупателю в чате. | Исходные настройки соответствуют роли. Право и галочка управляют уведомлениями. Telegram открывает нужный заказ или чат. | |
| 15 | Открыть переписку завершённого или отменённого заказа старше семи дней. Прочитать старые записи и открыть вложение. | Доступны история, фото и переход к заказу. Появляется подпись о закрытии записи. | |
| 16 | Прогнать 03–04, 09, 11–12 в Telegram Web и Mini App. На iPhone Safari и Android Chrome повторить замену, кнопку согласия, шторку выбора времени и отправку фото с клавиатурой. | Кнопки доступны при прокрутке и с клавиатурой, системное «Назад» возвращает к исходному экрану, безопасные зоны соблюдены. | |
