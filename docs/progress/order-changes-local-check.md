## Дополнения Claude (23.11.2026)

Проверяются в тех же сценариях отдельной строкой ✅/❌.

- **03а · Статусы у продавца (§13.2, §14.3).** До ответа сверху «Ждём ответа покупателя до …» и список изменений. После «Согласен» / «Не нужно» на строке «согласен ✓» / «отказался» без перезагрузки, заголовок ожидания исчезает, список «Изменения» остаётся.
- **03б · Числа совпадают у ролей (§17.1).** В каждой точке (до ответа, после «Согласен», после «Не нужно») итог и строка «вернёте / доплатит» у продавца и покупателя одинаковы. Расхождение — ❌, даже если каждое число по отдельности «логично».
- **05а · Деньги только в итоге (§14.1, §16.1).** На кнопках «Согласен» / «Не нужно» и в тексте строк сумм нет — только метки «−/+» (зелёная / оранжевая) и строка итога. Условных строк «если согласится / откажется» нет нигде.
- **12а · Лимиты чата (§11.7).** 1000 символов отправляются, 1001 — понятная ошибка; второе фото в одно сообщение не прикрепляется; 11-е сообщение за минуту — отказ с подсказкой подождать.
- **14а · Уведомления покупателю.** Покупателю в Telegram приходят: изменения состава, предложение времени, ответ магазина на просьбу о переносе и новое сообщение в чате — каждое один раз, ссылка открывает нужный экран.
- **15а · 7 дней (§9.13).** Завершённый заказ младше 7 дней — писать можно; старше — только чтение.
