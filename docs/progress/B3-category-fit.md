## Причина и исправление

- Исходники demo milk (вертикальная бутылка) и bakery (тарелка с выпечкой) просмотрены отдельно: предметы целые. Сжатие upload сохраняет весь файл и пропорции. Файлы не редактировались.
- CategoryPhoto использовал cover; широкие плитки отводили фото только боковую область, список ограничивал всю карточку 128 px. Теперь общий CategoryTile продавца/витрины выделяет область под названием: 1×1 — 70% обеих сторон области после отступов, остальные — полное contain. Список — квадратная область фото, отдельное название и две колонки.
- CatalogTabs и дополнительные кнопки списков используют replace. Общий useBack (стрелка и Telegram) ведёт из корня раздела домой; вложенные шаги сохраняют обычную историю, прямой вход без неё — домой с shop.
- Код/серверные правила 12.3 не менялись относительно release `4bd2a8fc354045748aedccf154daeb8c301e0f6f`. Общий useBack затрагивает только корни каталога.

## Проверки и границы

Регрессия до исправления: после последовательности вкладок браузерный Back оставлял `/brands`. После исправления основной каталог и smoke прошли. `check:fast` и 10 связанных тестов PASS. Итог CI/preview и просмотр снимков — в PR/финальной передаче.

Существующий seller browser-тест обнаружил неоднозначный локатор строки/статистики; локатор уточнён. Заголовок тестового IP больше не отправляется на внешний image host (иначе ORB). Это правки теста, не приложения. Дополнен существующий browser-путь, новые CI/scripts не создавались.
