Затронутые товары снова «В продаже». Возвращены обе исходные паузы приёма (доставка без плашки и самовывоз с плашкой) и галочка уведомлений владельца.

В основном демомагазине отменён №5. В корзину возвращены три исходные фасовки на 167 000. Переключение корзины обратно на доставку с прежним сохранённым адресом выдало «Сюда не доставляем», поэтому в корзине остался самовывоз.

**Локально.** Последовательный запуск трёх файлов API-тестов состава, времени и чата на Node 24: 11 из 11. Включены точные суммы §17.1, проигранная гонка за слот и режим чата после семи дней.
