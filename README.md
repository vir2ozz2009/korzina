# Korzina · Корзина

Независимый магазин с витриной, кабинетом продавца, Telegram Mini App и ботом. Разработку ведём в Codex из этого приватного репозитория. Figma хранит макеты, MagicPath помогает быстро собрать и проверить интерфейс, GitHub хранит принятый код и контекст проекта.

## Продолжить в новом чате

Откройте папку этого репозитория как основной каталог проекта Korzina в Codex. Начните новый чат в проекте, чтобы Codex подхватил `AGENTS.md` и инструкции. Напишите «Продолжай Korzina. Прочитай прогресс и план, затем возьми следующий блок витрины».

Для работы с холстом выберите `@MagicPath` в чате и напишите, какой экран нужен. Например, «Покажи принятую карточку томатов в проекте „Korzina · Главная“». В репозитории есть [инструкция korzina-magicpath](.agents/skills/korzina-magicpath/SKILL.md), которую Codex может выбрать для работы с этим проектом.

- [AGENTS.md](AGENTS.md) — правила и порядок работы.
- [План](docs/plan.md) — этапы, критерии готовности и следующий шаг.
- [Архитектура](docs/architecture.md) — маршруты, сервер, Cloudflare и Telegram.
- [Figma и MagicPath](docs/design.md) — ссылки на макеты и перенос изменений в код.
- [Прогресс](docs/progress.md) — выполненные участки и замеры.

## Запуск

В локальном окружении «Korzina» в Codex доступны действия «Открыть витрину локально» и «Проверить сборку Korzina». Для нового рабочего дерева установку зависимостей выполняет команда окружения `npm ci`. В обычном локальном чате зависимости можно установить вручную.

Для воспроизводимой сборки используйте Node.js 22.12+ из ветки 22 или более новую поддерживаемую версию Node.js.

```sh
npm ci
npm run dev
```

Откроется принятая тестовая карточка томатов. Кнопка «Назад» ведёт в демонстрационный каталог, откуда открывается корзина. Данные и количество сохраняются в этом браузере. Для проверки сборки выполните `npm run build`.

Текущий этап — прототип витрины. Подключение собственного API, Cloudflare и Telegram описано в плане.
