# Korzina — обязательный вход

Магазины еды в Telegram и браузере. Пишем с нуля; код Lavka не копируем.

## Начало

1. Сначала проверить `git status --short`, ветку и HEAD; затем `git fetch origin main` и сверить `origin/main`. Продолжать свою task-ветку; новую задачу начинать в отдельной ветке/worktree от свежего main. Не переключать грязную или чужую рабочую копию. При сбое обновления указать непроверенную свежесть. Чужие изменения не трогать; статусы брать из свежего main, старый PROGRESS поверх нового не писать.
2. [PROGRESS](docs/PROGRESS.md); подготовка/реализация — читать карточку `docs/tasks/<ID>.md`, затем карту своего блока: [12.1](docs/blocks/12.1.md), [12.2](docs/blocks/12.2.md), [12.3](docs/blocks/12.3.md). Иные блоки — строка [PLAN](docs/PLAN.md) и карточка. Истории — строки задачи в [индексе](docs/stories/README.md) и их критерии.
3. Выбрать этап по [маршруту чтения](docs/context/README.md). Искать заголовки и читать диапазон раздела, не весь docs/specs/DECISIONS/архив. Поддерживать [короткие источники и карты](docs/context/README.md#поддержание-контекста) в затронутом PR. Карта не предел: деньги, права, изоляция, повторы, возвраты и связанные операции обязательны при зависимости.

## Границы и источники

- Делать только «Входит»/«Нажимается» карточки; будущее и «Не входит» не показывать. Неоднозначность и новый продуктовый вопрос — в Work с рекомендацией по [правилам вопросов](docs/WORKFLOW.md#вопросы-андрею); не додумывать.
- Ожидаемое поведение — актуальное решение Андрея и согласованная спецификация; карточка ограничивает объём. Код main показывает реализацию, доказательства — проверенный SHA/среду, а не новое продуктовое одобрение. Figma — справочник Work; Codex её не открывает. Конфликты фиксировать, не разрешать догадкой. Процесс и роли — [WORKFLOW](docs/WORKFLOW.md#как-мы-работаем-блоками-решение-андрея-18112026), этапы и СТОПы — [стандарт блока](docs/specs/README.md#стандартный-порядок-блока-решение-андрея-18112026-эталон--блок-2-покупка).
- Сервер — истина цен, остатков, денег, заказа и прав. Изоляция магазинов/сессий, идемпотентность, ревизии, транзакции и снимок для возвратов сохраняются. Секреты и данные покупателей — только `.dev.vars`/Cloudflare secrets, никогда в Git и не отправлять наружу.
- Prod (`korzina-prod*`, `korzina.app` без demo), всё Lavka, платные сервисы и невосстановимое удаление demo — только отдельное «да» Андрея. Lavka и её ресурсы/домены/боты/старый холст — только разрешённое чтение по карточке или процедуре спецификации. [Точные границы и постоянные разрешения](docs/WORKFLOW.md#постоянные-разрешения-андрея), [Lavka и стоимость](docs/WORKFLOW.md#золотые-правила).
- Разрешены `task/*`, PR/вливание при зелёных проверках, `korzina-demo*`/`korzina-preview*`, demo-поддомены; UI в MagicPath «Korzina» `473310532867354624`; детали — по ссылке выше.

## Работа и завершение

Переиспользовать UI-кит/шаблоны; сначала контракт и сервер, затем экран. Без кода «на будущее», новых scripts/CI без карточки. Изменение UI-кита более 3 компонентов — СТОП и отдельная задача/PR. [Золотые правила](docs/WORKFLOW.md#золотые-правила), [проверки](docs/WORKFLOW.md#проверки).

Тесты денег, прав и заказа не удалять и не ослаблять без решения Андрея. Автотест поведения не заменять снимком. Объём — [TESTING §1](docs/TESTING.md#1-уровни-проверки--по-размеру-изменения); docs-only — документационный Check без runtime. Экран — после «одобряю» по ревизии; видимые изменения — зелёный preview smoke и снимки. Локальная проверка — локальный Codex, физический iPhone; окончательная приёмка — Андрей.

PR на задачу: draft → Ready → CI; main → demo. Обновить PROGRESS кратко, детали в `docs/progress/<ID>.md` до 60 строк; статусы историй «сделано» только после проверки всех критериев на demo. [Завершение](docs/WORKFLOW.md#как-заканчивать-чат), [отчёт](docs/WORKFLOW.md#шаблон-отчёта). После вливания не ждать Demo smoke, проверить в начале следующей задачи.

В конце: результат, следующий шаг, исполнитель и причина; последняя строка: «➡️ Куда писать — … . Текст для вставки — „…“». СТОПы и [короткие команды](docs/WORKFLOW.md#как-начинать-любой-чат) сохраняются.
