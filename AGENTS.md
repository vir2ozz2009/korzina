# Korzina — обязательный вход

Магазины еды, Web и Telegram. Пишем с нуля, код Lavka не копируем.

## Начало

Проверить status/ветку/HEAD, затем `git fetch origin main`. Продолжать свою task-ветку; новую задачу — в отдельной ветке/worktree от свежего main. Чужие изменения не трогать и грязную копию не переключать. Без обновления не заявлять свежесть. Нет checkout — читать GitHub по зафиксированному SHA.

[Маршрут](docs/context/README.md): строка ID в PROGRESS → актуальная карточка/передача → только свой тип работы. Читать разделы/символы, не весь архив. Деньги, права, изоляция, повторы, возвраты и жизненный цикл новых данных всегда расширяют карту.

## Границы

- Карточка ограничивает объём. Новое поведение/неоднозначность — Work с рекомендацией. Требования — актуальное решение Андрея и согласованная спецификация; main — реализация, доказательство — SHA/среда. Принятое сохранять; Figma — справочник Work, Codex её не открывает.
- Сервер — истина цен, остатков, денег, заказа и прав. Сохранять изоляцию, идемпотентность, ревизии, транзакции, снимки возвратов. Тесты денег/заказа/прав не ослаблять без решения Андрея. Секреты/данные покупателей не помещать в Git и не отправлять наружу.
- Разрешены task/*, PR/вливание при зелёных проверках, demo/preview. Prod, Lavka, платное и невосстановимое удаление — отдельное согласие; Lavka читать только по разрешённой ссылке. [Точные полномочия](docs/WORKFLOW.md#постоянные-разрешения-андрея) и явный СТОП задания обязательны.
- Переиспользовать UI-кит/шаблоны; контракт и сервер до экрана. Без кода на будущее, новых scripts/CI без карточки. Более трёх компонентов UI-кита — СТОП и отдельная задача/PR.

## Завершение

[Проверки](docs/TESTING.md): объём по изменению; полный Check — CI актуального SHA, локально только при недоступном CI. UI — одобренная ревизия, preview smoke и снимки. Физический iPhone проверяет локальный Codex, принимает Андрей; незавершённое не засчитывать.

[WORKFLOW](docs/WORKFLOW.md#как-заканчивать-чат): краткая строка своей задачи в PROGRESS и одна передача с доказательствами; статусы историй — только после всех критериев на demo. Разрешённый цикл до проверенного demo и сверку покрытия выполняет облачный Codex, затем передаёт прямо локальному по [полному циклу](docs/WORKFLOW.md#полный-технический-цикл-до-demo). Docs-only — без runtime. Новый этап — новый чат по WORKFLOW, текущую итерацию не обрывать.
